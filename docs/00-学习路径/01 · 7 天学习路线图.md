# 7 天学习路线图

很多同学刚接触 Three.js 时，最大的问题不是「难」，而是「不知道先学啥、后学啥」。今天点一下相机，明天戳一下着色器，后天又去啃 WebGPU，结果哪个都只会皮毛。

这篇就是给你的一条**被验证过的顺序**：先让你在第一天就看到东西能动，再一天天把积木搭起来。每天有明确目标、要读的章节链接，还有勾选清单——做完打勾，7 天后你就能自己写出完整的小项目。

::: tip 大白话时间
学 3D 就像学做菜。你不能一上来就研究「分子料理」，得先学会开火、切菜、炒个蛋。这份路线图就是「7 天家常菜速成班」——每天一道菜，第 7 天自己设计一桌。
:::

## 一·五、由浅入深：完整阅读顺序（跨分组）

::: tip 大白话时间
L1/L2 是「照着做」，L3 是「想明白」，L4 是「扛得住」。

:::

## 二、第 1 天：从零到「有东西在转」

### 今日目标

页面上出现一个彩色立方体，并且它在不停旋转。就这一件事——做到就算过关。

### 学什么

- [01 · Three.js 是个啥](</01-基础入门/01 · Three.js 是个啥>)：搞明白 Three.js 是什么、能干嘛、和 WebGL 啥关系。
- [02 · 把环境搭起来](</01-基础入门/02 · 把环境搭起来>)：用 Vite + three 把开发环境装好。
- [03 · 第一个 3D 场景](</01-基础入门/03 · 第一个 3D 场景>)：照着敲出你的第一个场景。

### 今日检查清单

- [ ] 我能说清「场景、相机、渲染器」各自是干嘛的
- [ ] 环境装好了，`npm run dev` 能打开页面
- [ ] 立方体转起来了（不是黑屏）
- [ ] 我改过颜色、尺寸、转速，看到了变化
- [ ] 我知道忘了 `appendChild(renderer.domElement)` 会白屏

::: tip 大白话时间
第一天唯一的任务就是「**让它动起来**」。别管原理，先抄代码、先看到效果。3D 这东西，眼睛看到效果的那一刻，脑子才真正开始理解。
:::

## 三、第 2 天：三件套与几何体材质

### 今日目标

不再死记硬背那"三件套"，而是理解它们怎么配合；能用代码捏出球、圆柱、平面等多种形状，并给它们换材质。

### 学什么

- [04 · 三件套详解](</01-基础入门/04 · 三件套详解>)：把场景、相机、渲染器彻底讲透。
- [05 · 几何体与材质](</02-核心概念/05 · 几何体与材质>)：各种 Geometry 和 Material 的用法。
- 配套速查：[API 05 · WebGLRenderer 全参数](</06-API速查手册/API 05 · WebGLRenderer 全参数>)、[API 06 · 几何体全参考](</06-API速查手册/API 06 · 几何体全参考>)、[API 07 · Material 基类与基础材质](</06-API速查手册/API 07 · Material 基类与基础材质>)。

### 今日检查清单

- [ ] 我能解释「Mesh = 几何体 + 材质」
- [ ] 我会造 Box / Sphere / Plane / Cylinder 四种几何体
- [ ] 我知道 `MeshBasicMaterial` 不受光照影响、`MeshStandardMaterial` 受
- [ ] 我能给物体设置 `wireframe: true` 看到网格线

## 四、第 3 天：坐标变换与光照阴影

### 今日目标

把物体精确摆到想要的位置、角度、大小；给场景加上灯，让物体有明暗立体感，还能投出影子。

### 学什么

- [06 · 坐标与变换](</02-核心概念/06 · 坐标与变换>)：position / rotation / scale、父子关系、坐标系。
- [07 · 光照与阴影](</02-核心概念/07 · 光照与阴影>)：环境光、平行光、点光、阴影配置。
- 配套速查：[API 09 · 光照与阴影全参考](</06-API速查手册/API 09 · 光照与阴影全参考>)。
- 练手案例：[案例 04 · 弹跳球与真实阴影](</07-实战案例集/案例 04 · 弹跳球与真实阴影>)。

### 今日检查清单

- [ ] 我理解 position 是「平移」、rotation 是「旋转」、scale 是「缩放」
- [ ] 我知道物体默认绕自己的中心旋转
- [ ] 我加上了 `castShadow` / `receiveShadow` 并看到了影子
- [ ] 我知道 `MeshBasicMaterial` 再怎么打灯也不会变亮

::: tip 大白话时间
光照是 3D 的「灵魂」。同样一个球，不打灯就是个彩色圆圈，打了灯才有「立体」的感觉——因为明暗变化告诉你的大脑：这是个球，不是圆。
:::

## 五、第 4 天：动画循环与鼠标控制器

### 今日目标

用 r187 推荐的 `renderer.setAnimationLoop()` 写动画（不再用老式 `requestAnimationFrame`），并能用鼠标拖动旋转视角。

### 学什么

- [08 · 动画循环（r187 新写法）](</03-动画与交互/08 · 动画循环（r187 新写法）>)：新的循环写法、时间驱动动画。
- [09 · 鼠标控制器](</03-动画与交互/09 · 鼠标控制器>)：OrbitControls 的用法。
- 配套速查：[API 14 · 控制器全参考](</06-API速查手册/API 14 · 控制器全参考>)。

### 今日检查清单

- [ ] 我用 `setAnimationLoop` 而不是 `requestAnimationFrame` 写循环
- [ ] 我知道循环里要调用 `controls.update()`
- [ ] 鼠标左键能旋转、滚轮能缩放视角
- [ ] 我尝试让动画"按时间"走，而不是每帧固定加一点

::: danger 警告
**别用已废弃的 `Clock` 来算时间。** r187 里推荐自己用 `performance.now()` 算时间差，或者用 `Timer`。老教程里满屏的 `new THREE.Clock()` 已经过时了，别照抄。
:::

::: tip 大白话时间
