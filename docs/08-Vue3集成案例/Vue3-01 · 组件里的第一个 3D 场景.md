# Vue3-01：组件里的第一个 3D 场景

::: tip 大白话时间
第一次在 Vue 组件里放 3D，就像往新租的店面里搬一台大型冰柜：得等房东交了钥匙（组件挂载完）才能搬进去通电；哪天不租了，还得拔电、清货、把冰柜拖走，不能给下家留一摊烂子。
核心就三步——挂载后搭台（场景/相机/渲染器）、每帧转一下、销毁时反过来拆干净。
这是后面所有案例的"起手式模板"，任何一个 Vue 组件里要放 3D 画布，都从这三步开始。
:::

::: tip 效果长啥样
一个 Vue3 组件，页面上是 `400px` 高的画布区域，里面一个彩色立方体不停旋转。麻雀虽小，但**初始化、动画、清理**三件事一件不少——这是后面所有案例的模板。
:::

## 完整代码（`src/components/MyScene.vue`）

```vue
<template>
  <!-- ref 拿到这个 div，Three.js 的 canvas 会被塞进来 -->
  <div ref="container" class="canvas-box"></div>
</template>

<script setup>
import { ref, shallowRef, onMounted, onUnmounted } from 'vue'
import * as THREE from 'three'

const container = ref(null)        // 模板里的 div
const renderer = shallowRef(null)  // Three.js 对象：用 shallowRef，不用 ref！

let scene, camera, cube, startTime

onMounted(() => {
  const w = container.value.clientWidth
  const h = container.value.clientHeight

  // 1. 场景 + 相机
  scene = new THREE.Scene()
  scene.background = new THREE.Color(0x1a1a2e)
  camera = new THREE.PerspectiveCamera(60, w / h, 0.1, 100)
  camera.position.z = 4

  // 2. 渲染器（注意是 renderer.value —— shallowRef 要解包）
  renderer.value = new THREE.WebGLRenderer({ antialias: true })
  renderer.value.setSize(w, h)
  container.value.appendChild(renderer.value.domElement)

  // 3. 一个会变色的立方体
  cube = new THREE.Mesh(
    new THREE.BoxGeometry(1.6, 1.6, 1.6),
    new THREE.MeshNormalMaterial()
  )
  scene.add(cube)

  // 4. 渲染循环：回调参数 time 是毫秒时间戳
  startTime = performance.now()
  renderer.value.setAnimationLoop((time) => {
    const t = (time - startTime) / 1000   // 转成从启动算起的秒数
    cube.rotation.x = t * 0.6
    cube.rotation.y = t * 0.9
    renderer.value.render(scene, camera)
  })

  window.addEventListener('resize', onResize)
})

function onResize() {
  const w = container.value.clientWidth
  const h = container.value.clientHeight
  camera.aspect = w / h
  camera.updateProjectionMatrix()
  renderer.value.setSize(w, h)
}

onUnmounted(() => {
  // ⚠️ 清理四件套，一个都不能少
  renderer.value.setAnimationLoop(null)          // ① 停渲染循环
  window.removeEventListener('resize', onResize) // ② 移除监听
  scene.traverse(obj => {                         // ③ 释放几何体和材质
    obj.geometry?.dispose()
    if (Array.isArray(obj.material)) obj.material.forEach(m => m.dispose())
    else obj.material?.dispose()
  })
  renderer.value.dispose()                       // ④ 释放渲染器
  renderer.value.domElement.remove()             //    把 canvas 从 DOM 摘掉
})
</script>

<style scoped>
.canvas-box { width: 100%; height: 400px; }
/* scoped 样式默认穿透不到 Three.js 动态插入的 canvas，用 :deep() */
.canvas-box :deep(canvas) { display: block; }
</style>
```

## 关键点拆解

::: tip 为什么在 onMounted 里初始化
`const container = ref(null)` 刚开始是 `null`，只有组件**挂载完成**后，`container.value` 才指向真实的 `<div>`。在那之前访问 `container.value.clientWidth` 会直接报错。所以凡是碰 DOM 的初始化，统统放 `onMounted`。
:::

::: tip 大白话时间
那个 `<div>` 的 ref 刚开始是个空盒子（null），组件还没挂到页面上呢。这会儿就去量它宽高，等于对着空气量尺寸——直接报错。`onMounted` 就是"房东交钥匙"的信号，拿到钥匙再去量、再去塞 canvas，稳。
:::

::: tip 为什么用 shallowRef 而不是 ref
`ref()` 会把对象也变成响应式代理（内部调 `reactive()`）——这正是 Three.js 最怕的。`shallowRef()` 只跟踪「整个对象被替换」，**不代理对象内部**，Three.js 对象放进去安然无恙。代价是改内部属性要让 Vue 知道时得手动 `triggerRef()`，但 3D 渲染本来就不靠 Vue 驱动，正合适。
:::

::: tip 大白话时间
`ref` 像个过度热情的安检员，连 Three.js 物体里面的螺丝钉都要拆开重新包一遍——包完就不是原来那个物体了，Three.js 当场不认。`shallowRef` 只盯"整个盒子换没换"，盒子里装啥一概不碰。3D 物体要的就是这种"别动我内部"的放手式管理。
:::

::: warning 清理不是可选项
`onUnmounted` 里那四步漏掉任何一步，路由切走后都会留下后果：不停渲染（Case 白跑）、resize 监听泄漏（内存涨）、显存不释放（GPU 爆）、canvas 残留在 DOM（界面错乱）。养成习惯：**初始化时写了什么，销毁时就反着拆什么**。
:::

::: tip 小改进
- 把 `MeshNormalMaterial` 换成 `new THREE.MeshStandardMaterial({ color: 0x42b883 })`，再加一盏 `DirectionalLight`，就有真实光照了。
- 用 `ResizeObserver` 替代 `window.resize`，能监听容器本身尺寸变化（比如侧边栏收起），更精准。
:::
