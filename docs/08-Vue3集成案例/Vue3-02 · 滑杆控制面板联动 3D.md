# Vue3-02：滑杆控制面板联动 3D

::: tip 大白话时间
这块就像开车：你手里的方向盘和油门是 Vue 控件，车的发动机是 Three.js。你不会把手伸进发动机里拨火花塞，而是转方向盘、踩油门，通过一根传动轴（watch / 每帧读取）让发动机乖乖变速。
核心一句：Vue 手里只捏着"转速、颜色、线框"这几个旋钮值，3D 那边只管照着旋钮转，两边靠一根传话线连着。
凡是做带控制面板、拖个滑杆就要实时看到 3D 变化的功能，都是这个套路。
:::

::: tip 效果长啥样
上面一排 Vue 写的控件（滑杆调转速、颜色选择器调颜色、复选框切线框），下面是一个 Three.js 立方体。**拖滑杆转速立刻变、选颜色立方体立刻变色**——这就是 Vue 响应式和 Three.js 之间的「桥」。
:::

## 完整代码（`src/components/ControlPanel.vue`）

```vue
<template>
  <div class="wrap">
    <div class="panel">
      <label>转速
        <input type="range" v-model.number="speed" min="0" max="4" step="0.1">
        <b>{{ speed.toFixed(1) }}</b>
      </label>
      <label>颜色 <input type="color" v-model="color"></label>
      <label><input type="checkbox" v-model="wireframe"> 线框模式</label>
    </div>
    <div ref="container" class="canvas-box"></div>
  </div>
</template>

<script setup>
import { ref, shallowRef, watch, onMounted, onUnmounted } from 'vue'
import * as THREE from 'three'

// —— Vue 这边：只管「配置」——
const speed = ref(1)
const color = ref('#42b883')
const wireframe = ref(false)

// —— Three.js 这边——
const container = ref(null)
const material = shallowRef(null)
let scene, camera, renderer, cube, startTime, angle = 0, lastTime = 0

onMounted(() => {
  const w = container.value.clientWidth, h = container.value.clientHeight
  scene = new THREE.Scene()
  scene.background = new THREE.Color(0x101018)
  camera = new THREE.PerspectiveCamera(60, w / h, 0.1, 100)
  camera.position.z = 4

  // 材质存进 shallowRef，供 watch 修改
  material.value = new THREE.MeshStandardMaterial({
    color: color.value, wireframe: wireframe.value
  })
  cube = new THREE.Mesh(new THREE.BoxGeometry(1.8, 1.8, 1.8), material.value)
  scene.add(cube)
  scene.add(new THREE.AmbientLight(0xffffff, 0.6))
  const light = new THREE.DirectionalLight(0xffffff, 2)
  light.position.set(3, 5, 4)
  scene.add(light)

  renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(w, h)
  container.value.appendChild(renderer.domElement)

  renderer.setAnimationLoop((time) => {
    const dt = Math.min((time - lastTime) / 1000, 0.05)  // 帧间隔，限幅
    lastTime = time
    angle += dt * speed.value      // 每帧直接读 speed.value
    cube.rotation.y = angle
    renderer.render(scene, camera)
  })
  window.addEventListener('resize', onResize)
})

// —— 桥：Vue 变量变了 → 改 Three.js 对象——
watch(color, v => material.value?.color.set(v))
watch(wireframe, v => { if (material.value) material.value.wireframe = v })
// speed 不用 watch：渲染循环每帧读 speed.value 即可，更省

function onResize() {
  const w = container.value.clientWidth, h = container.value.clientHeight
  camera.aspect = w / h
  camera.updateProjectionMatrix()
  renderer.setSize(w, h)
}

onUnmounted(() => {
  renderer.setAnimationLoop(null)
  window.removeEventListener('resize', onResize)
  scene.traverse(o => {
    o.geometry?.dispose()
    if (Array.isArray(o.material)) o.material.forEach(m => m.dispose())
    else o.material?.dispose()
  })
  renderer.dispose()
  renderer.domElement.remove()
})
</script>

<style scoped>
.wrap { max-width: 700px; }
.panel { display: flex; gap: 20px; flex-wrap: wrap; margin-bottom: 12px; font: 14px sans-serif; }
.panel label { display: flex; align-items: center; gap: 6px; }
.canvas-box { width: 100%; height: 400px; }
.canvas-box :deep(canvas) { display: block; }
</style>
```

## 关键点拆解

::: tip 两类参数，两种处理方式
这是全册最重要的设计思想：
- **连续变化的参数**（转速、位置）：渲染循环每帧直接读 `speed.value`。因为它本来就要每帧更新，读一个 ref 的值几乎零成本。
- **偶尔改一次的参数**（颜色、线框、材质类型）：用 `watch` 监听，变了才去改 Three.js 对象。因为每帧无脑重设颜色是浪费。

分清这两类，你的 Vue3 + Three.js 应用就不会卡。
:::

::: tip 大白话时间
旋钮也分脾气：转速这种"一直在动"的，渲染循环每帧顺手读一下，比专门派人盯着划算；颜色、线框这种"半天不动一回"的，才值得挂个 watch 守着，变了才喊一声。分清哪类，性能能差好几倍。
:::

::: tip 为什么改颜色要 color.set(v) 而不是直接赋值
`material.color` 是一个 `THREE.Color` 对象，不能直接 `material.color = '#ff0000'`（那样会把 Color 对象替换成字符串，Three.js 就懵了）。要调它的 `.set()` 方法把新颜色「灌」进去。`watch` 拿到的 `v` 是 `v-model` 绑定的字符串比如 `#42b883`，`Color.set()` 正好认识这种格式。
:::

::: tip 大白话时间
换颜色不是把立方体扔了重做一个——那就跟"嫌墙颜色不好看就把房子拆了重建"一样傻。材质早就在那儿了，只要拧一下它的 `.color` 旋钮，把新颜色灌进去就行，又快又省钱。
:::

::: tip 用累加角度代替直接设 rotation
`angle += dt * speed.value` 然后 `cube.rotation.y = angle`：这样**改速度不会跳变**。如果写成 `cube.rotation.y = time * speed.value`，一拖滑杆速度突变，角度会瞬间跳到另一个值，画面「闪一下」。累加的方式则平滑过渡。
:::

::: tip 继续加控件
照这个模式，想加什么控件都行：
- 缩放：`watch(scale, v => cube.scale.setScalar(v))`
- 显示/隐藏：`watch(visible, v => cube.visible = v)`
- 金属度：`watch(metalness, v => material.value.metalness = v)`
:::
