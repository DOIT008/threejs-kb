# Vue3-10：完整实战 · 3D 产品配置器

::: tip 大白话时间
前面九章练的都是单个零件，这一章把它们攒成一辆能上路的整车：Vue 面板是方向盘和仪表盘，useThree 是发动机底盘，watch 是传动轴，Raycaster 是触摸选车屏，截图按钮是行车记录仪。你拧一下"颜色"旋钮，车漆立刻就换。
核心一句：Vue 从头到尾不碰"每帧渲染"这台发动机，只在配置变了时伸手调一次 3D 零件，其余时间 3D 自己转。
想做个能写进简历、把学到的全串起来的小项目，就照这台车装配。
:::

::: tip 最终效果
一个能写进简历的小项目：左边是 Vue 写的配置面板（选产品型号、换颜色、调材质、转视角、截图），右边是 Three.js 实时渲染的产品预览。改任何配置，3D 画面立刻响应。这一章把前面 9 章的技术全串起来了。
:::

## 用到的技术清单

| 技术 | 用在哪 |
|---|---|
| `shallowRef` | 装场景/相机/渲染器/产品物体 |
| `watch` | 配置变化 → 更新 3D 材质/几何体 |
| composable | `useThree()` 复用初始化与清理 |
| 事件回调 | Raycaster 点击 3D 物体 → 更新 UI |
| `toDataURL` | 截图导出 |
| 完整 dispose | 组件销毁不留残余 |

## 文件 2：`src/components/ProductConfigurator.vue`

```vue
<template>
  <div class="app">
    <!-- 左侧：Vue 配置面板 -->
    <aside class="sidebar">
      <h2>产品配置器</h2>

      <label>型号
        <select v-model="model">
          <option value="box">方形款</option>
          <option value="cylinder">圆柱款</option>
          <option value="sphere">球形款</option>
        </select>
      </label>

      <label>颜色
        <input type="color" v-model="color">
      </label>

      <label>材质
        <select v-model="finish">
          <option value="matte">哑光</option>
          <option value="metal">金属</option>
          <option value="glossy">亮面</option>
        </select>
      </label>

      <label>自动旋转
        <input type="checkbox" v-model="autoRotate">
      </label>

      <button @click="takeSnapshot">📷 保存截图</button>
      <p class="status">{{ status }}</p>
      <p class="tip">💡 点一下产品可以选中它</p>
    </aside>

    <!-- 右侧：Three.js 画布 -->
    <main ref="container" class="stage"></main>
  </div>
</template>

<script setup>
import { ref, shallowRef, watch } from 'vue'
import * as THREE from 'three'
import { useThree } from '../composables/useThree'

// —— Vue 状态：全是普通数据 ——
const model = ref('box')
const color = ref('#42b883')
const finish = ref('matte')
const autoRotate = ref(true)
const status = ref('就绪')

// —— 3D 场景 ——
const container = ref(null)
const { scene, camera, renderer, ready, onFrame, add } = useThree(container, {
  background: 0xf0f2f5, cameraZ: 5
})

const product = shallowRef(null)      // 3D 物体用 shallowRef
const raycaster = new THREE.Raycaster()
const mouse = new THREE.Vector2()

const geometryOf = m => ({
  box:      () => new THREE.BoxGeometry(2, 2, 2),
  cylinder: () => new THREE.CylinderGeometry(1, 1, 2, 48),
  sphere:   () => new THREE.SphereGeometry(1.3, 48, 32)
}[m]())

const materialParams = {
  matte:  { roughness: 0.9, metalness: 0.0 },
  metal:  { roughness: 0.25, metalness: 0.9 },
  glossy: { roughness: 0.05, metalness: 0.1 }
}

function buildProduct() {
  if (product.value) {                       // 换型号：先清掉旧的
    scene.value.remove(product.value)
    product.value.geometry.dispose()
    product.value.material.dispose()
  }
  product.value = new THREE.Mesh(
    geometryOf(model.value),
    new THREE.MeshStandardMaterial({ color: color.value, ...materialParams[finish.value] })
  )
  add(product.value)
}

// 场景就绪后建产品；之后配置变化实时响应
watch(ready, v => {
  if (!v) return
  buildProduct()
  // 灯光
  scene.value.add(new THREE.HemisphereLight(0xffffff, 0x888899, 1.5))
  const key = new THREE.DirectionalLight(0xffffff, 2)
  key.position.set(4, 6, 5)
  scene.value.add(key)
  // 每帧：自动旋转
  onFrame(() => {
    if (product.value && autoRotate.value) product.value.rotation.y += 0.01
  })
  // 点击检测
  renderer.value.domElement.addEventListener('pointerdown', onClick)
})

watch(model,  () => buildProduct())                       // 换型号 → 重建
watch(color,  v => product.value?.material.color.set(v))  // 换颜色 → 改材质
watch(finish, v => {                                       // 换材质 → 改参数
  if (!product.value) return
  Object.assign(product.value.material, materialParams[v])
})
watch(autoRotate, v => status.value = v ? '自动旋转中' : '已暂停旋转')

function onClick(e) {
  const rect = renderer.value.domElement.getBoundingClientRect()
  mouse.x = ((e.clientX - rect.left) / rect.width) * 2 - 1
  mouse.y = -((e.clientY - rect.top) / rect.height) * 2 + 1
  raycaster.setFromCamera(mouse, camera.value)
  status.value = raycaster.intersectObject(product.value).length
    ? '✅ 已选中产品' : '点一下产品试试'
}

function takeSnapshot() {
  // 保留绘图缓冲区才能截到图（默认渲染后会清空）
  renderer.value.render(scene.value, camera.value)
  const url = renderer.value.domElement.toDataURL('image/png')
  const a = document.createElement('a')
  a.href = url
  a.download = `产品-${model.value}.png`
  a.click()
  status.value = '📷 截图已保存'
}
</script>

<style scoped>
.app { display: flex; min-height: 500px; font-family: sans-serif; }
.sidebar { width: 240px; padding: 20px; background: #fafafa; border-right: 1px solid #e0e0e0; }
.sidebar h2 { font-size: 18px; margin-top: 0; }
.sidebar label { display: block; margin: 14px 0; font-size: 14px; }
.sidebar select, .sidebar input[type=color] { margin-top: 6px; }
button { width: 100%; padding: 10px; background: #42b883; color: #fff; border: 0; border-radius: 6px; cursor: pointer; }
.status { font-size: 13px; color: #42b883; }
.tip { font-size: 12px; color: #999; }
.stage { flex: 1; }
.stage :deep(canvas) { display: block; }
</style>
```

::: warning 截图的一个细节
`WebGLRenderer` 默认 `preserveDrawingBuffer: false`，渲染完就把绘图缓冲区清了，直接 `toDataURL()` 可能得到空白图。上面代码在截图前**手动再渲染一次**再取图，就能截到当前画面。另一种做法是在创建渲染器时设 `preserveDrawingBuffer: true`，但会略微影响性能。
:::

## 关键点拆解

::: tip 整个项目的数据流
```text
Vue 配置面板 (ref)
      │  watch
      ▼
Three.js 物体 (shallowRef)
      │  setAnimationLoop 渲染
      ▼
屏幕画面
      │  Raycaster 点击
      ▼
Vue status (ref) → 界面更新
```
一个闭环。Vue 从头到尾**没有参与逐帧渲染**，只在配置变化时动手改一次 Three.js 对象。这就是高性能 Vue3 + Three.js 应用的正确架构。
:::

::: tip 大白话时间
看那条数据流就明白了：Vue 只在"你动了控件"时出手一次，改完就撒手；中间那几百帧全是 3D 自己在转、自己在画；你点一下产品，它再把"选中了"这个消息递回给 Vue 显示一行字。Vue 绝不掺和逐帧渲染——这正是画面不卡的秘密。
:::

::: tip 换型号为什么 dispose 再重建
不同型号用不同几何体（Box/Cylinder/Sphere），没法简单地「改参数」变形，只能换整个 geometry。换之前 dispose 旧的，避免显存泄漏。而换颜色、换材质参数则不用重建——直接改现有材质属性即可，成本几乎为零。**能改属性就别重建**。
:::

::: tip 大白话时间
换颜色、换材质参数，就像给同一件衣服换个颜色、换颗纽扣——直接改就行，不用重做一件。可换型号（方的变圆的）等于衣服要换版型，没法小修小补，只能把旧的扔了（dispose）重做一件。原则是：拧旋钮能解决的，就别动不动推倒重来。
:::

::: tip 继续扩展成完整项目
- 加 shadow：渲染器开 `shadowMap`，产品 `castShadow`，加个地面 `receiveShadow`。
- 加环境贴图：`scene.environment = pmrem.fromScene(new RoomEnvironment()).texture`，金属材质立刻有反射质感。
- 加多个产品：把配置存进 Pinia（案例 06），做成一个可选型号列表。
- 用 TS：给 `useThree` 和配置项加类型，配合 Volar 有完整提示。
- 加导出：除了 PNG，还可以导出当前配置为 JSON，下次导入还原。
:::
