# 后期辉光实验室

「Bloom 辉光我加了，怎么没效果？」——这个问题十有八九是阈值设错了。这个实验室把三个参数摊开，让你看清楚辉光到底挑谁发光。

<BloomLab />

## 后期处理是怎么回事

::: tip 大白话时间
正常渲染是「画完直接显示」。后期处理是「画完先存起来，再拿去加工一轮，最后显示」——就像拍照后套滤镜。

`EffectComposer` 就是这条加工流水线：

1. **RenderPass**：先把场景正常画一遍，存进纹理
2. **UnrealBloomPass**：找出画面里超过亮度阈值的部分，模糊扩散，叠回去
3. **OutputPass**：做色调映射和色彩空间转换，输出最终画面

可以再加别的 Pass（景深、描边、色彩校正），串成一条链。
:::

## 三个参数

| 参数 | 作用 | 常见坑 |
|---|---|---|
| **threshold 阈值** | 亮度超过它才发光 | 设太高 → 谁都不发光（最常见）。设太低 → 整个画面糊成一片 |
| **strength 强度** | 辉光叠加强度 | 太大过曝，一般 0.5~1.5 |
| **radius 半径** | 模糊扩散范围 | 决定光晕大小，一般 0.2~0.6 |

实验室里那几个彩色球有 `emissive`（自发光），亮度高，所以过阈值会发光；底下那个暗灰方块不发光，永远不参与辉光——这个对比就是 threshold 的意义。

## 为什么我的辉光没效果

按顺序排查：

1. **阈值太高** → 先把 threshold 拉到 0、emissive 拉到 5，一定能看到
2. **物体不够亮** → 普通材质 + 普通灯光很难过阈值，给它加 `emissive` 或用超亮颜色（颜色值可以 > 1）
3. **渲染没走 composer** → 循环里必须是 `composer.render()`，不能还是 `renderer.render(scene, camera)`。本组件用 `setRenderOverride` 替换了渲染函数——自己写的时候记得改
4. **没加 OutputPass** → r152 之后色彩管理变了，缺 OutputPass 会导致颜色发灰或过亮
5. **resize 没同步** → 窗口变化时 `composer.setSize(w, h)`，否则画面模糊

::: warning 性能代价
每个 Pass 都是一次全屏绘制，Bloom 内部还有多次模糊采样，是**很贵**的效果。移动端慎用——要么降分辨率，要么只在关键场景开。性能专题里有更详细的剖析方法。
:::
