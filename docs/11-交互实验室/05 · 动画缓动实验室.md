# 动画缓动实验室

同样从 A 点走到 B 点、同样 2 秒，为什么有的动画像机器、有的像有生命？秘密全在「缓动函数」里。

<EasingLab />

## 缓动的本质

::: tip 大白话时间
动画进度 `t` 从 0 走到 1（就像秒表从 0% 走到 100%）。如果直接用 t，物体匀速移动——很机械。

**缓动函数就是一个「把 0~1 重新映射成 0~1」的函数**，它改变的是速度分布，不改变起点终点。比如 `easeIn`（t²）：开始慢、结束快，像汽车起步。`bounce`：快到终点时弹几下，像皮球落地。

现实里几乎没有东西是匀速的——车会加速减速、人会起步停下。所以好的动画都要加缓动。
:::

## 各曲线特点

| 缓动 | 手感 | 适用场景 |
|---|---|---|
| `linear` | 匀速、机械 | 转盘、进度条、匀速旋转 |
| `easeIn` | 慢启动、快结束 | 物体"冲出去" |
| `easeOut` | 快启动、慢刹车 | 元素飞入、面板滑出 |
| `easeInOut` | 两头慢中间快 | 最通用，页面转场、相机移动 |
| `back` | 冲过头再退回 | 按钮点击、弹窗出现，活泼 |
| `elastic` | 像弹簧来回抖 | 强调性动画、奖励反馈 |
| `bounce` | 像皮球弹跳 | 落地、掉落效果 |

## 在代码里怎么用

关键是把「已用时间 / 总时长」算出进度 t，再丢给缓动函数：

```js
const DURATION = 2 // 秒
let elapsed = 0
let prev = performance.now() // 必须先初始化，否则第一帧读 prev 会报 ReferenceError

renderer.setAnimationLoop(() => {
  const now = performance.now()
  const dt = Math.min(now - prev, 100) / 1000 // 上限 100ms，防止切后台回来跳一大步
  prev = now
  elapsed += dt

  const t = Math.min(elapsed / DURATION, 1) // 0~1 的进度
  const k = easeInOut(t)                     // 经过缓动的值
  cube.position.x = startX + (endX - startX) * k // 用 k 插值
})
```

::: tip 别手写缓动函数
实验室里为了讲解手写了这些函数，实际项目推荐用现成库：

- **Tween.js**（`@tweenjs/tween.js`）——Three.js 生态标配，`new Tween(obj).to({...}, 2000).easing(Easing.Quadratic.InOut).start()`
- **GSAP**——功能最强，时间线、补间、stagger 全有
- Three.js 自带的 `AnimationMixer`——适合播放模型里烘焙好的关键帧动画

核心概念是一样的，用库省得造轮子。
:::
