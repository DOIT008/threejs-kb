# 光照实验室

「为什么我加了灯画面还是平的？」——这是新手最常问的问题之一。答案往往是：只有一种光，或者所有光都很强，把明暗对比抹平了。这个实验室让你亲手体会三种光各自的分工。

<LightLab />

## 三种光，各管一摊

::: tip 大白话时间
把 3D 场景当成一个摄影棚：

- **环境光 HemisphereLight** 是「房间里的漫射光」——天花板反射下来的天光 + 地面反射，它没有方向，只负责「别让暗面死黑」。
- **平行光 DirectionalLight** 是「太阳」——光线平行、方向统一，负责塑造立体感和投影。你调光源 X/Y，就像在改变太阳在天空的位置。
- **点光源 PointLight** 是「灯泡」——从一个点向四面八方发散，近处亮远处暗，适合做局部重点照明。

一个好看的场景通常是三者搭配：环境光打底、平行光塑形、点光源点缀。
:::

## 怎么玩

1. **先关掉所有灯**——只剩黑色，证明材质本身不发光（除非是 `MeshBasicMaterial` 或有 emissive）。
2. **只开环境光**——三个球都能看见，但完全没有立体感，像纸片。这就是"只有环境光"的效果。
3. **加平行光，拖动光源 X/Y**——阴影方向跟着变，球的明暗交界（terminator）随之移动，立体感出来了。
4. **三个球的粗糙度不同（0.15/0.5/0.95）**——观察高光：越光滑高光越集中越亮。这就是 roughness 的作用。
5. **切「夜景」预设**——环境光调暗、平行光关闭、暖色点光源打开，氛围立刻不一样。

::: warning 阴影为什么要有四个开关
阴影不是"加个灯就自动有"，它要三处同时开：渲染器 `renderer.shadowMap.enabled = true`、灯 `castShadow = true`、物体 `castShadow` + 地面 `receiveShadow`。少一个都不显示。实验室里勾选「开启阴影」控制的是灯那一处。
:::
