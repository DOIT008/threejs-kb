这一章有点特别——**不是看图，是真能动手玩**。下面每个演示都是嵌在文档里的实时 3D 场景，鼠标拖动能转视角，滚轮能缩放，控件能改参数，改完立刻见效。

:::

## 六、这些演示是怎么实现的

你可能会好奇：Markdown 里怎么塞进交互 3D？核心就三件事：

```js
// 1. 一个通用舞台：onMounted 里才初始化 WebGL（SSR 构建时不会炸）
onMounted(() => {
  renderer = new THREE.WebGLRenderer({ antialias: true })
  scene = new THREE.Scene()
  camera = new THREE.PerspectiveCamera(50, w / h, 0.1, 1000)
  renderer.setAnimationLoop(() => renderer.render(scene, camera))
})

// 2. 卸载时彻底清理，避免切页后内存泄漏
onBeforeUnmount(() => {
  scene.traverse(o => { o.geometry?.dispose(); o.material?.dispose() })
  renderer.dispose()
  renderer.domElement.remove()
})

// 3. 在主题里全局注册组件，Markdown 直接写 <MaterialLab />
```

完整的 composable 源码在 `docs/.vitepress/theme/composables/useThreeStage.js`，十个组件的源码在同级 `components/` 目录。composable 还提供 `setActiveCamera()`（切换相机）和 `setRenderOverride()`（替换渲染方式，辉光实验室用它把 `renderer.render` 换成 `composer.render`）。想加自己的演示，照着改就行。

::: info 和 Vue3 案例的区别
这里的组件跑在**文档站点**里（VitePress 自带 Vue3），用来演示单个概念；[**08-Vue3集成案例**](</08-Vue3集成案例/Vue3-00 · 怎么用这些案例>)那一章教你把 Three.js 装进**自己的** Vue3 项目。两者技术相同，目的不同：一个是「看懂」，一个是「会用」。
:::
