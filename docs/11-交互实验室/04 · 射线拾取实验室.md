# 射线拾取实验室

鼠标怎么知道你点中了哪个 3D 物体？答案是「从鼠标位置发射一条射线，看它穿过谁」。这个实验室把整条链路可视化。

<RaycastLab />

## 拾取三步走

::: tip 大白话时间
想象你闭着眼睛，有人告诉你「正前方偏左一点有个球」。你伸手去摸——你的手臂就是**射线**，摸到的第一个东西就是**命中的物体**。

Three.js 的做法一模一样：

1. **把鼠标位置换算成 NDC**：屏幕坐标（像素）转成 -1~1 的标准化坐标。屏幕中心是 (0,0)，左上角是 (-1,1)，右下角是 (1,-1)。注意 Y 轴是**反的**（屏幕往下是正，NDC 往上是正）。
2. **`raycaster.setFromCamera(pointer, camera)`**：从相机位置，穿过鼠标指向的那个点，发射一条射线。
3. **`raycaster.intersectObjects(objects)`**：算出射线和每个物体的交点，按距离从近到远排序。第一个就是你要的。
:::

## 右侧读数怎么看

鼠标移动时，右侧的 `NDC x / y` 实时变化——这就是传给 raycaster 的坐标。把鼠标放在画布正中心，读数接近 (0, 0)；移到边缘，接近 ±1。

勾选「显示射线」，会画出那条黄色的线。你会看到它始终从相机出发、穿过鼠标位置——非常直观。

::: warning 两个高频坑
**① 坐标要用画布的包围盒算**，不能直接用 `clientX / innerWidth`。如果画布不是全屏（像本页这样在左边栏），用错就会点不准。正确写法就在组件的 `updatePointer` 里。

**② `intersectObjects` 的第二个参数 recursive**：物体是 Group 时，要传 `true` 才会检测它的子物体。实验室里都是直接的 Mesh，用了 `false`。
:::
