# 鼠标交互：射线拾取 Raycaster

3D 场景里，「用户点中了哪个物体」不像 2D 网页那么简单。因为屏幕是 2D 的，物体是 3D 的——需要一套专门的办法。

::: tip 大白话时间
想象你闭着眼睛，从屏幕这个「窗户」往屋里**射出一根激光笔**。激光穿过窗户，碰到第一个物体——那个就是你点中的东西。

Raycaster（射线投射器）就是这根激光笔。
:::

## 一、基本用法

```js
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

// 监听鼠标移动
window.addEventListener('pointermove', (event) => {
  // 把鼠标屏幕坐标转成 -1 ~ 1 的标准设备坐标
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

renderer.setAnimationLoop(() => {
  // 从相机出发，穿过鼠标位置射出射线
  raycaster.setFromCamera(mouse, camera);

  // 检测射线和哪些物体相交（第二个参数 true 表示检测子物体）
  const hits = raycaster.intersectObjects(scene.children, true);

  if (hits.length > 0) {
    const object = hits[0].object;  // 第一个就是最近的
    object.material.color.set(0xff0000); // 变红
  }

  renderer.render(scene, camera);
});
```

::: warning 注意
`mouse.y` 前面有个**负号**！因为屏幕坐标 Y 轴向下为正，而 Three.js 的世界坐标 Y 轴向上为正——必须翻转。忘了这个负号，点击位置会上下颠倒。
:::

### 坐标转换拆解

```js
mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
```

::: tip 大白话时间
Three.js 需要的坐标范围是 **-1 到 1**：屏幕最左边是 -1，最右边是 +1，中间是 0。

鼠标的 `clientX` 是像素值（比如 0~1920）。除以宽度得到 0~1，乘 2 得到 0~2，减 1 就变成 -1~1。

Y 轴同理，但屏幕 Y 从上往下增长，和 3D 世界相反，所以要加负号翻转。
:::

## 二、intersect 返回什么？

```js
const hits = raycaster.intersectObjects(objects);
```

返回一个数组，按**距离从近到远**排序。每个元素包含：

| 属性 | 说明 |
|---|---|
| `distance` | 射线起点到交点的距离 |
| `point` | 交点的世界坐标（Vector3） |
| `object` | 被击中的物体 |
| `face` | 被击中的三角面（含法线） |
| `uv` | 交点处的纹理坐标（做贴图交互很有用） |

## 三、悬停高亮（完整例子）

```js
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2(-10, -10); // 初始放在屏幕外
let hovered = null;

addEventListener('pointermove', e => {
  mouse.x = (e.clientX / innerWidth) * 2 - 1;
  mouse.y = -(e.clientY / innerHeight) * 2 + 1;
});

renderer.setAnimationLoop(() => {
  raycaster.setFromCamera(mouse, camera);
  const hits = raycaster.intersectObjects(clickableObjects, false);
  const current = hits.length ? hits[0].object : null;

  if (current !== hovered) {
    if (hovered) hovered.material.emissive.set(0x000000);
    if (current) current.material.emissive.set(0x333333);
    hovered = current;
    document.body.style.cursor = current ? 'pointer' : 'default';
  }

  renderer.render(scene, camera);
});
```

::: tip 小贴士
用 `emissive`（自发光）来做高亮，比直接改 `color` 好看——它是在原色上叠加光，不会破坏物体本身的材质感。

性能提示：不要在 `pointermove` 里做射线检测（鼠标移动事件可能一秒触发上百次）。像上面这样**只在动画循环里检测一次**，配合一个 `needsUpdate` 标记更好。
:::

## 四、点击拾取

```js
addEventListener('click', () => {
  raycaster.setFromCamera(mouse, camera);
  const hits = raycaster.intersectObjects(clickableObjects);
  if (hits.length) {
    console.log('你点了：', hits[0].object.name);
  }
});
```

::: tip 大白话时间
「悬停高亮」和「点击拾取」原理完全一样，只是触发时机不同。

实际项目里，把可点击的物体放进一个单独的数组（`clickableObjects`），而不是每次都检测 `scene.children`——这样更快，也避免误中地面、灯光这些不该点的东西。
:::

### 深一层：userData——把「点中」变成「业务事件」

上面拿到的是 `object`——一个 3D 物体。但实际业务里你要的是「设备编号」「商品 ID」「楼层信息」。这就是 `userData` 的用武之地：它是每个 Object3D 自带的一个普通对象，专门给你挂自定义数据。

```js
// 建设备时把业务数据挂上去
const pump = new THREE.Mesh(geometry, material);
pump.userData = {
  id: 'PUMP-01',
  name: '一号循环泵',
  type: 'pump',
  status: 'running'
};
scene.add(pump);

// 拾取时直接读出来
const hits = raycaster.intersectObjects(clickableObjects, false);
if (hits.length) {
  const info = hits[0].object.userData;
  showDetailPanel(info); // { id: 'PUMP-01', name: '一号循环泵', ... }
}
```

::: tip 大白话时间
`userData` 就是给 3D 物体**贴的快递单**。

屏幕上你看到的是一个泵的模型，快递单上写着「这是 PUMP-01，一号循环泵」。用户点模型时，你不是把模型交给业务代码，而是**把快递单撕下来交给它**——后面的详情面板、报警联动、跳转路由就都能对上号了。
:::

**GLTF 模型的坑：数据常常挂在父节点上。**

从 Blender 导出的模型通常是多层嵌套，`userData` 可能写在根节点，但射线命中的是某个子 Mesh。这时候要沿着父链往上找：

```js
function findUserData(object) {
  let current = object;
  while (current) {
    if (current.userData?.id) return current.userData;
    current = current.parent;
  }
  return null;
}

const info = findUserData(hits[0].object);
if (info) showDetailPanel(info);
```

::: danger Vue3 项目特别注意
**不要把 Vue 的响应式代理塞进 `userData`。** three.js 内部会大量读写这些对象，Proxy 会带来性能损耗，还可能因为循环引用导致 `JSON.stringify()` 直接报错。

```js
import { markRaw } from 'vue'

mesh.userData = markRaw({ id: 'PUMP-01', status: 'running' })
```

另外 `userData` 里只放**纯数据**（字符串、数字、普通对象），不要放 DOM 元素、Vue 组件实例、Three.js 的 Object3D 引用。
:::

数字孪生项目里这套组合用得最多：`userData.id` → 查 Pinia 里的设备状态 → 右侧面板高亮。完整链路见[「点击设备查看详情」](</10-数字孪生与数字工厂/04 · 点击设备查看详情>)。

## 五、射线其他用法

```js
// 设置射线的起点和方向（不从相机出发）
raycaster.set(origin, direction);

// 限制检测距离
raycaster.near = 0;
raycaster.far = 10;

// 只检测某一类物体：用 Layers
raycaster.layers.set(1);
mesh.layers.enable(1);
```

::: tip 小贴士
射线拾取还能做很多事：
- **角色贴地**：从角色脚底向下发射线，检测地面高度
- **射击游戏**：从枪口发射线，判断是否命中敌人
- **测量工具**：点击两点，计算距离
:::
