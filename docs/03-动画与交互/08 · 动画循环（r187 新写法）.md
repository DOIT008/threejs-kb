# 动画循环

3D 动画的原理和电影一模一样：**快速播放一张张静止画面，骗过你的眼睛。**

::: tip 大白话时间
电影每秒 24 帧，Three.js 通常每秒 60 帧（跟屏幕刷新率一致）。

每一帧做的事都一样：**改一点数据 → 重新画一遍**。只要够快，你的大脑就觉得它在动。
:::

## 一、推荐写法：setAnimationLoop + Timer

这是 r187 官方推荐的方式（新版例子全都这么写）：

```js
import * as THREE from 'three';

const timer = new THREE.Timer();

renderer.setAnimationLoop(() => {
  timer.update();                       // 先更新计时器
  const delta = timer.getDelta();       // 距上一帧过了多少秒
  const elapsed = timer.getElapsed();   // 总共过了多少秒

  cube.rotation.y += 1 * delta;         // 每秒转 1 弧度
  ball.position.y = Math.sin(elapsed) * 0.5;

  renderer.render(scene, camera);
});
```

### 为什么用 setAnimationLoop？

```js
// 老写法（还能用，但不推荐）
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();

// 新写法
renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
```

| 对比 | requestAnimationFrame | setAnimationLoop |
|---|---|---|
| 自动跟随屏幕刷新率 | ✅ | ✅ |
| 切到后台自动暂停 | ✅ | ✅ |
| 支持 WebXR（VR/AR） | ❌ 要自己处理 | ✅ 原生支持 |
| 停止动画 | 要自己管状态 | `renderer.setAnimationLoop(null)` |

::: tip 小贴士
`Timer` 在 r179 之前是独立扩展，r179 起已进入核心库，`import * as THREE from 'three'` 就能直接用 `THREE.Timer`。
:::

## 二、关于 Clock（老教程里的常客）

你会在大量老教程里看到：

```js
const clock = new THREE.Clock();
const delta = clock.getDelta();
const elapsed = clock.getElapsedTime();
```

::: warning 注意
`Clock` 在 **r183 已被标记为废弃（deprecated）**，r187 仍能运行，但控制台可能给警告。新代码请直接用 `Timer`：

| 旧 API | 新 API |
|---|---|
| `new THREE.Clock()` | `new THREE.Timer()` |
| `clock.getDelta()` | `timer.getDelta()` |
| `clock.getElapsedTime()` | `timer.getElapsed()` |
| （无需） | `timer.update()` 每帧调用 |

如果用 `Timer` 时切到后台再回来发现物体「瞬移」了，可以加上 `timer.connect(document)` 恢复旧版的页面可见性处理。
:::

## 三、为什么要乘 delta？

按「帧」改数据有个大问题：**60 帧的电脑和 30 帧的电脑，物体速度差一倍。**

```js
// ❌ 按帧算：不同设备速度不同
cube.rotation.y += 0.01;

// ✅ 按时间算：所有设备速度一致
cube.rotation.y += 1 * delta; // 每秒转 1 弧度
```

::: tip 大白话时间
`delta` 就是「这一帧花了多久」。帧率高它就小，帧率低它就大。乘上它，速度就恒定——

**快的电脑多走几小步，慢的电脑少走几大步，最后走的距离一样。**

这是做流畅动画的关键，一定要养成习惯。
:::

## 四、常用动画公式

```js
// 匀速旋转
mesh.rotation.y += delta;

// 上下浮动（正弦波）
mesh.position.y = Math.sin(elapsed * 2) * 0.5;

// 呼吸缩放
const s = 1 + Math.sin(elapsed * 3) * 0.1;
mesh.scale.setScalar(s);

// 绕圈走
mesh.position.x = Math.cos(elapsed) * 5;
mesh.position.z = Math.sin(elapsed) * 5;

// 摆锤
mesh.rotation.z = Math.sin(elapsed * 2) * 0.5;
```

::: tip 大白话时间
`Math.sin()` 的输出在 -1 到 1 之间来回摆动，画出来就是一条波浪线。

把这个波浪值乘上幅度、加到位置上，物体就「来回动」了。`sin(elapsed * 2)` 里的 2 是速度——数字越大摆得越快。
:::

## 五、缓动动画（Tween）

想让物体「慢慢加速再慢慢停下」，光靠 sin 不够。手动实现 easing：

```js
// 缓入缓出：从 0 平滑到 1，再平滑回到 0
const easeInOut = t => t < 0.5 ? 2*t*t : 1 - Math.pow(-2*t + 2, 2) / 2;

// 在 2 秒内从 A 移动到 B
let progress = 0;
renderer.setAnimationLoop(() => {
  timer.update();
  progress = Math.min(timer.getElapsed() / 2, 1);
  const t = easeInOut(progress);
  mesh.position.x = THREE.MathUtils.lerp(0, 5, t); // 插值
  renderer.render(scene, camera);
});
```

::: tip 小贴士
项目里做复杂动画，建议用专门的补间库，比如 **GSAP** 或 **TWEEN.js**（`@tweenjs/tween.js`）。它们提供了几十种缓动曲线、时间轴、序列动画，比手写舒服得多。
:::

## 六、性能注意

- **别在动画循环里 `new` 对象**！每帧创建 `new THREE.Vector3()`、`new THREE.Color()` 会让垃圾回收器忙死

```js
// ❌ 糟糕
function animate(){
  mesh.position = new THREE.Vector3(x, y, z); // 每帧都 new
}

// ✅ 正确
const pos = new THREE.Vector3(); // 循环外创建一次
function animate(){
  pos.set(x, y, z);
  mesh.position.copy(pos);
}
```

- 用 `THREE.MathUtils.lerp()` 做插值，别自己写浮点运算
- 静态物体不要放在循环里反复赋值
