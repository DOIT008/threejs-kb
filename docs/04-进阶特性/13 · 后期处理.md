# 后期处理：给画面加滤镜

后期处理（Post-processing）就是：**先把场景渲染成一张图，再对这张图做加工，最后显示出来。**

::: tip 大白话时间
就像手机拍照：拍完还能加滤镜、磨皮、调色、加暗角。

Three.js 里也一样——画面先渲染到一张「离屏画布」，然后一串「滤镜」依次处理，最后才输出到屏幕。发光、景深、描边这些效果都靠它。
:::

## 一、EffectComposer 基础套装

```js
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

// 1. 创建合成器
const composer = new EffectComposer(renderer);

// 2. 第一个 Pass：渲染场景（必须有）
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// 3. 中间可以加各种效果 Pass
// composer.addPass(bloomPass);

// 4. 最后一个 Pass：输出到屏幕（r152+ 推荐加上）
const outputPass = new OutputPass();
composer.addPass(outputPass);

// 渲染时用 composer，不用 renderer
renderer.setAnimationLoop(() => {
  composer.render();
});
```

::: warning 注意
用了 `EffectComposer` 后，要调用 `composer.render()` 而不是 `renderer.render()`。

r152 之后要加 `OutputPass` 做最终的颜色空间转换和色调映射——少了它画面会偏暗或偏亮。
:::

## 二、泛光 Bloom（最常用）

让画面中明亮的部分「发光」，霓虹灯、能量条、发光按钮全靠它：

```js
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(innerWidth, innerHeight),
  1.5,   // strength 强度
  0.4,   // radius 半径（光晕扩散范围）
  0.85   // threshold 阈值（亮度超过这个值的才发光）
);
composer.addPass(bloomPass);
```

::: tip 大白话时间
`threshold` 是关键：它决定「多亮才算亮」。

设 0.85，只有画面中最亮的 15% 区域会发光。想让更多东西发光，把 threshold 调低；想只让特别亮的部分发光，调高。

配合 `MeshBasicMaterial` 用纯白/亮色材质做发光物体，效果最好。
:::

### 选择性泛光（高级）

让只有特定物体发光，其他不发光——用两层场景渲染 + 亮度差合成。代码较长，官方示例 `webgl_postprocessing_unreal_bloom_selective.html` 有完整实现。

## 三、其他常用 Pass

```js
// 景深：模拟相机对焦，远处模糊
import { BokehPass } from 'three/addons/postprocessing/BokehPass.js';
const bokeh = new BokehPass(scene, camera, {
  focus: 10,      // 对焦距离
  aperture: 0.025,// 光圈（越大背景越糊）
  maxblur: 0.01
});

// 描边：给物体加轮廓线
import { OutlinePass } from 'three/addons/postprocessing/OutlinePass.js';
const outline = new OutlinePass(new THREE.Vector2(w, h), scene, camera);
outline.selectedObjects = [selectedMesh]; // 要描边的物体
outline.edgeStrength = 3;
outline.edgeGlow = 1;
outline.visibleEdgeColor.set('#42b883');

// FXAA / SMAA：抗锯齿
import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';
import { FXAAShader } from 'three/addons/shaders/FXAAShader.js';
const fxaa = new ShaderPass(FXAAShader);
fxaa.material.uniforms['resolution'].value.set(1/w, 1/h);

// 胶片颗粒、色调、暗角等
import { FilmPass } from 'three/addons/postprocessing/FilmPass.js';
const film = new FilmPass(0.35, 0.025, 648, false);
```

| Pass | 效果 | 性能开销 |
|---|---|---|
| UnrealBloomPass | 发光 | 中高 |
| BokehPass | 景深 | 高 |
| OutlinePass | 描边 | 中 |
| FXAAShader | 抗锯齿 | 低 |
| FilmPass | 胶片颗粒 | 低 |
| GlitchPass | 故障特效 | 低 |

## 四、性能建议

::: tip 大白话时间
后期处理是**逐像素**操作的——每个 Pass 都要把整张图过一遍。1920×1080 的屏幕有 200 多万个像素，串 5 个 Pass 就是 1000 万次计算。

所以：**效果要克制，别堆太多 Pass。** 两个就够了，多了手机直接卡死。
:::

- Pass 数量控制在 2~3 个以内
- 移动端可以动态关闭后期处理
- 用 `composer.setSize()` 处理窗口变化
- 低性能设备可以降低渲染分辨率：`renderer.setPixelRatio(1)`
