# 纹理贴图：让物体有细节

纯色材质看多了会腻。真实世界有木纹、金属划痕、布料的纤维——这些靠**纹理（Texture）**实现。

::: tip 大白话时间
材质（Material）决定物体「是什么料子」，纹理（Texture）就是往料子上**印的图案**。

比如一个木头箱子：Material 说「这是木头，粗糙，不反光」，Texture 说「表面有年轮纹路」。两者配合才有真实感。
:::

## 一、加载图片纹理

```js
const loader = new THREE.TextureLoader();

// 方式一：回调
loader.load('/textures/wood.jpg', (texture) => {
  material.map = texture;
  material.needsUpdate = true; // 重要！改了贴图要通知材质更新
});

// 方式二：先创建空纹理，加载完自动填充
const texture = loader.load('/textures/wood.jpg');
const material = new THREE.MeshStandardMaterial({ map: texture });
```

::: warning 注意
图片路径在 `file://` 下通常加载失败——又是本地服务器的问题。用 Live Server 或 Vite 就不会有这个问题。

加载跨域图片时，对方服务器必须允许 CORS，否则会报错。可以设 `loader.setCrossOrigin('anonymous')`。
:::

## 二、常见贴图类型

```js
const material = new THREE.MeshStandardMaterial({
  map: colorTexture,           // 颜色贴图（基础色）
  normalMap: normalTexture,    // 法线贴图（凹凸细节，不改几何体）
  roughnessMap: roughTexture,  // 粗糙度贴图（哪里亮哪里哑）
  metalnessMap: metalTexture,  // 金属度贴图
  aoMap: aoTexture,            // 环境光遮蔽（缝隙变暗）
  emissiveMap: glowTexture,    // 自发光贴图
  displacementMap: dispTexture,// 位移贴图（真的改变顶点，很贵）
  alphaMap: alphaTexture       // 透明度贴图
});
```

::: tip 大白话时间
最常用的是前三个：

- **map（颜色贴图）**：就是「印上去的画」
- **normalMap（法线贴图）**：骗眼睛用的——几何体还是光滑的，但光照计算时假装表面有凹凸。比真的建模便宜太多，游戏里的砖墙、皮肤纹理都靠它
- **roughnessMap（粗糙度贴图）**：让同一物体有的地方反光、有的地方不反光，比如旧金属上的锈斑
:::

### 法线贴图示例

```js
const loader = new THREE.TextureLoader();
const colorMap = loader.load('/brick_color.jpg');
const normalMap = loader.load('/brick_normal.jpg');

colorMap.colorSpace = THREE.SRGBColorSpace;  // 颜色贴图要设 sRGB
// normalMap 不用设，保持线性空间（默认）

const wall = new THREE.Mesh(
  new THREE.PlaneGeometry(10, 5),
  new THREE.MeshStandardMaterial({
    map: colorMap,
    normalMap: normalMap,
    normalScale: new THREE.Vector2(1, 1) // 凹凸强度
  })
);
```

::: warning 注意
**颜色贴图**（map）要设置 `colorSpace = THREE.SRGBColorSpace`，否则颜色会偏暗/偏亮。

**数据贴图**（normalMap、roughnessMap 等）不要设置——它们是数学数据，不是颜色，用线性空间才对。
:::

### 深一层：色彩管理全链路

上面那条规则很多人是「背下来」的，可一到项目中还是对不上设计稿。原因是色彩管理不是某一个参数，而是**一条从输入到输出的链路**，任何一环错了，最后颜色都会偏。

::: tip 大白话时间
把整条链路想成**洗照片**：

- 你拍的 RAW 原片（sRGB 图片、十六进制色值）→ 先**转成线性光**，这是暗房里的「原始底片」
- 所有调色、加光（光照计算）都在这张线性底片上做，数学才干净
- 最后**冲印成照片**给屏幕看 → 再转回 sRGB

如果在「底片」阶段就拿着冲印好的照片继续修，修一次偏一次。Three.js 里那些 `colorSpace` 设置，本质上就是在说「这张图是底片还是照片」。
:::

链路上的每个环节各管一段：

| 环节 | 谁负责 | 正确设置 | 设错后的现象 |
| --- | --- | --- | --- |
| ① 全局开关 | `THREE.ColorManagement.enabled` | r152 起默认 `true`，别关 | 关掉后整条链路失效，颜色普遍发灰 |
| ② 代码里的色值 | `new THREE.Color()` / `setHex()` | 默认按 sRGB 输入，自动转线性 | 手动填线性值时颜色会偏暗 |
| ③ 颜色贴图 | `texture.colorSpace` | `THREE.SRGBColorSpace` | 贴图偏暗、对比过强 |
| ④ 数据贴图 | `texture.colorSpace` | `THREE.NoColorSpace`（默认） | 凹凸/粗糙度错乱，材质像塑料 |
| ⑤ 光照计算 | Three.js 内部 | 全程线性，不用管 | — |
| ⑥ 输出到屏幕 | `renderer.outputColorSpace` | `THREE.SRGBColorSpace`（默认） | 整个画面偏暗或惨白 |
| ⑦ 高光压缩 | `renderer.toneMapping` | `ACESFilmicToneMapping` + 合适 `toneMappingExposure` | 亮部死白、颜色发灰 |

**一套「不会偏色」的标准起手式：**

```js
// ① 全局色彩管理（r152+ 默认开启，写出来是为了自文档化）
THREE.ColorManagement.enabled = true;

// ⑥ 渲染器出口
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;

// ② 色值：十六进制默认按 sRGB 解释，不用手动转换
const brand = new THREE.Color(0x42b883);

// ③ 颜色贴图设 sRGB，④ 数据贴图保持默认
const colorMap = loader.load('/brick_color.jpg');
colorMap.colorSpace = THREE.SRGBColorSpace;
const normalMap = loader.load('/brick_normal.jpg');
// normalMap.colorSpace 保持 THREE.NoColorSpace，别动
```

**什么时候要 `texture.needsUpdate = true`？**

`colorSpace`、`wrapS`、`repeat`、`flipY` 这些属性改变后，需要重新上传纹理到 GPU，所以要设 `texture.needsUpdate = true`。但 **r152 之后 `colorSpace` 的修改会自动触发更新**，一般不用手动设；而运行时用 Canvas 重绘了内容（`CanvasTexture`）则必须设：

```js
ctx.fillStyle = '#ff0000';
ctx.fillRect(0, 0, 64, 64);
canvasTexture.needsUpdate = true; // 告诉 GPU：像素变了，重新传一遍
```

::: danger 后期处理时的隐藏坑
`EffectComposer` 渲染到的是 **RenderTarget**，不是屏幕，所以 `renderer.outputColorSpace` 在这一步**不生效**。正确做法是让最后一个 Pass 负责输出转换：

```js
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

composer.addPass(new RenderPass(scene, camera));
composer.addPass(new UnrealBloomPass(...));
composer.addPass(new OutputPass()); // 必须放最后：做色调映射 + sRGB 转换
```

漏掉 `OutputPass` 的画面通常会**偏暗、发灰**，而且怎么调灯光都救不回来——因为错在出口，不在入口。详见[「后期辉光实验室」](</11-交互实验室/07 · 后期辉光实验室>)。
:::

**「颜色跟设计稿对不上」排查表（按顺序查）：**

1. 贴图是颜色贴图吗？是 → `colorSpace = SRGBColorSpace`；不是 → 保持默认。
2. 用了后期处理吗？用了 → 检查末尾有没有 `OutputPass`。
3. 有没有手动改过 `renderer.outputColorSpace`？改成了 `LinearSRGBColorSpace` 就会偏暗。
4. `toneMapping` 是什么？`NoToneMapping` 下强光会死白，`ACESFilmic` 下颜色会稍微「电影感」地偏灰，这是正常的，用 `toneMappingExposure` 调。
5. 设计稿本身是 sRGB 还是 P3？浏览器按 sRGB 显示，P3 素材要先在导出时转换。

::: tip 延伸阅读
完整 API 参数见 `docs/06-API速查手册/API 05 · WebGLRenderer 全参数.md`；实际排错场景见 `docs/05-实战与排错/18 · 常见问题排错.md`。
:::

## 三、纹理的常用属性

```js
texture.wrapS = THREE.RepeatWrapping;   // 水平方向重复
texture.wrapT = THREE.RepeatWrapping;   // 垂直方向重复
texture.repeat.set(4, 4);              // 重复 4×4 次
texture.offset.set(0.5, 0);            // 偏移
texture.rotation = Math.PI / 4;        // 旋转
texture.center.set(0.5, 0.5);          // 旋转中心
texture.flipY = false;                 // 翻转 Y（某些模型格式需要）
texture.anisotropy = renderer.capabilities.getMaxAnisotropy(); // 斜视角更清晰
```

::: tip 大白话时间
`RepeatWrapping` 就像**铺瓷砖**：一张图不够大，就重复贴。

地板、墙面用这个特别合适——一张 512px 的砖块图，重复 20 次就能铺满整个地板，比用一张 10000px 的大图省内存多了。
:::

## 四、程序化生成纹理

没有图片素材？用 Canvas 画一个：

```js
const canvas = document.createElement('canvas');
canvas.width = canvas.height = 256;
const ctx = canvas.getContext('2d');

// 画个棋盘格
for (let i = 0; i < 8; i++) {
  for (let j = 0; j < 8; j++) {
    ctx.fillStyle = (i + j) % 2 ? '#ffffff' : '#42b883';
    ctx.fillRect(i * 32, j * 32, 32, 32);
  }
}

const texture = new THREE.CanvasTexture(canvas);
texture.colorSpace = THREE.SRGBColorSpace;
texture.wrapS = texture.wrapT = THREE.RepeatWrapping;
texture.repeat.set(4, 4);

const material = new THREE.MeshStandardMaterial({ map: texture });
```

::: tip 小贴士
CanvasTexture 很适合做：文字标签、动态更新内容（比如 3D 场景里显示实时数据）、简单的程序化图案。
:::

## 五、环境贴图（反射）

让金属物体反射周围环境：

```js
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

new RGBELoader().load('/hdri/studio.hdr', (texture) => {
  texture.mapping = THREE.EquirectangularReflectionMapping;
  scene.environment = texture;   // 给所有物体提供环境反射
  // scene.background = texture; // 也可以顺便当背景
});
```

::: tip 大白话时间
金属球为什么看起来是「金属」？因为它反射周围的东西。

没有环境贴图时，金属材质看起来就是一团黑或灰。`scene.environment` 给它一张「周围世界的照片」，反射立刻真实起来。

想快速看到效果，可以用 `RoomEnvironment`（Three.js 自带的示例环境）：

```js
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment()).texture;
```
:::
