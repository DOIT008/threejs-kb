# 场景、相机、渲染器详解

上一章你跑通了第一个场景。这一章把「三件套」掰开揉碎讲清楚——它们是最基础也最重要的三个概念。

::: tip 大白话时间
想象你在**拍电影**：

- **场景 Scene** = 片场，演员（物体）和道具（灯光）都待在这里
- **相机 Camera** = 摄影机，决定从哪个角度、多远的地方拍
- **渲染器 Renderer** = 摄影师 + 冲印师，把拍到的画面变成你能看到的照片

流程就是：**搭台子 → 架机器 → 出片子**。
:::

## 一、场景 Scene

### 它是什么

场景是一个**容器**，是所有 3D 物体的「根」。只有加进场景的东西，才会被渲染出来。

```js
const scene = new THREE.Scene();
scene.add(mesh);       // 加物体
scene.add(light);      // 加灯
scene.add(group);      // 加分组
```

### 常用属性

```js
// 设置背景色
scene.background = new THREE.Color(0x1a1a2e);

// 用图片当背景（需要加载纹理，后面会讲）
scene.background = texture;

// 加雾：远处的物体渐渐融进背景色
scene.fog = new THREE.Fog(0x1a1a2e, 10, 50);
//              颜色       近处   远处

// 指数雾：更自然的衰减
scene.fog = new THREE.FogExp2(0x1a1a2e, 0.02);
```

::: tip 大白话时间
`Fog(颜色, 10, 50)` 的意思是：距离相机 10 以内清晰，50 以外完全变成背景色，中间渐变。

雾有两个作用：**好看**（营造纵深）和**藏拙**（遮挡远处没做好的模型，还能提升性能——反正看不见了）。
:::

### 场景树

场景里的物体可以**嵌套**，形成一个树状结构：

```js
const scene = new THREE.Scene();

const car = new THREE.Group();       // 一辆车 = 一个组
const wheel1 = new THREE.Mesh(...);  // 四个轮子
const wheel2 = new THREE.Mesh(...);
car.add(wheel1, wheel2, ...);

scene.add(car);  // 只需把车加进场景
car.position.x = 3;  // 移动车，轮子跟着走
```

::: tip 小贴士
`Group` 本身不显示任何东西，它只是个「收纳盒」。移动/旋转 Group，里面所有子物体都会跟着动。做复杂物体（人、车、机器人）时必备。
:::

## 二、相机 Camera

### 透视相机 PerspectiveCamera

模拟人眼：**近大远小**。最常用。

```js
const camera = new THREE.PerspectiveCamera(fov, aspect, near, far);
```

| 参数 | 全称 | 大白话 | 常用值 |
|---|---|---|---|
| `fov` | field of view | 视野角度，越大看得越广（广角镜头） | 45~75 |
| `aspect` | aspect ratio | 画面宽高比，写窗口宽/窗口高 | `innerWidth/innerHeight` |
| `near` | near plane | 比这更近的东西不画 | 0.1 |
| `far` | far plane | 比这更远的东西不画 | 1000 |

::: tip 大白话时间
`fov` 就像你睁眼的大小。fov 小（比如 30）像望远镜，看到的范围窄但物体显得大；fov 大（比如 90）像鱼眼镜头，看到的范围广但边缘会变形。

游戏里常用 60~75，产品展示常用 35~50（不会变形得太夸张）。
:::

::: warning 注意
`near` 和 `far` 的比值别太夸张（比如 `near=0.0001, far=1000000`），会导致**深度精度不足**，物体表面一闪一闪的（z-fighting）。实践中 `near=0.1, far=1000` 这种比例就很安全。
:::

### 正交相机 OrthographicCamera

**没有近大远小**，所有物体大小一致。做等距视角游戏、工程图纸、2D 游戏时用。

```js
const camera = new THREE.OrthographicCamera(
  -5, 5,   // 左、右边界
  5, -5,   // 上、下边界
  0.1, 100 // 近、远
);
```

| 相机 | 特点 | 用途 |
|---|---|---|
| 透视相机 | 近大远小，有纵深感 | 大多数 3D 场景 |
| 正交相机 | 大小恒定，无透视 | 工程图、等距游戏、UI |

### 相机的常用操作

```js
camera.position.set(5, 3, 8);       // 放到某个位置
camera.lookAt(0, 0, 0);             // 看向某个点
camera.position.y += 1;             // 移动相机
camera.rotation.z = Math.PI / 4;    // 直接转（一般不推荐）
camera.zoom = 2;                    // 缩放（正交相机常用）
camera.updateProjectionMatrix();    // 改完参数记得调用
```

::: tip 大白话时间
`lookAt(0,0,0)` 就是命令相机：「盯着原点看」。

除非你要做第一人称游戏，否则**别手动改 rotation**——用 `lookAt()` 让相机自动对准目标，简单又不容易晕。想让用户自己转视角？用 `OrbitControls`（后面会讲），那是专门干这个的。
:::

## 三、渲染器 WebGLRenderer

### 创建与配置

```js
const renderer = new THREE.WebGLRenderer({
  antialias: true,    // 抗锯齿，边缘更平滑（推荐开）
  alpha: true,        // 背景透明，能看到后面的 HTML
  powerPreference: 'high-performance'
});

renderer.setSize(width, height);       // 画布尺寸
renderer.setPixelRatio(Math.min(devicePixelRatio, 2)); // 适配高清屏
renderer.setClearColor(0x000000, 1);   // 背景色（scene.background 会覆盖它）
document.body.appendChild(renderer.domElement);
```

### `setPixelRatio` 是干嘛的？

::: tip 大白话时间
Retina 屏（苹果高清屏）上一个 CSS 像素对应 2~3 个物理像素。如果不特别设置，画面在高清屏上会**发虚**。

`setPixelRatio(devicePixelRatio)` 就是按屏幕的真实像素密度来渲染，画面更清晰。

为什么要 `Math.min(..., 2)` 限制上限？因为 3 倍像素意味着 9 倍的计算量，手机会卡死。限制到 2 是清晰度和性能的平衡点。
:::

### 阴影设置

```js
renderer.shadowMap.enabled = true;                      // 总开关
renderer.shadowMap.type = THREE.PCFShadowMap;            // 柔和阴影（r182 起 PCFShadowMap 本身就是柔化的，PCFSoftShadowMap 已移除）
```

注意：光了这一行还不够，灯和物体都要分别设置（详见[「光照」](</02-核心概念/07 · 光照与阴影>)那章）。

### 色彩与色调映射

```js
renderer.outputColorSpace = THREE.SRGBColorSpace;  // 新版默认就是
renderer.toneMapping = THREE.ACESFilmicToneMapping; // 电影级色调映射
renderer.toneMappingExposure = 1.0;                 // 曝光度
```

::: tip 小贴士
如果你觉得画面「灰蒙蒙的」「不够通透」，试试加上 `ACESFilmicToneMapping`，通常能立刻提升质感。这是很多 Three.js 作品的「秘密武器」。
:::

## 三者如何配合

一次渲染的完整流程：

```text
1. 你把物体 add 到 scene
2. 你设置好 camera 的位置和角度
3. 调用 renderer.render(scene, camera)
4. 渲染器遍历场景树，把能看见的东西画成图片
5. 图片显示在 canvas 上
```

::: tip 大白话时间
`renderer.render(scene, camera)` 这一行，翻译成人话就是：

**「以这台相机的视角，把那个场景拍下来，画到屏幕上。」**

Every frame 都拍一张，快速连播，就成了动画。所有 Three.js 程序，归根结底都是这一行。
:::
