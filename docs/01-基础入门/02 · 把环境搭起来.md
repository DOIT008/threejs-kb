# 把环境搭起来

写代码之前，先让 Three.js 能在浏览器里跑起来。这里给两种方式：**CDN**（最快）和 **npm**（正经项目用）。

## 方式一：CDN，三分钟跑起来

新建一个 `index.html`，把下面这段贴进去：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的第一个 Three.js</title>
  <style>
    body { margin: 0; overflow: hidden; }
    canvas { display: block; }
  </style>
</head>
<body>
  <script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
    }
  }
  </script>
  <script type="module">
    import * as THREE from 'three';
    console.log('Three.js 加载成功，版本：', THREE.REVISION);
  </script>
</body>
</html>
```

然后在 VS Code 里装一个 **Live Server** 插件，右键文件选择「Open with Live Server」。浏览器会自动打开，按 F12 打开控制台，能看到版本号就说明成功了。

::: warning 注意
**别直接双击 HTML 文件打开！** 浏览器对 `file://` 开头的本地文件有安全限制，`type="module"` 的脚本很可能加载失败，控制台会报 CORS 错误。一定要用本地服务器。

如果你不想装插件，也可以在目录里执行 `npx serve` 或 `python -m http.server 8000`，然后访问 `http://localhost:8000`。
:::

### `importmap` 是个啥？

::: tip 大白话时间
以前用第三方库，得去网上下载一个 `.js` 文件，放到项目里，再写 `<script src="...">` 引入。麻烦。

`importmap` 就像是给浏览器一张**地址簿**：你代码里写 `import ... from 'three'`，浏览器一查地址簿——哦，`three` 对应的是 unpkg 上那个网址，去那儿拿。

于是**不用下载、不用打包工具、不用构建**，直接就能写 `import` 语句。浏览器原生支持，现代浏览器全都能用。
:::

注意这里配了两条映射：

| 映射 | 作用 |
|---|---|
| `"three"` | 核心库，写 `import * as THREE from 'three'` 时用 |
| `"three/addons/"` | 官方扩展（控制器、加载器等），写 `import { OrbitControls } from 'three/addons/controls/OrbitControls.js'` 时用 |

::: tip 关于版本
本知识库统一使用**当前最新版 r187**（npm 包 `three@0.187.0`，2026 年 10 月发布）。Three.js 没有传统意义上的「大版本」，每次发布叫一个 **revision（修订版）**——GitHub 上标 `r187`，npm 上对应 `0.187.x`，代码里用 `THREE.REVISION` 能读到当前版本号（字符串 `"187"`）。

它大约每 1~3 个月发一次版，偶尔会有破坏性改动（比如 r183 用 `Timer` 取代了 `Clock`，r186 移除了 `PCFSoftShadowMap`）。本知识库已按 r187 的写法更新；锁定版本是为了避免 API 变动带来的意外，等熟悉了再升级也不迟。
:::

## 方式二：npm + Vite（正经项目用）

真要长期做项目，用 npm 管理依赖更靠谱：

```bash
# 创建项目
npm create vite@latest my-three-app
cd my-three-app

# 安装依赖
npm install
npm install three

# 启动开发服务器
npm run dev
```

然后 `src/main.js` 里写：

```js
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

console.log('版本：', THREE.REVISION);
```

### Vite 项目结构

```text
my-three-app/
├── index.html
├── package.json
├── src/
│   ├── main.js        ← 你的 Three.js 代码
│   └── style.css
└── node_modules/      ← npm 装的依赖（包括 three）
```

::: tip 大白话时间
Vite 就是个**本地开发服务器 + 打包工具**。它帮你干两件事：

1. 你改代码，浏览器自动刷新（热更新）
2. 项目做完要上线时，它能把代码压缩打包成一堆小文件

小 demo 用 CDN 就够了；项目一大、文件一多，Vite 就香了。
:::

## 两种方式怎么选？

| 场景 | 推荐 |
|---|---|
| 学习、做 demo、写代码片段 | CDN + importmap |
| 正式项目、要上线、代码分文件 | npm + Vite |
| 想用 TypeScript | npm + Vite |

::: tip 小贴士
本知识库的所有例子，**两种方式都能跑**。用 CDN 的话把例子放进 `<script type="module">`；用 Vite 的话放进 `main.js`。
:::

## 检查是否成功

在控制台输入：

```js
THREE.REVISION
```

能输出 `"187"`（对应 r187）就说明环境没问题。如果数字不一样，说明你用了别的版本——代码大体通用，但遇到 API 对不上时记得核对版本。
