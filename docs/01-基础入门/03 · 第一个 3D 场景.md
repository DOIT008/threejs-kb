# 第一个 3D 场景

废话不多说，先上能跑的代码。把上一章环境里的 `import` 部分换成下面这段，刷新页面：

```js
import * as THREE from 'three';

// 1. 场景：装东西的大盒子
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

// 2. 相机：观众的眼睛
const camera = new THREE.PerspectiveCamera(
  75,                                     // 视野角度
  window.innerWidth / window.innerHeight, // 宽高比
  0.1,                                    // 最近能看到哪
  1000                                    // 最远能看到哪
);
camera.position.z = 5;

// 3. 渲染器：把画面画到屏幕上
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// 4. 造一个立方体
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x42b883 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 5. 不停地把画面画出来
renderer.setAnimationLoop(() => {
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
});
```

看到**一个绿色立方体在转**了吗？恭喜，你已经进入 3D 世界了。

## 逐行拆解

### 第 1 步：场景

```js
const scene = new THREE.Scene();
```

场景就是一个**空盒子**，所有要显示的东西都得 `scene.add(xxx)` 加进去。

### 第 2 步：相机

```js
const camera = new THREE.PerspectiveCamera(75, aspect, 0.1, 1000);
camera.position.z = 5;
```

创建了「透视相机」，四个参数后面会详细讲。这里只需要知道：`z = 5` 表示**相机往后退了 5 步**。为什么要退？因为物体默认在原点 `(0,0,0)`，相机也在原点的话，就等于贴在物体脸上，什么都看不见。

::: tip 大白话时间
想象你站在客厅正中央，脸贴着墙——你能看到墙吗？只能看到一片糊。

同理，相机和物体必须**拉开距离**。往后退 5 步，正好能看到整个立方体。
:::

### 第 3 步：渲染器

```js
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
```

渲染器负责把 3D 场景算成 2D 图片。它内部会创建一个 `<canvas>` 元素，`renderer.domElement` 就是这个 canvas。第三行把它塞进页面，你才能看见。

::: warning 注意
忘了 `appendChild(renderer.domElement)` 是新手最常犯的错误之一——代码没错，但页面上什么都没有，因为画布根本没加到页面里。
:::

### 第 4 步：造物体

```js
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x42b883 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

三行对应三件事：

| 代码 | 大白话 |
|---|---|
| `BoxGeometry(1,1,1)` | 造一个 1×1×1 的立方体**形状** |
| `MeshBasicMaterial(...)` | 做一件绿色的**外衣** |
| `new THREE.Mesh(形状, 外衣)` | 把形状和外衣**组合成物体** |
| `scene.add(cube)` | 把物体**放进场景** |

### 第 5 步：动画循环

```js
renderer.setAnimationLoop(() => {
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
});
```

`setAnimationLoop` 会让浏览器**每秒调用这个函数约 60 次**。每次做两件事：

1. 把立方体稍微转一点
2. 重新画一遍画面

::: tip 关于写法
老教程里常见的是 `requestAnimationFrame` 自己写循环。r187 官方推荐用 `renderer.setAnimationLoop()`——更简洁，而且原生支持 VR/AR。详细的动画章节会讲。
:::

::: tip 大白话时间
这就是**翻页动画**：你小时候可能在书角画过小人在跑，快速翻页他就动起来了。

Three.js 就是那个「翻页」的人——每秒翻 60 页，每页把立方体转 0.01 弧度。你的眼睛觉得它在连续旋转，其实它是 60 张静态图。
:::

### 深一层：`renderer.render()` 这一行里发生了什么

你现在能写出这 5 步了，但 `renderer.render(scene, camera)` 到底干了啥？知道个大概，以后遇到「物体突然消失」「改了参数没反应」就不会一脸懵。

每调用一次 `render()`，Three.js 内部大致做四件事：

| 顺序 | 内部动作 | 用大白话说 |
| --- | --- | --- |
| 1 | 更新场景矩阵 | 从根节点往下，算出每个物体「在世界里到底在哪」——`scene.add(cube)` 只是登记，位置要这一步才算出来 |
| 2 | 视锥剔除 | 判断每个物体在不在相机视野内，不在就跳过（所以物体跑到相机背后就不画了） |
| 3 | 排序 | 透明物体按距离从远到近排，不透明物体按材质分组——为了减少 GPU 状态切换 |
| 4 | 提交绘制 | 把几何体和材质交给 GPU，发出 draw call，屏幕上一个立方体出现了 |

::: tip 大白话时间
`render()` 就像**导演喊开机**：

1. 先确认每个演员站在哪（更新矩阵）
2. 镜头拍不到的演员先休息（视锥剔除）
3. 按出场顺序排好队（排序）
4. 喊「Action！」（draw call）

你写的那 5 行代码是在**搭舞台和选演员**，`render()` 才是真正开机拍摄。
:::

**这解释了三个常见疑惑：**

- **为什么改了 `cube.position.x` 立刻生效？** 因为下一帧的第 1 步会重新算矩阵，你不用手动通知。
- **为什么物体跑到屏幕外就不见了？** 第 2 步把它剔除了。如果你逐帧改顶点位置却没更新包围球，就会「明明还在视野里却被剔除」——粒子系统那章专门讲这个。
- **为什么一万个独立 Mesh 会卡？** 第 4 步每个 Mesh 至少一次 draw call，一万个就是一万次。所以才有 `InstancedMesh`。

::: warning 一次只画一帧会怎样？
把 `setAnimationLoop` 删掉、只留一句 `renderer.render(scene, camera)`，你还是能看到立方体——只是它不会转。

这说明「渲染」和「动画」是两件事：`render()` 负责画一帧，循环负责不停地画。
:::

## 试试改几个数

亲手改改下面这些数字，看效果变化，比看十遍理论管用：

| 改哪里 | 变成什么 | 效果 |
|---|---|---|
| `BoxGeometry(1,1,1)` 改成 `(2,1,1)` | 宽变成 2 | 立方体变成扁的长方体 |
| `0x42b883` 改成 `0xff0000` | 颜色变红 | 红色立方体 |
| `0.01` 改成 `0.05` | 转得更快 | 快速旋转 |
| `camera.position.z = 5` 改成 `10` | 相机退更远 | 立方体变小 |
| 删掉 `cube.rotation.x += 0.01` | 不绕 X 轴转 | 只绕 Y 轴转 |

## 窗口大小变化时

现在缩放浏览器窗口，画面会被拉伸变形。加上这段就好了：

```js
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});
```

::: tip 小贴士
`camera.updateProjectionMatrix()` 这行千万别忘！改了相机参数后必须调用它，否则改动不生效。这是新手最容易漏掉的一行代码。
:::

## 小结

你已经掌握了 Three.js 最核心的流程：

```text
创建场景 → 创建相机 → 创建渲染器 → 往场景里加物体 → 循环渲染
```

后面所有复杂的项目，本质上都是在这五步上添砖加瓦。
