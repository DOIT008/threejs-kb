# 光照与阴影

除了 `MeshBasicMaterial` 那种「自发光」材质，其他材质**没有光就什么都看不见**。

::: tip 大白话时间
想象你在一个全黑的房间里：就算放一头大象在面前，你也看不见。

Three.js 的世界默认就是**全黑房间**。你得像拍电影一样，自己布光。
:::

## 一、常用灯光

### 1. AmbientLight 环境光 —— 打底的

```js
const ambient = new THREE.AmbientLight(0xffffff, 0.5);
scene.add(ambient);
```

从**四面八方均匀照射**，没有方向，不产生阴影。作用是「别让暗面死黑」。

### 2. HemisphereLight 半球光 —— 天空 + 地面

```js
const hemi = new THREE.HemisphereLight(
  0x87ceeb,  // 天空色（蓝）
  0x8b5a2b,  // 地面色（棕）
  1.0        // 强度
);
scene.add(hemi);
```

从上方是天空色，从下方是地面色。户外场景神器，比环境光自然得多。

### 3. DirectionalLight 平行光 —— 太阳

```js
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(5, 10, 5);
scene.add(sun);
```

光线**互相平行**，像太阳（无限远）。适合做主光源。

### 4. PointLight 点光源 —— 灯泡

```js
const bulb = new THREE.PointLight(0xffaa00, 50, 20, 2);
//                                颜色   强度 距离 衰减
bulb.position.set(0, 3, 0);
scene.add(bulb);
```

从一个点向四周发散，离得越远越暗。第二个参数是强度，第三个是照射距离（0 = 无限远）。

::: warning 注意
r155 之后 Three.js 启用了**物理正确光照**，PointLight/SpotLight 的强度数值感觉和老版本完全不同（需要更大的值，比如 50、100）。如果你按老教程写 `intensity: 1` 发现太暗，别怀疑自己——把数值调大就行。
:::

### 5. SpotLight 聚光灯 —— 舞台灯

```js
const spot = new THREE.SpotLight(0xffffff, 100);
spot.position.set(0, 10, 0);
spot.angle = Math.PI / 6;     // 光锥张角
spot.penumbra = 0.3;          // 边缘柔化（0~1）
spot.distance = 30;
spot.decay = 2;
spot.target.position.set(0, 0, 0); // 照向哪里
scene.add(spot, spot.target);
```

### 6. RectAreaLight 面光源 —— 灯管/柔光箱

```js
import { RectAreaLightUniformsLib } from 'three/addons/lights/RectAreaLightUniformsLib.js';
RectAreaLightUniformsLib.init(); // 必须初始化！

const rect = new THREE.RectAreaLight(0xffffff, 5, 4, 2); // 颜色、强度、宽、高
rect.position.set(0, 5, 5);
rect.lookAt(0, 0, 0);
scene.add(rect);
```

一块矩形在发光，能产生很漂亮的柔和高光，适合拍产品。

| 灯 | 大白话 | 能投影吗 | 性能 |
|---|---|---|---|
| AmbientLight | 阴天天光 | ❌ | 极低 |
| HemisphereLight | 天空+地面反光 | ❌ | 低 |
| DirectionalLight | 太阳 | ✅ | 中 |
| PointLight | 灯泡 | ✅ | 中高 |
| SpotLight | 手电筒/舞台灯 | ✅ | 中高 |
| RectAreaLight | 柔光箱 | ❌ | 中 |

::: tip 关于新版本
**SunLight** 扩展（`three/addons/lights/SunLight.js`）内置级联阴影（cascaded shadow maps），做大场景户外阳光时阴影质量比普通 DirectionalLight 好很多，r186 起可用、r187 继续支持。

而 **r187**（当前版本）在光照相关上的改进是：重新设计了 PMREM 环境贴图的生成方式（基于立方体渲染目标），让基于图片的照明（IBL）质量更高——配合后面「纹理」章节的 `scene.environment` 使用效果更明显。
:::

## 二、阴影

### 开阴影的四个开关

::: tip 大白话时间
阴影要同时满足四个开关，缺一个都看不到——就像拍电影要有灯、有演员、有地面才能看到影子：

1. **渲染器**打开阴影开关
2. **灯**设置 `castShadow = true`（它会投影）
3. **物体**设置 `castShadow`（它投影）和**接收面**设置 `receiveShadow`（它上面出现影子）
:::

```js
// 1. 渲染器
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFShadowMap; // r187 推荐，本身就是柔化的

// 2. 灯
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);  // 阴影贴图分辨率，越高越清晰越吃性能
sun.shadow.camera.near = 0.5;
sun.shadow.camera.far = 50;
sun.shadow.camera.left = -10;
sun.shadow.camera.right = 10;
sun.shadow.camera.top = 10;
sun.shadow.camera.bottom = -10;
sun.shadow.bias = -0.0001;           // 消除Shadow acne（表面条纹）

// 3. 物体和地面
cube.castShadow = true;
floor.receiveShadow = true;
```

::: warning 注意
平行光的阴影用的是**正交相机**，默认范围只有 ±5。场景大了，阴影会被裁掉——所以要调 `shadow.camera.left/right/top/bottom` 覆盖整个场景。

`shadow.bias` 设成很小的负值（如 `-0.0001`）能消除物体表面的条纹状伪影（shadow acne）。但别设太大，否则影子会和物体「脱节」（peter panning）。
:::

### 万能起手式

不知道先加什么灯？先来这一套，基本不会错：

```js
// 天空光打底
scene.add(new THREE.HemisphereLight(0xffffff, 0x444444, 1.2));

// 主光（太阳）
const sun = new THREE.DirectionalLight(0xffffff, 2.5);
sun.position.set(5, 10, 7);
sun.castShadow = true;
scene.add(sun);

// 补光（从反面照亮暗部）
const fill = new THREE.DirectionalLight(0x88bbff, 0.6);
fill.position.set(-5, 3, -5);
scene.add(fill);
```

::: tip 大白话时间
这就是摄影里的**三点布光**：主光（塑造形体）+ 补光（提亮暗部）+ 环境光（统一基调）。

只用一盏灯，物体背面会死黑一片，看起来很「平」。加一盏弱弱的补光，立体感立刻出来。
:::

## 三、光照性能

- 每多一盏灯，着色器计算量就增加，**灯不是越多越好**
- 阴影尤其贵：每盏投影的灯都要额外渲染一遍场景
- 能用 `AmbientLight`/`HemisphereLight` 解决的，就别用投影灯
- 静态场景可以设 `light.shadow.autoUpdate = false`，阴影只算一次
- 移动端建议最多 1~2 盏投影灯
