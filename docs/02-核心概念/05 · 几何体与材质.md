# 几何体与材质：万物皆网格

Three.js 里你能看见的实体，几乎都是 **Mesh（网格）**。一个 Mesh 由两样东西拼出来：

> **Mesh = Geometry（几何体，长什么样）+ Material（材质，表面是什么感觉）**

::: tip 大白话时间
**Geometry 是骨架，Material 是衣服。**

同一个骨架，穿上红衣服就是红球，穿上金属衣服就是钢球。骨架管形状，衣服管长相。

所以造物体永远分三步：造形状 → 做材质 → 拼起来。
:::

```js
const geometry = new THREE.SphereGeometry(1, 32, 32);
const material = new THREE.MeshStandardMaterial({ color: 0x42b883 });
const ball = new THREE.Mesh(geometry, material);
scene.add(ball);
```

## 一、内置几何体

Three.js 自带很多现成形状，直接 new 就能用：

```js
new THREE.BoxGeometry(1, 1, 1);              // 立方体：宽、高、深
new THREE.SphereGeometry(1, 32, 32);        // 球：半径、水平分段、垂直分段
new THREE.PlaneGeometry(4, 2);              // 平面：宽、高
new THREE.CylinderGeometry(1, 1, 2, 32);    // 圆柱：顶半径、底半径、高、分段
new THREE.ConeGeometry(1, 2, 32);           // 圆锥：半径、高、分段
new THREE.TorusGeometry(1, 0.4, 16, 100);   // 甜甜圈：半径、管径、管分段、环分段
new THREE.TorusKnotGeometry(1, 0.3);        // 扭结（很酷，试试就知道）
new THREE.IcosahedronGeometry(1, 0);        // 二十面体：半径、细节等级
new THREE.DodecahedronGeometry(1, 0);       // 十二面体
new THREE.OctahedronGeometry(1, 0);         // 八面体
new THREE.TetrahedronGeometry(1, 0);        // 四面体
new THREE.CircleGeometry(1, 32);            // 圆盘（2D）
new THREE.RingGeometry(0.5, 1, 32);         // 圆环（2D）
```

::: tip 小贴士
分段数（比如 `32, 32`）越大，表面越圆滑，但顶点越多、越吃性能。一般 32 就够了，球体用 48 已经很顺滑。别动不动写 1000。
:::

### 看几何体长什么样

`IcosahedronGeometry` 这类多面体有个细节等级参数：

```js
new THREE.IcosahedronGeometry(1, 0); // 20 个面，棱角分明
new THREE.IcosahedronGeometry(1, 1); // 80 个面，稍微圆一点
new THREE.IcosahedronGeometry(1, 2); // 320 个面，接近球
```

配合 `wireframe: true` 材质能看到网格结构，很适合学习：

```js
const m = new THREE.MeshBasicMaterial({ color: 0x42b883, wireframe: true });
```

## 二、BufferGeometry：自定义几何体

所有内置几何体本质都是 **BufferGeometry**——一堆顶点数据。你可以自己造：

```js
const geometry = new THREE.BufferGeometry();

// 三个顶点，每个顶点 3 个数（x, y, z）
const vertices = new Float32Array([
  -1, -1, 0,
   1, -1, 0,
   0,  1, 0
]);
geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));

// 计算法线（光照需要）
geometry.computeVertexNormals();

const mesh = new THREE.Mesh(geometry, new THREE.MeshNormalMaterial());
scene.add(mesh);
```

::: tip 大白话时间
BufferGeometry 就是**「点连成面」**。你告诉它三个点的坐标，它帮你连成一个三角形。

复杂模型（ mountains、地形）本质上就是成千上万个三角形。你以后加载的 `.glb` 模型，最后也会变成 BufferGeometry。
:::

### 深一层：运行时改顶点，三个必做动作

静态几何体建好就完事了，但波浪、布料、形变动画这些效果需要在**每一帧修改顶点**。这时有三个动作缺一不可，少一个就是"我改了数据怎么没反应"：

```js
const pos = geometry.attributes.position;

// 每帧改顶点
for (let i = 0; i < pos.count; i++) {
  const x = pos.getX(i), y = pos.getY(i);
  pos.setZ(i, Math.sin(x + time) * Math.cos(y + time) * 0.3);
}

// ① 通知 GPU：数据变了，重新上传
pos.needsUpdate = true;

// ② 重算法线：否则光照还是按旧形状算，看起来"平"的
geometry.computeVertexNormals();

// ③ 重算包围球：否则视锥剔除可能把变形后的物体误判为"画面外"而不画
geometry.computeBoundingSphere();
```

::: tip 大白话时间
把 GPU 想象成一个**只认快递单的仓库**：你在 CPU 这边改了数据，得贴上 `needsUpdate` 这张"重新发货"的标签，它才会来取。

法线是"每个面朝哪个方向"的记录——光照全靠它。你把面掰弯了却没更新法线，光还是按原来方向照，看起来就不对。

包围球是物体的"大致活动范围"标记。视锥剔除（画面外的东西不画）靠它判断。你把顶点拉远了却没更新这个范围，引擎可能以为物体还在原地，结果整个物体突然消失——这个 bug 特别隐蔽。
:::

::: warning 性能提醒
`computeVertexNormals()` 和 `computeBoundingSphere()` 都要遍历所有顶点，**顶点多时别每帧无脑调**。做法取舍：

- 顶点少（几千以内）：每帧重算没问题，代码简单
- 顶点多：法线用着色器算（顶点着色器里算波浪），或者隔几帧算一次
- 只改了一个轴、光照不敏感（如线框）：可以只做 ①，跳过 ②③

:::

## 三、常用材质

### 材质速查表

| 材质 | 特点 | 吃光照吗 | 典型用途 |
|---|---|---|---|
| `MeshBasicMaterial` | 纯色，不受光影响 | ❌ | 调试、图标、发光的物体 |
| `MeshLambertMaterial` | 漫反射，便宜 | ✅ | 低配设备、性能优先 |
| `MeshPhongMaterial` | 有高光，塑料感 | ✅ | 经典材质 |
| `MeshStandardMaterial` | 物理正确，真实感强 | ✅ | **最常用**，推荐默认选它 |
| `MeshPhysicalMaterial` | Standard 的加强版 | ✅ | 玻璃、车漆、清漆 |
| `MeshNormalMaterial` | 按法线方向染色 | ❌ | 调试神器 |
| `MeshDepthMaterial` | 按深度染色 | ❌ | 特殊效果（后期处理） |
| `ShaderMaterial` | 自己写着色器 | 看你自己 | 高级特效 |
| `PointsMaterial` | 点材质 | ❌ | 粒子 |

### MeshStandardMaterial 详解

日常开发 90% 的场景用它：

```js
const material = new THREE.MeshStandardMaterial({
  color: 0x42b883,       // 颜色
  roughness: 0.4,        // 粗糙度：0=镜面，1=完全哑光
  metalness: 0.6,        // 金属度：0=非金属（塑料/木头），1=金属
  transparent: true,     // 是否透明
  opacity: 0.8,          // 透明度 0~1
  side: THREE.DoubleSide,// 渲染哪面：FrontSide/BackSide/DoubleSide
  flatShading: true,     // 平面着色，有棱角感
  emissive: 0x000000,    // 自发光颜色
  emissiveIntensity: 1   // 自发光强度
});
```

::: tip 大白话时间
**roughness（粗糙度）**和 **metalness（金属度）** 是理解 PBR 材质的钥匙：

- 塑料球：roughness 高（0.7），metalness 0
- 抛光金属球：roughness 低（0.1），metalness 1
- 磨砂金属：roughness 0.5，metalness 1
- 橡胶：roughness 1，metalness 0

:::

::: warning 注意
如果你发现加了灯但物体还是一模一样亮，八成是用了 `MeshBasicMaterial`——它**完全不吃光照**。想看光影效果，换成 `MeshStandardMaterial`。
:::

### MeshPhysicalMaterial：玻璃效果

```js
const glass = new THREE.MeshPhysicalMaterial({
  color: 0xffffff,
  metalness: 0,
  roughness: 0,
  transmission: 1,       // 透射！关键参数
  thickness: 0.5,        // 厚度
  ior: 1.5,              // 折射率（玻璃约 1.5）
  transparent: true
});
```

::: tip 小贴士
`transmission` 是做玻璃/透明塑料的关键。它和简单的 `opacity` 不一样——`opacity` 只是变淡，`transmission` 会真实地折射背后的物体。
:::

### 深一层：透明渲染的完整链条

"我设了 `transparent: true`，为什么半透明物体还是穿帮、互相遮挡、看到背面？"——透明渲染是 Three.js 最反直觉的一块，四个属性要一起理解：

| 属性 | 默认值 | 作用 | 什么时候改 |
|---|---|---|---|
| `transparent` | `false` | 开启透明混合 | 想半透明时必开 |
| `opacity` | `1` | 透明度 0~1 | 配合 transparent 用 |
| `depthWrite` | `true` | 是否写入深度缓冲 | **半透明物体常要设 `false`** |
| `side` | `FrontSide` | 渲染正面/背面/双面 | 平面、单面模型设 `DoubleSide` |
| `alphaTest` | `0` | 透明度低于阈值直接丢弃 | 树叶、镂空贴图（比 transparent 快） |
| `renderOrder` | `0` | 强制绘制顺序 | 透明物体排序错乱时手动调 |

::: tip 大白话时间
**为什么半透明这么麻烦？** 不透明物体好办：谁近画谁，近的挡住远的，不用犹豫。半透明物体不行——你得先画远的、再画近的，才能透过前面看到后面。

Three.js 会按物体中心到相机的距离自动排序，但这个排序是**按物体**的，不是按像素。两个半透明物体交叉在一起时，无论谁先画都会出错——这就是"穿插穿帮"的根源。

`depthWrite: false` 的意思是"我画了但别记我的深度"，这样后面的半透明物体不会被前面那个的错误深度挡掉。代价是物体之间不再互相遮挡——所以这是权衡，不是万能药。
:::

```js
// 典型的半透明物体配置
const mat = new THREE.MeshStandardMaterial({
  color: 0x42b883,
  transparent: true,
  opacity: 0.6,
  depthWrite: false,    // 避免半透明互相遮挡出错
  side: THREE.DoubleSide, // 想看到背面时
});

// 两个交叉的半透明平面排序乱了？手动指定顺序
planeA.renderOrder = 1;
planeB.renderOrder = 2;   // 数字大的后画（画在上面）
```

::: warning 三个高频坑
**① 忘了设 transparent**：只改 opacity 不设 `transparent: true`，透明度完全不生效——opacity 被忽略。

**② 树叶/镂空用错方法**：带 alpha 通道的树叶贴图，用 `alphaTest: 0.5` 比 `transparent: true` 更好——它是"直接丢弃"而不是"混合"，不用排序，性能高得多，也不会有透明穿插问题。

**③ 玻璃里的物体看不见**：`MeshPhysicalMaterial` 的 `transmission` 走的是另一套渲染路径（透射），和 `transparent + opacity` 不是一回事。混用容易出问题，二选一。
:::

## 四、运行时修改物体

```js
mesh.material.color.set(0xff0000);   // 改颜色
mesh.material.wireframe = true;      // 线框模式
mesh.material.opacity = 0.5;         // 改透明度（要 transparent:true）
mesh.geometry.dispose();             // 释放旧几何体（重要！）
mesh.geometry = newGeometry;         // 换几何体
```

::: warning 注意
**多个 Mesh 共用同一个材质时，改一个，其他全跟着变**——因为它们指向同一个对象。想单独改，用 `material.clone()` 复制一份：

```js
const myMat = material.clone();
mesh.material = myMat;
```

换几何体/材质时，旧的要调用 `dispose()` 释放显存，否则长时间运行会内存泄漏。
:::

## 五、性能小贴士

- 相同的几何体和材质**尽量复用**，别在循环里 `new` 几百份
- 分段数够用就行，别无脑堆高
- 物体特别多（成千上万个相同物体）时，用 `InstancedMesh`（进阶章节会讲）
- 看不见的物体可以设 `mesh.visible = false`，或者直接 `scene.remove(mesh)`
