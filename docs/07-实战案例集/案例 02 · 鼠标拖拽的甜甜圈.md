# 案例 02：鼠标拖拽的甜甜圈

::: tip 大白话时间
这个案例就像把个实物摆你手里：鼠标拖着翻来覆去看，滚轮凑近拉远，手一松它还会靠惯性慢慢停。
核心思路：别自己写「鼠标移动 → 相机绕圈」那堆三角函数，直接用官方现成的 OrbitControls 接管鼠标。
做产品展示、模型预览，或者任何要让人「转着看」的画面，就用它。
:::

::: tip 效果长啥样
一个金属质感的「甜甜圈」（其实是环面纽结，比普通甜甜圈更酷），**按住鼠标拖动就能360度看它，滚轮能拉近拉远**。你不动它时，它自己还会慢慢转。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>鼠标拖拽的甜甜圈</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x101018);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 2, 7);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 主角：环面纽结 —— 甜甜圈的豪华升级版
// 参数：半径 1.4、管粗 0.45、横向 180 段、纵向 32 段（段数越多越光滑）
const knot = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1.4, 0.45, 180, 32),
  new THREE.MeshStandardMaterial({ color: 0x42b883, roughness: 0.25, metalness: 0.6 })
);
scene.add(knot);

scene.add(new THREE.AmbientLight(0xffffff, 0.6));
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(5, 5, 5);
scene.add(light);
// 补一盏冷色背光，让金属边缘更立体
const rim = new THREE.DirectionalLight(0x4488ff, 1.5);
rim.position.set(-5, -2, -4);
scene.add(rim);

// 控制器：鼠标拖动旋转、滚轮缩放、右键平移
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;    // 惯性：松手后慢慢停下，手感更顺滑
controls.autoRotate = true;       // 没人操作时自己转
controls.autoRotateSpeed = 1.5;   // 自转速度

renderer.setAnimationLoop(() => {
  controls.update();              // 阻尼和自动旋转都必须每帧调用
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip OrbitControls 是啥
它就是**现成的鼠标控制器**，帮你把「拖动 → 相机绕着物体转」这一堆数学全包了。你只要 new 一个、每帧 `update()` 一下，剩下的鼠标滚轮、右键平移它都处理好了。
:::

::: tip 大白话时间
代码里为啥多打一盏蓝色背光（rim）？金属这东西很挑光，只打正面它就跟糊了层黑膜似的发闷。从背后补一盏冷光，边缘就勾出一条亮边，立刻有立体感——跟你拍照时打轮廓光一个道理。
:::

::: warning 最容易踩的坑
设了 `enableDamping = true` 却**忘了在动画里调 `controls.update()`**——结果就是画面卡住不动、拖了没反应。记住：只要开了阻尼或自动旋转，`update()` 就是必写项。
:::

::: tip 常用开关
| 属性 | 效果 |
|---|---|
| `enablePan = false` | 禁用右键平移，防止物体被拖出画面 |
| `minDistance / maxDistance` | 限制滚轮缩放范围，比如 `3` 到 `12` |
| `maxPolarAngle = Math.PI / 2` | 不让相机转到地平线以下 |
| `autoRotateSpeed = 5` | 自转加快 |
:::

::: tip 换个几何体试试
把 `TorusKnotGeometry(...)` 换成下面任意一行，甜甜圈立刻变身：

- `new THREE.TorusGeometry(2, 0.6, 32, 100)` → 普通甜甜圈
- `new THREE.IcosahedronGeometry(2, 0)` → 20 面体（硬核棱角）
- `new THREE.KnotGeometry` 不存在，别写错——是 `TorusKnotGeometry`
:::
