# 案例 12：水晶球折射

::: tip 大白话时间
这个案例就像手里真攥着一颗玻璃珠：透过它看后面转悠的彩色小球，画面被扭曲、放大，跟真的一样。
核心思路：用 MeshPhysicalMaterial 的 transmission（物理级透射）加一张环境贴图，让球把背后的画面抓下来、按折射率折弯再贴回去。
做玻璃杯、宝石、水滴、镜头，任何要「高级通透质感」的材质，就靠它。
:::

::: tip 效果长啥样
一颗通透的**玻璃水晶球**悬在中央，背后几颗彩色小球绕着它转。透过水晶球看那些球，画面被**扭曲、放大、折射**——像真的握着一颗玻璃珠。这是 PBR 材质里 `transmission`（透射）的威力。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>水晶球折射</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x101018);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 0, 7);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.toneMapping = THREE.ACESFilmicToneMapping;  // 电影级色调映射，玻璃更通透
document.body.appendChild(renderer.domElement);

// 用内置的「房间环境」生成环境贴图 —— 不用下载任何 HDR 文件！
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;

// 主角：水晶球
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(1.7, 64, 64),
  new THREE.MeshPhysicalMaterial({
    color: 0xffffff,
    metalness: 0,
    roughness: 0.05,
    transmission: 1,       // 透光度：1 = 像玻璃一样完全透光
    thickness: 1.6,        // 厚度：越大折射弯曲越明显
    ior: 1.5,              // 折射率：水 1.33、玻璃 1.5、钻石 2.4
    clearcoat: 1,          // 表面清漆层，增加高光
    clearcoatRoughness: 0.1
  })
);
scene.add(ball);

// 球后面绕圈的小球：透过水晶球看它们会被折射扭曲
const orbiters = [];
const COLORS = [0xff4488, 0x44aaff, 0xffcc44, 0x44ffaa];
COLORS.forEach((c, i) => {
  const m = new THREE.Mesh(
    new THREE.SphereGeometry(0.5, 32, 32),
    new THREE.MeshStandardMaterial({ color: c, emissive: c, emissiveIntensity: 0.4 })
  );
  m.position.set(Math.cos(i / 4 * Math.PI * 2) * 2.6, Math.sin(i / 4 * Math.PI * 2) * 1.8, -1.5);
  scene.add(m);
  orbiters.push({ mesh: m, offset: i / 4 * Math.PI * 2 });
});

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

renderer.setAnimationLoop(() => {
  const t = performance.now() / 1000;
  orbiters.forEach(o => {
    const a = o.offset + t * 0.6;
    o.mesh.position.set(Math.cos(a) * 2.6, Math.sin(a) * 1.8, -1.5);
  });
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip transmission 是「真透明」
普通的 `transparent + opacity` 只是把物体变半透，不会折射背后的东西。而 `MeshPhysicalMaterial` 的 `transmission: 1` 是**物理级透射**：渲染器会把球背后的画面抓下来，按 `ior` 折射率弯曲后再贴回来——所以透过球看后面的小球是**扭曲变形**的，这才是真玻璃。
:::

::: tip 为什么要 scene.environment
玻璃需要「反射周围环境」才有质感。`scene.environment` 给整个场景一张环境贴图，玻璃材质就会反射它。`RoomEnvironment` 是 Three.js **内置的一个虚拟房间**，用 `PMREMGenerator` 转成可用格式即可——完全不用去下载 HDR 文件，离线也能跑。
:::

::: tip 大白话时间
开头那行 `toneMapping = ACESFilmicToneMapping` 图啥？普通渲染亮的地方容易白成一片、细节全没了；ACES 是套电影级的压亮算法，把过曝的高光柔下来，玻璃上的反光才有层次、看着更透。算是给画面加的一层滤镜。
:::

::: tip ior 折射率怎么记
`ior`（Index of Refraction）决定光线弯曲程度：水 `1.33`、玻璃 `1.5`、钻石 `2.4`。值越大，透过物体看到的画面扭曲越夸张。`thickness` 则控制「光在玻璃里走了多远」，越大弯曲累积越明显。两个配合调，能做出从气泡到钻石的各种效果。
:::

::: tip 改着玩
- `ior` 改成 `2.4` → 钻石感，扭曲强烈
- `roughness` 改成 `0.3` → 磨砂玻璃，背后模糊
- `color` 改成 `0x88ccff` → 蓝色水晶球
- `transmission` 改成 `0.5` → 半透光，介于玻璃和塑料之间
:::

::: warning 性能提示
透射材质渲染开销较大（每帧要额外渲染一遍背景），手机上谨慎用在大面积物体上。想要轻量替代，可以用 `MeshPhysicalMaterial` 配 `opacity + transparent` 假装透明，但没有真实折射。
:::
