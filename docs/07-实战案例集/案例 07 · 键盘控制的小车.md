# 案例 07：键盘控制的小车

::: tip 大白话时间
这个案例像玩遥控小车：按 W 往前、按 A/D 拐弯，后面还有个跟拍摄影师扛着镜头一直黏在你车屁股后头。
核心思路：用个 keys「小本本」记下哪些键正按着，动画循环只管查本子决定动不动；镜头用 lerp 一点点追上去，不硬切。
做第三人称小游戏、场景漫游，任何「键盘操控 + 镜头跟随」都能照这个改。
:::

::: tip 效果长啥样
一辆红白配色、带四个轮子的小车停在草地上。**按 W / ↑ 前进，S / ↓ 后退，A / ←、D / → 转向**，镜头会平滑地跟在车后面。一个小小的 third-person 驾驶游戏就这样成了。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>键盘控制的小车</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div style="position:fixed;top:12px;left:12px;color:#fff;font:15px sans-serif;background:#0009;padding:8px 12px;border-radius:6px;pointer-events:none">
  W / ↑ 前进 · S / ↓ 后退 · A / ←、D / → 转向
</div>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x87ceeb);
scene.fog = new THREE.Fog(0x87ceeb, 25, 70);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 200);
camera.position.set(0, 9, 14);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
document.body.appendChild(renderer.domElement);

// 草地 + 网格路标
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(200, 200),
  new THREE.MeshStandardMaterial({ color: 0x55aa55, roughness: 1 })
);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);
const grid = new THREE.GridHelper(200, 200, 0x336633, 0x66cc66);
grid.position.y = 0.02;
scene.add(grid);

// 小车 = 一个 Group，里面塞车身、车顶、四个轮子
const car = new THREE.Group();
const body = new THREE.Mesh(
  new THREE.BoxGeometry(2, 0.8, 3.5),
  new THREE.MeshStandardMaterial({ color: 0xff4444, roughness: 0.4 })
);
body.position.y = 0.9; body.castShadow = true;
car.add(body);

const cabin = new THREE.Mesh(
  new THREE.BoxGeometry(1.6, 0.7, 1.8),
  new THREE.MeshStandardMaterial({ color: 0xdddddd })
);
cabin.position.set(0, 1.6, -0.3); cabin.castShadow = true;
car.add(cabin);

const wheelGeo = new THREE.CylinderGeometry(0.45, 0.45, 0.3, 20);
const wheelMat = new THREE.MeshStandardMaterial({ color: 0x222222 });
[[-1.1, 1.15], [1.1, 1.15], [-1.1, -1.15], [1.1, -1.15]].forEach(([x, z]) => {
  const w = new THREE.Mesh(wheelGeo, wheelMat);
  w.position.set(x, 0.45, z);
  w.rotation.z = Math.PI / 2;   // 圆柱默认竖着，转成横躺当轮子
  car.add(w);
});
scene.add(car);

scene.add(new THREE.AmbientLight(0xffffff, 0.6));
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(10, 20, 10);
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);
sun.shadow.camera.left = -40; sun.shadow.camera.right = 40;
sun.shadow.camera.top = 40; sun.shadow.camera.bottom = -40;
scene.add(sun);

// 键盘状态：按下记 true，松开记 false
const keys = {};
addEventListener('keydown', e => { keys[e.code] = true; });
addEventListener('keyup',   e => { keys[e.code] = false; });

const SPEED = 12;                 // 前进速度
const camTarget = new THREE.Vector3();  // 相机想待的位置（复用，避免每帧 new）
let last = performance.now();

renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;

  // 转向
  if (keys['ArrowLeft']  || keys['KeyA']) car.rotation.y += 2 * dt;
  if (keys['ArrowRight'] || keys['KeyD']) car.rotation.y -= 2 * dt;

  // 前进方向 = 车头方向（车头默认朝 -z）
  const forward = new THREE.Vector3(-Math.sin(car.rotation.y), 0, -Math.cos(car.rotation.y));
  if (keys['ArrowUp']   || keys['KeyW']) car.position.addScaledVector(forward,  SPEED * dt);
  if (keys['ArrowDown'] || keys['KeyS']) car.position.addScaledVector(forward, -SPEED * dt);

  // 相机跟随：lerp 平滑插值，避免硬生生瞬移
  camTarget.set(car.position.x, 9, car.position.z + 14);
  camera.position.lerp(camTarget, 0.08);
  camera.lookAt(car.position.x, 1, car.position.z);

  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 键盘控制就一个「记账本」
`keys` 对象就是个小本本：`keydown` 时把对应键记成 `true`，`keyup` 记成 `false`。动画循环里只管**查这个本子**——哪个键是 true 就执行对应动作。这比在事件里直接移动物体更平滑，因为移动跟着帧走。
:::

::: tip 大白话时间
车身、车顶、四个轮子为啥要全塞进一个 Group（`car`）里，而不是各自扔进场景？因为这样移动或转向车只要动这一个 Group，轮子自然跟着走。要是散着放，你得分别挪 6 个零件——改辆车要动 6 处，谁受得了。
:::

::: tip 车头方向怎么算
车默认朝 `-z`，转了 `θ` 度后，车头方向就是 `(-sin θ, 0, -cos θ)`。用 `addScaledVector(方向, 距离)` 就能让车**朝自己车头**前进，而不是永远朝屏幕上方——所以转向后再前进，车会拐弯。
:::

::: tip lerp 是「温柔地追」
`camera.position.lerp(目标, 0.08)` 意思是「每帧朝目标挪 8%」。这样相机是**慢慢追上**车，而不是死死钉在固定偏移——画面有跟随感又不生硬。系数越小越「拖沓」，越大越「紧跟」。
:::

::: tip 改着玩
- `SPEED` 改大 → 飙车；改小 → 龟速
- 转向的 `2 * dt` 改成 `4 * dt` → 方向盘更灵敏
- 把车身的 `castShadow` 和地板的 `receiveShadow` 去掉一行 → 看阴影如何消失（复习案例 04）
:::
