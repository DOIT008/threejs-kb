# 案例 03：星空穿越

::: tip 大白话时间
这个案例像坐飞船穿越星空：镜头一直往前冲，星星从身边嗖嗖往两边飞，配上雾看着特别深远。
核心思路：几千颗星打包成一次绘制（Points），每帧把每颗的 z 往前推一点，飞过头就传送回远处接着飞。
做科幻片头、游戏背景，或者任何要「往前飞」的纵深感画面，就靠它。
:::

::: tip 效果长啥样
眼前是**几千颗彩色星星**组成的浩瀚宇宙，镜头不停往前飞，星星从身边呼啸而过冲向屏幕两侧，配上雾效有强烈的**纵深感**——像坐飞船穿越星际。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>星空穿越</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x000005);
scene.fog = new THREE.FogExp2(0x000005, 0.015);   // 远处的星星淡出 → 深度感

const camera = new THREE.PerspectiveCamera(70, innerWidth / innerHeight, 0.1, 200);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 造 3000 颗星星：每颗就是一个「点」
const count = 3000;
const positions = new Float32Array(count * 3);   // 每颗星 3 个数：x,y,z
const colors = new Float32Array(count * 3);      // 每颗星 3 个数：r,g,b
for (let i = 0; i < count; i++) {
  positions[i * 3]     = (Math.random() - 0.5) * 120;  // x 随机铺开
  positions[i * 3 + 1] = (Math.random() - 0.5) * 80;   // y 随机铺开
  positions[i * 3 + 2] = (Math.random() - 0.5) * 160;  // z 前后拉开
  const c = new THREE.Color().setHSL(Math.random(), 0.7, 0.7); // 随机彩色
  colors[i * 3] = c.r; colors[i * 3 + 1] = c.g; colors[i * 3 + 2] = c.b;
}

const geo = new THREE.BufferGeometry();
geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geo.setAttribute('color',    new THREE.BufferAttribute(colors, 3));

const stars = new THREE.Points(geo, new THREE.PointsMaterial({
  size: 0.4,
  vertexColors: true,   // 用上面 setAttribute('color') 的颜色
  transparent: true,
  opacity: 0.9
}));
scene.add(stars);

renderer.setAnimationLoop(() => {
  const pos = geo.attributes.position.array;
  // 让每颗星星朝镜头方向（+z）飞过来
  for (let i = 0; i < count; i++) {
    pos[i * 3 + 2] += 0.35;              // z 每帧加一点 = 向镜头靠近
    if (pos[i * 3 + 2] > 80) pos[i * 3 + 2] -= 160; // 飞过头就传送回远处
  }
  geo.attributes.position.needsUpdate = true;  // 关键！通知显卡数据变了
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 为什么用 Points 不用 3000 个 Mesh
如果建 3000 个小球队，显卡得画 3000 次，卡到飞起。而 `Points` 把 3000 个点**打包成一次绘制**，性能天差地别。这就是「粒子系统」的核心思想。
:::

::: tip 大白话时间
星星飞过头为啥是 `z -= 160` 送回远处，而不是删了重建？因为反复 new 对象又慢又费内存。这里玩的是循环利用：跑出画面的挪到队尾接着用，几千颗星空就这样永远飞不完，还几乎不花钱。
:::

::: tip position 数组怎么读懂
`positions` 是个扁平数组，第 0、1、2 三个数是第 1 颗星的 x/y/z，第 3、4、5 是第 2 颗的……所以第 `i` 颗星的 z 坐标是 `positions[i * 3 + 2]`。这是 Three.js 里最基础的「缓冲区」写法。
:::

::: warning 忘了 needsUpdate = 白的忙
改完 `position` 数组后**必须**写 `geo.attributes.position.needsUpdate = true`。否则你改的是内存里的数据，显卡不知道，画面纹丝不动。这是新手做粒子动画最常踩的坑。
:::

::: tip 改着玩
- `pos[i*3+2] += 0.35` 改大 → 飞得更快（比如 `1.2` 就是跃迁引擎）
- `size: 0.4` 改大 → 星星变大，像雪花
- 把 `+= 0.35` 换成 `+= (camera.position.z - pos[i*3+2]) * 0.01` → 星星越近飞越快，更真实
:::
