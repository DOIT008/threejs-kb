# 案例 11：烟花秀

::: tip 大白话时间
这个案例像过年放烟花：一朵朵自己升空炸开，亮点四散着慢慢飘落；你用鼠标点哪儿，就在哪儿再补放一朵。
核心思路：所有粒子塞进一个大 Points 当「池子」，放一朵就是往池里填 120 个朝四面八方飞的粒子，每帧算重力加阻力，命到了就把末尾粒子挪过来填空。
做节日特效、庆祝动画、游戏技能，要漫天飞舞的粒子就用它。
:::

::: tip 效果长啥样
黑夜里一朵朵彩色烟花**自动升空炸开**，无数亮点四散飞溅、受重力缓缓下落、渐渐熄灭。用鼠标点画面任意位置，还能在那儿**手动放一朵**。这是粒子系统的集大成案例。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>烟花秀</title>
<style>body { margin: 0; overflow: hidden; cursor: crosshair; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x050510);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 500);
camera.position.set(0, 0, 90);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 一个 Points 装下所有烟花的粒子（最多 3000 颗）
const MAX = 3000;
const positions = new Float32Array(MAX * 3);
const colors = new Float32Array(MAX * 3);
const geo = new THREE.BufferGeometry();
geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geo.setAttribute('color',    new THREE.BufferAttribute(colors, 3));
const points = new THREE.Points(geo, new THREE.PointsMaterial({
  size: 1.1,
  vertexColors: true,
  transparent: true,
  opacity: 0.9,
  blending: THREE.AdditiveBlending,  // 叠加混合 → 粒子重叠处更亮
  depthWrite: false
}));
scene.add(points);

let active = 0;                       // 当前用到的粒子数
const vels = Array.from({ length: MAX }, () => new THREE.Vector3());
const lifes = new Float32Array(MAX);

// 在 (ox,oy,oz) 放一朵烟花：生成 120 个朝四面八方飞的粒子
function launch(ox, oy, oz) {
  const color = new THREE.Color().setHSL(Math.random(), 1, 0.65);
  for (let k = 0; k < 120 && active < MAX; k++) {
    const i = active++;
    positions[i*3] = ox; positions[i*3+1] = oy; positions[i*3+2] = oz;
    colors[i*3] = color.r; colors[i*3+1] = color.g; colors[i*3+2] = color.b;
    // 球面均匀随机方向 × 随机速度
    const theta = Math.random() * Math.PI * 2;
    const phi = Math.acos(2 * Math.random() - 1);
    const speed = 18 + Math.random() * 22;
    vels[i].set(
      Math.sin(phi) * Math.cos(theta) * speed,
      Math.sin(phi) * Math.sin(theta) * speed,
      Math.cos(phi) * speed
    );
    lifes[i] = 1.4 + Math.random();
  }
}

let last = performance.now();
let nextLaunch = 0;
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  const t = now / 1000;

  if (t > nextLaunch) {              // 每隔约 1.3 秒自动放一朵
    launch((Math.random() - 0.5) * 70, 8 + Math.random() * 22, 0);
    nextLaunch = t + 1.3;
  }

  for (let i = 0; i < active; i++) {
    positions[i*3]   += vels[i].x * dt;
    positions[i*3+1] += vels[i].y * dt;
    positions[i*3+2] += vels[i].z * dt;
    vels[i].y -= 8 * dt;             // 重力：慢慢往下掉
    vels[i].multiplyScalar(0.985);   // 空气阻力：越来越慢
    lifes[i] -= dt;

    // 寿命耗尽：把「最后一个粒子」搬到当前位置补空位，再删掉末尾（O(1) 删除）
    if (lifes[i] <= 0) {
      const j = --active;
      if (j !== i) {
        positions[i*3] = positions[j*3];
        positions[i*3+1] = positions[j*3+1];
        positions[i*3+2] = positions[j*3+2];
        colors[i*3] = colors[j*3];
        colors[i*3+1] = colors[j*3+1];
        colors[i*3+2] = colors[j*3+2];
        vels[i].copy(vels[j]);
        lifes[i] = lifes[j];
      }
      i--;
    }
  }
  geo.setDrawRange(0, active);       // 只画前 active 个粒子
  geo.attributes.position.needsUpdate = true;
  geo.attributes.color.needsUpdate = true;
  renderer.render(scene, camera);
});

// 点击哪儿就在哪儿放一朵
addEventListener('pointerdown', e => {
  const x = (e.clientX / innerWidth - 0.5) * 90;
  const y = -(e.clientY / innerHeight - 0.5) * 55;
  launch(x, y, 0);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 球面均匀随机方向
想让烟花炸成**球状**而不是一团扁的，方向要均匀分布在球面上。技巧是 `theta = 随机×2π`、`phi = acos(2×随机-1)`，再用球坐标转直角坐标。这是图形学里生成均匀球面方向的标准公式，记住能用一辈子。
:::

::: tip 粒子「池」与 O(1) 删除
我们不反复创建/销毁粒子，而是开一个大数组（容量 3000）当**粒子池**，用 `active` 记录用到哪。粒子死了怎么删？直接 `splice` 会挪动后面所有元素（慢）。这里用**交换删除**：把最后一个粒子搬到死掉的位置，然后 `active--`——一步到位，性能友好。这是游戏开发的常用优化。
:::

::: tip 大白话时间
自动放烟花为啥用 `nextLaunch` 计时，而不用 `setInterval` 定时器？因为动画循环本来每帧就在跑，顺手查一下到点了没最省事；定时器是另一套节奏，容易和画面帧错拍。把时间判断揉进循环里，画面才不抖、说放就放。
:::

::: tip 为什么用 AdditiveBlending
`AdditiveBlending`（叠加混合）让粒子颜色**相加**，多颗粒子重叠的地方就越叠越亮，接近白色——这正好模拟了烟花/火焰的高光核心。配上 `depthWrite: false` 避免粒子互相遮挡产生的方块边缘。
:::

::: tip 改着玩
- `120` 改成 `300` → 一朵烟花更饱满（注意 MAX 上限）
- `lifes` 的 `1.4 + 随机` 改大 → 烟花在天上停留更久
- 把 `vels[i].y -= 8 * dt` 改小（如 `2`）→ 失重感，像在太空放烟花
:::
