# 案例 04：弹跳球与真实阴影

::: tip 大白话时间
这个案例就像看一颗皮球往地上砸：啪、啪、啪越弹越低，地上的影子还跟着球忽大忽小。
核心思路：中学那三行物理公式（加速、位移、碰地反弹）每帧算一小步；想有影子，渲染器、球、地板、灯四个开关一个都不能少。
做小游戏、物理演示，或者任何想要「有重量、踩在地上」感觉的画面，就用它。
:::

::: tip 效果长啥样
一颗红球从空中落下，**啪、啪、啪**越弹越低最后停下来，地上有一团**跟着球移动、随高度变化大小**的真实阴影。这是入门物理模拟的教科书案例。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>弹跳球与真实阴影</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 4, 10);
camera.lookAt(0, 1, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;            // ① 总开关：打开阴影
renderer.shadowMap.type = THREE.PCFShadowMap; // r182 起它就是柔化的，PCFSoftShadowMap 已移除
document.body.appendChild(renderer.domElement);

// 主角：球
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(0.8, 48, 32),
  new THREE.MeshStandardMaterial({ color: 0xff6b6b, roughness: 0.4 })
);
ball.castShadow = true;                       // ② 球要「投下」阴影
scene.add(ball);

// 地板：接住阴影
const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(30, 30),
  new THREE.MeshStandardMaterial({ color: 0x2a2a40, roughness: 0.9 })
);
floor.rotation.x = -Math.PI / 2;              // 平面默认竖着，转 90° 躺平
floor.receiveShadow = true;                   // ③ 地板要「接收」阴影
scene.add(floor);

const grid = new THREE.GridHelper(30, 30, 0x444466, 0x333355);
grid.position.y = 0.01;                       // 抬高一点，避免和地板重叠闪烁
scene.add(grid);

// 灯：负责投影
const light = new THREE.DirectionalLight(0xffffff, 3);
light.position.set(5, 10, 5);
light.castShadow = true;                      // ④ 灯要「能投影」
light.shadow.mapSize.set(2048, 2048);         // 阴影贴图分辨率，越高越清晰
// 框住阴影相机范围，超出这个盒子的地方不投影
light.shadow.camera.left = -10;
light.shadow.camera.right = 10;
light.shadow.camera.top = 10;
light.shadow.camera.bottom = -10;
scene.add(light);
scene.add(new THREE.AmbientLight(0xffffff, 0.4));

// 极简物理：高度、速度、重力、弹性
let h = 6;        // 球心当前高度
let v = 0;        // 当前速度
const G = -18;    // 重力加速度（负号 = 向下）
const BOUNCE = 0.82; // 弹性：撞地后保留 82% 的速度，越弹越低

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05); // 时间差转秒；限幅防止卡顿后「穿模」
  last = now;

  v += G * dt;          // 速度 += 加速度 × 时间
  h += v * dt;          // 高度 += 速度 × 时间
  if (h < 0.8) {        // 球心低于半径 = 碰地了
    h = 0.8;            // 按回地面，别陷进去
    v = -v * BOUNCE;    // 速度反向并衰减 → 弹起来
  }
  ball.position.y = h;
  ball.rotation.x += dt * 2;
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 阴影的四把钥匙
想看到阴影，必须**同时**满足四个条件，少一个都是白忙：
1. 渲染器 `renderer.shadowMap.enabled = true`（总开关）
2. 投影物 `ball.castShadow = true`（谁投影）
3. 接收物 `floor.receiveShadow = true`（谁接影）
4. 灯 `light.castShadow = true`（谁产生影）
:::

::: warning r187 注意
老教程常写的 `THREE.PCFSoftShadowMap` 从 r182 起废弃、r186 起移除，r187 里写入会警告并回退到 `PCFShadowMap`。自 r182 起 `PCFShadowMap` 本身就是柔化的，想要更软可以调大 `shadow.mapSize` 或加 `shadow.radius`。
:::

::: tip 物理就三行公式
`v += G*dt` → `h += v*dt` → 碰地反弹 `v = -v * 弹性`。这就是中学物理的匀加速运动，只不过拆成每一帧算一小步。`dt` 是「这一帧过了多久」，用它而不是写死数值，才能让不同帧率的电脑看到**一样快**的动画。
:::

::: tip 大白话时间
代码里 `dt` 外面套了个 `Math.min(..., 0.05)` 是防啥？防止你切走标签页再回来时，dt 突然变成好几秒——那球一步就穿过地板掉地心去了。限幅就是给时间差封顶：卡再久，也只当过了 0.05 秒，稳。
:::

::: tip 改着玩
- `BOUNCE` 改成 `0.95` → 像超级弹球，弹很久才停
- `BOUNCE` 改成 `0.3` → 像橡皮泥，啪一下就趴下
- `G` 改成 `-3` → 月球重力，慢动作飘落
:::
