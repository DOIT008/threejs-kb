# 案例 06：迷你太阳系

::: tip 大白话时间
这个案例就像小时候那套太阳系玩具：行星挂在看不见的杆子上，你转中间的轴，它们就一圈圈绕太阳跑，自己还一边转。
核心思路：造个空 Group 当「转轴」，行星挂在它边上——转转轴就是公转，转行星自己就是自转，互不打架。这招叫父子层级。
做齿轮联动、机械臂、月亮绕地球，任何「一层带着一层转」的东西，都用得上。
:::

::: tip 效果长啥样
中间一颗发光太阳，四颗不同颜色的行星各自沿着**看不见的轨道公转**，同时**自己还在自转**。鼠标可拖动视角。这一例的核心是 Three.js 里超重要的「父子层级」。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>迷你太阳系</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x05050a);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 200);
camera.position.set(0, 18, 28);
camera.lookAt(0, 0, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 太阳：用 Basic 材质（自己发光，不受光照影响）
const sun = new THREE.Mesh(
  new THREE.SphereGeometry(2.5, 48, 32),
  new THREE.MeshBasicMaterial({ color: 0xffcc33 })
);
scene.add(sun);
// 点光源放在太阳中心，让行星有明暗面。第二参是强度，第三参是照射距离(0=无限)，第四是衰减
scene.add(new THREE.PointLight(0xffdd88, 300, 0, 2));

// 行星配置：半径、轨道距离、颜色、公转速度
const planets = [
  { r: 0.4, d: 4.5,  c: 0xaaaaaa, s: 1.6 },  // 水星：小、快
  { r: 0.7, d: 6.5,  c: 0xff8844, s: 1.1 },  // 金星
  { r: 0.8, d: 9,    c: 0x4488ff, s: 0.8 },  // 地球
  { r: 0.5, d: 12,   c: 0xcc7744, s: 0.6 }   // 火星：远、慢
];
const orbiters = [];

planets.forEach(p => {
  // 画一圈细细的轨道线（圆环躺平）
  const ring = new THREE.Mesh(
    new THREE.RingGeometry(p.d - 0.02, p.d + 0.02, 128),
    new THREE.MeshBasicMaterial({ color: 0x444466, side: THREE.DoubleSide })
  );
  ring.rotation.x = -Math.PI / 2;
  scene.add(ring);

  // 关键：造一个空的 Group 当「转轴」，放在太阳中心
  const pivot = new THREE.Group();
  scene.add(pivot);

  const planet = new THREE.Mesh(
    new THREE.SphereGeometry(p.r, 32, 16),
    new THREE.MeshStandardMaterial({ color: p.c, roughness: 0.8 })
  );
  planet.position.x = p.d;  // 行星挂在转轴「边上」
  pivot.add(planet);        // 加到转轴里，而不是直接加到 scene

  orbiters.push({ pivot, planet, speed: p.s });
});

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  orbiters.forEach(o => {
    o.pivot.rotation.y += dt * o.speed;   // 转「转轴」→ 行星绕太阳公转
    o.planet.rotation.y += dt * 3;        // 转「行星自己」→ 自转
  });
  sun.rotation.y += dt * 0.3;
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 转轴（pivot）是啥， why 不用三角函数
想让行星绕圈，新手常想到用 `x = cos(角度)×半径`、`z = sin(角度)×半径` 硬算。更聪明的办法是**造一个看不见的 Group 当转轴**：把行星放在转轴边上（离中心 `p.d`），然后**只转这个转轴**，行星就被带着画圆了——这就是父子层级，父级转动，子级跟着走。
:::

::: tip 公转和自转怎么分开
转**转轴**（`pivot.rotation.y`）→ 公转；转**行星自己**（`planet.rotation.y`）→ 自转。两个动作互不干扰，因为它们是不同的对象。这就是层级结构的威力：把「运动」分配到合适的层级上。
:::

::: tip 大白话时间
太阳为啥用 `MeshBasicMaterial` 而不是给行星用的 Standard？因为太阳是自己发光的，不该被别的光照出暗面——Basic 材质不吃光照，颜色永远亮堂堂。要是给太阳用 Standard，没被照到就成了黑球，那还叫太阳吗。
:::

::: tip 升级成真太阳系
- 给地球加个「月球」：把月球 `moon` 加到 `planet`（地球）里，而不是 pivot 里——月球就会一边绕地球转、一边跟着地球公转。层层嵌套，理论上有几层都行。
- 加土星环：`new THREE.RingGeometry(1.2, 2, 64)` 加到行星上，转个角度。
- 行星轨道做成椭圆：`planet.position.x = p.d; planet.position.z = p.d * 0.6;` 并给 pivot 加缩放。
:::
