# 案例 01：会呼吸的变色星球

::: tip 大白话时间
这个案例让一颗球像有心跳一样一胀一缩、还不停换颜色，就跟给张照片 P 上「呼吸 + 心情」似的。
核心思路：拿 sin 正弦波当节拍器控制大小，拿 HSL 色相转圈控制变色，每帧各算一次就行。
想让按钮、图标、星球「活起来」，或者做个抓眼球的 loading 动画，就会想到这一招。
:::

::: tip 效果长啥样
漆黑的太空里悬浮着一颗球，它像心跳一样**一胀一缩**，颜色还在**不停地渐变**（绿→蓝→紫→红…），底下有网格当地平线。这就是最经典的「Hello World 升级版」。
:::

## 完整代码

保存为 `demo.html` 打开：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>会呼吸的变色星球</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

// 1. 场景：黑色太空
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x0f1020);

// 2. 相机：从正面看
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 100);
camera.position.z = 6;

// 3. 渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 4. 主角：一颗球（先不给颜色，颜色交给动画循环改）
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(1.5, 48, 32),
  new THREE.MeshStandardMaterial({ roughness: 0.3, metalness: 0.35 })
);
scene.add(ball);

// 5. 灯光：环境光打底 + 一盏主灯打出明暗
scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const key = new THREE.DirectionalLight(0xffffff, 2.5);
key.position.set(4, 6, 5);
scene.add(key);

// 6. 地面网格：给眼睛一个「空间感」参照
const grid = new THREE.GridHelper(24, 24, 0x42b883, 0x223344);
grid.position.y = -2.2;
scene.add(grid);

// 7. 动画：每帧更新
renderer.setAnimationLoop(() => {
  const t = performance.now() / 1000;          // 从页面打开到现在的秒数
  ball.scale.setScalar(1 + Math.sin(t * 2) * 0.12);      // 正弦波 → 一胀一缩
  ball.material.color.setHSL((t * 0.12) % 1, 0.65, 0.55); // 色相循环 → 变色
  ball.rotation.y += 0.008;                               // 顺便自转
  renderer.render(scene, camera);
});

// 8. 窗口变化时自适应
addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 三行动画在干嘛
- `Math.sin(t * 2)`：正弦波在 -1 到 1 之间来回摆，乘 `0.12` 缩小幅度，再加 `1` 让它永远接近 1 —— 于是球就在 0.88~1.12 倍之间**呼吸**。`2` 越大喘得越快。
- `setHSL((t * 0.12) % 1, ...)`：HSL 色相是 0~1 的圆环，`% 1` 让它转一圈又回到头，颜色就**循环渐变**。`0.12` 是变色速度。
- `setAnimationLoop`：Three.js 推荐的动画入口，浏览器每帧自动调一次（约 60 次/秒）。
:::

::: tip 大白话时间
为啥非用 sin 而不用「涨到 1.2 就往回缩」那种 if 判断？因为 sin 天生就在 -1~1 之间平滑来回摆，不用写边界判断，转折处也不会咯噔一下卡住。一行顶十行，还贼顺滑。
:::

::: tip 自己改着玩
- 把 `0.12` 改成 `0.3` → 呼吸幅度变大，球快撑爆了
- 把 `t * 2` 改成 `t * 8` → 心跳加速
- 把 `SphereGeometry` 换成 `IcosahedronGeometry(1.5, 1)` → 变成低多边形风格
:::
