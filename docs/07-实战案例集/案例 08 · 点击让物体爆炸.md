# 案例 08：点击让物体爆炸

::: tip 大白话时间
这个案例像戳破一个气球：啪地炸成一把彩色纸屑四处飞，落着落着又自己拼回原球，能反复戳。
核心思路：先用射线判断你点没点中球，中了就撒出 160 个带随机速度的小方块，每帧按「速度 + 重力」挪一挪，时间一到全清掉、球复原。
做点击彩蛋、破坏特效、庆祝动效，想要「啪」一下的爽感就找它。
:::

::: tip 效果长啥样
屏幕中间一颗绿球慢慢转。**用鼠标点它一下——啪！**炸成 160 块彩色碎片向四面八方飞溅，受重力下落、边飞边翻滚，两三秒后自动重聚成原球，可以反复点。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>点击爆炸</title>
<style>body { margin: 0; overflow: hidden; cursor: crosshair; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 100);
camera.position.z = 8;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.AmbientLight(0xffffff, 0.7));
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(5, 5, 5);
scene.add(light);

// 目标球
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(1.5, 48, 32),
  new THREE.MeshStandardMaterial({ color: 0x42b883, roughness: 0.4 })
);
scene.add(ball);

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0x222233 })
);
ground.rotation.x = -Math.PI / 2;
ground.position.y = -3;
scene.add(ground);

const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
const fragments = [];   // 当前活着的碎片

// 点击 → 发射射线 → 看有没有打中球
addEventListener('pointerdown', e => {
  mouse.x = (e.clientX / innerWidth) * 2 - 1;    // 屏幕坐标 → -1~1
  mouse.y = -(e.clientY / innerHeight) * 2 + 1;  // y 轴要反过来
  raycaster.setFromCamera(mouse, camera);
  if (raycaster.intersectObject(ball).length > 0) explode();
});

function explode(){
  ball.visible = false;
  const geo = new THREE.BoxGeometry(0.22, 0.22, 0.22);  // 碎片共用同一几何体
  for (let i = 0; i < 160; i++) {
    const mat = new THREE.MeshStandardMaterial({
      color: new THREE.Color().setHSL(Math.random(), 0.8, 0.6)
    });
    const f = new THREE.Mesh(geo, mat);
    // 从球附近随机位置起步
    f.position.set(
      ball.position.x + (Math.random() - 0.5) * 2,
      ball.position.y + (Math.random() - 0.5) * 2,
      ball.position.z + (Math.random() - 0.5) * 2
    );
    scene.add(f);
    fragments.push({
      mesh: f,
      vel: new THREE.Vector3(
        (Math.random() - 0.5) * 2,
        (Math.random() - 0.5) * 2 + 1.5,  // 略微偏上，炸得更漂亮
        (Math.random() - 0.5) * 2
      ).multiplyScalar(5),
      life: 2.2
    });
  }
  setTimeout(reset, 2600);
}

function reset(){
  fragments.forEach(f => {
    scene.remove(f.mesh);
    f.mesh.material.dispose();   // 材质是每块独立的，必须释放
  });
  fragments.length = 0;
  ball.visible = true;
}

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  ball.rotation.y += dt * 0.6;

  for (let i = fragments.length - 1; i >= 0; i--) {
    const f = fragments[i];
    f.vel.y -= 9.8 * dt;                          // 重力
    f.mesh.position.addScaledVector(f.vel, dt);   // 按速度移动
    f.mesh.rotation.x += dt * 5;                  // 边飞边翻滚
    f.mesh.rotation.y += dt * 3;
    f.life -= dt;
    if (f.life <= 0) {
      scene.remove(f.mesh);
      f.mesh.material.dispose();
      fragments.splice(i, 1);
    }
  }
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 射线拾取三板斧
「鼠标点到 3D 物体了吗」靠 `Raycaster`（射线检测器）：
1. 把鼠标屏幕坐标换成 **-1~1** 的标准坐标（注意 y 要取反）
2. `raycaster.setFromCamera(鼠标, 相机)` —— 从相机穿过鼠标点射出一条射线
3. `raycaster.intersectObject(球)` —— 返回射线打中的物体列表，**有东西就是点中了**
:::

::: tip 爆炸 = 一堆带速度的小球
「爆炸」没有魔法，就是生成 160 个小方块，每个给一个**随机的三维速度**（`vel`），然后每帧 `位置 += 速度 × dt`，再让 `速度.y -= 重力 × dt` 慢慢往下掉。加上随机旋转，就有炸裂翻滚的感觉了。
:::

::: tip 大白话时间
生成速度时为啥给 y 方向偷偷加了 `+1.5`？纯随机的话碎片容易往地里钻，看着像塌了而不是炸了。整体往上抬一点，碎片先冲上天再落下，才有那种砰地炸开的花状。
:::

::: warning 碎片用完要 dispose
`scene.remove()` 只是把物体从画面拿掉，**不会释放显存**。材质是每块碎片独立创建的，必须 `material.dispose()`。几何体是共享的（160 块共用一个 `geo`），所以只释放一次即可——这正是共享几何体的好处。这是 Three.js 内存管理的铁律。
:::

::: tip 改着玩
- `160` 改成 `500` → 更壮观的碎裂（但更吃性能）
- 速度的 `multiplyScalar(5)` 改成 `10` → 炸得更猛
- 把 `BoxGeometry` 换成 `TetrahedronGeometry(0.25)` → 尖锐的三角碎片
:::
