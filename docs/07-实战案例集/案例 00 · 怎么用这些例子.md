# 案例集使用说明

::: tip 大白话时间
这些案例就是给你「照着抄」的，别怕。
套路是：先打开看效果 → 把整段代码抄走跑起来 → 改两个数字看画面怎么变 → 看懂了就关掉代码自己默写一遍。
一句话：手敲一遍，顶你干看十遍。
:::

::: tip 这一册是干嘛的
前面 38 章讲的是「零件怎么用」，这一册直接给你**一整个一整个能跑的小作品**。每个案例都是**一个完整的 HTML 文件**——把代码复制走、存成 `.html`、用浏览器打开，就能看到会动的 3D 画面。不用装软件、不用构建工具。
:::

## 三步跑起来

1. 复制案例里的**全部**代码
2. 新建文本文件粘进去，保存成 `demo.html`（后缀必须是 `.html`）
3. 双击打开，或者直接拖进浏览器窗口

::: warning 打开是黑的怎么办
少数浏览器不允许本地文件直接加载 3D 模块。这时在该文件夹空白处按住 **Shift + 右键 → 在此处打开终端**，运行 `python -m http.server 8000`，再访问 `http://localhost:8000/demo.html` 即可。这也正是本知识库自身的打开方式。
:::

## 所有案例共用的「骨架」

代码看着长，其实套路固定。记住这四样，自己写也快：

| 部件 | 作用 | 大白话 |
|---|---|---|
| `scene` 场景 | 装所有东西的盒子 | 摄影棚 |
| `camera` 相机 | 决定从哪儿看 | 摄影机的镜头 |
| `renderer` 渲染器 | 把画面画到屏幕 | 摄影师按快门 |
| `setAnimationLoop` | 每帧画一次 | 连续播放形成动画 |

::: tip 关于版本
全部基于当前最新版 **r187**，CDN 链接写死在 `importmap` 里，联网即可运行。想换版本，改链接里的 `0.187.0` 就行。动画计时统一用浏览器自带的 `performance.now()`，零依赖、最省心。
:::
