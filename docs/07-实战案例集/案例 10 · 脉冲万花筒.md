# 案例 10：脉冲万花筒

::: tip 大白话时间
这个案例像往水面正中间扔了颗石子：一圈圈涟漪往外荡，只不过这里的「水面」是几千个小方块围成的空心大立方。
核心思路：4096 个方块用 InstancedMesh 一次画完，每个按「离中心多远」上色和缩放，波就一圈圈从里往外扩。
做视觉特效、音乐律动、脉冲动画、酷炫片头，想要那种「整齐又震撼」就抄它。
:::

::: tip 效果长啥样
4096 个小方块排成一个空心立方阵，每个方块**按到中心的距离**渐变染色，整团东西像心跳一样**一呼一吸地膨胀收缩**，同时缓慢旋转，颜色持续流动。视觉冲击力很强，代码却不难。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>脉冲万花筒</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x080812);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 200);
camera.position.set(24, 20, 24);
camera.lookAt(0, 0, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const N = 16;                       // 每条边 16 格 → 16³ = 4096 个小方块
const GAP = 1.3;                    // 格子间距
const COUNT = N * N * N;
const geo = new THREE.BoxGeometry(0.55, 0.55, 0.55);
const mesh = new THREE.InstancedMesh(geo, new THREE.MeshBasicMaterial(), COUNT);
const dummy = new THREE.Object3D();
const color = new THREE.Color();

// 预先算好每个方块的原始坐标和到中心的距离
const cells = [];
let idx = 0;
for (let x = 0; x < N; x++) {
  for (let y = 0; y < N; y++) {
    for (let z = 0; z < N; z++) {
      const px = (x - N / 2) * GAP;
      const py = (y - N / 2) * GAP;
      const pz = (z - N / 2) * GAP;
      const dist = Math.sqrt(px * px + py * py + pz * pz);
      cells.push({ x: px, y: py, z: pz, dist });
      color.setHSL((dist / 35 + 0.5) % 1, 0.85, 0.6);  // 按距离染色
      mesh.setColorAt(idx++, color);
    }
  }
}
scene.add(mesh);

renderer.setAnimationLoop(() => {
  const t = performance.now() / 1000;
  let i = 0;
  for (const c of cells) {
    // 波从中心向外扩散：sin(距离 × 频率 - 时间 × 速度)
    const wave = Math.sin(c.dist * 0.55 - t * 3) * 0.28;
    const scale = 1 + wave;
    dummy.position.set(c.x * scale, c.y * scale, c.z * scale);
    dummy.rotation.set(t * 0.2, t * 0.25, 0);
    dummy.updateMatrix();
    mesh.setMatrixAt(i++, dummy.matrix);
  }
  mesh.instanceMatrix.needsUpdate = true;  // 通知显卡矩阵变了
  mesh.rotation.y += 0.003;
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 4096 个方块为什么能流畅
还是 `InstancedMesh` 的功劳：一次绘制调用画 4096 份。每帧我们只更新一个 16 位浮点矩阵缓冲区（`instanceMatrix`），显卡照着它摆放所有方块。要是建 4096 个独立 Mesh，光是遍历更新就得卡爆。
:::

::: tip 大白话时间
为啥一上来就把每个方块的位置和到中心的距离算好存进 `cells`，不在动画里现算？因为这些值压根不变，每帧重算 4096 次纯属浪费。先算一遍存着，动画循环只管拿来用——这种能提前算就别反复算的思路，是做大量物体时的基本功。
:::

::: tip 「波」的公式再看一眼
`sin(距离 × 0.55 - 时间 × 3)`：减号意味着波**从中心向外传播**（若是加号则向内收）。距离越远的点，同一时刻处在波的不同相位，于是就出现一圈圈向外扩散的涟漪——和水面投石子的道理一样（复习案例 05）。
:::

::: tip 改着玩
- `t * 3` 改成 `t * 8` → 脉冲传播飞快
- `0.28` 改成 `0.5` → 呼吸幅度更夸张
- 把 `MeshBasicMaterial()` 换成 `new THREE.MeshBasicMaterial({ wireframe: true })` → 变成科幻线框风
:::
