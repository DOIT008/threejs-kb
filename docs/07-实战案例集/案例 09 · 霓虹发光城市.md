# 案例 09：霓虹发光城市

::: tip 大白话时间
这个案例像给整座夜城的高楼全装上霓虹灯：楼本身够艳，灯还会把光晕到周围，隔着雾看一片流光溢彩。
核心思路：400 栋楼用 InstancedMesh「批量复印」一次画完；画面画好后，再让 EffectComposer 加一道工序，专挑亮的地方糊出光晕（Bloom）。
做赛博朋克城市、科幻界面、任何要「发光发炸」的氛围，就靠这套后期处理。
:::

::: tip 效果长啥样
夜色中一片由**几百栋彩色高楼**组成的城市，楼体发出霓虹般的辉光，边缘晕开一层柔光，镜头绕着城市缓缓旋转。这是「后期处理泛光（Bloom）」的经典效果——赛博朋克风一键get。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>霓虹发光城市</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';
import { EffectComposer }  from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass }      from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x050510);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 300);
camera.position.set(30, 25, 30);
camera.lookAt(0, 5, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 用 InstancedMesh 一次画出 400 栋楼（比建 400 个 Mesh 快得多）
const COUNT = 400;
const geo = new THREE.BoxGeometry(1, 1, 1);
const mat = new THREE.MeshBasicMaterial();  // Basic：颜色不受光照影响，更鲜艳
const city = new THREE.InstancedMesh(geo, mat, COUNT);
const dummy = new THREE.Object3D();          // 临时对象，专门用来算矩阵
const COLORS = [0x00ffff, 0xff00ff, 0x42b883, 0xffaa00, 0x4488ff, 0xff3366];

for (let i = 0; i < COUNT; i++) {
  const x = (Math.random() - 0.5) * 70;
  const z = (Math.random() - 0.5) * 70;
  const h = 2 + Math.random() * 22;              // 楼高 2~24
  dummy.position.set(x, h / 2, z);
  dummy.scale.set(1 + Math.random(), h, 1 + Math.random());
  dummy.updateMatrix();                          // 把位置/缩放烘焙成矩阵
  city.setMatrixAt(i, dummy.matrix);             // 写入第 i 栋楼的变换
  city.setColorAt(i, new THREE.Color(COLORS[i % COLORS.length]));
}
scene.add(city);

// 后期处理流水线：先把场景画出来，再叠泛光
const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));          // ① 常规渲染
const bloom = new UnrealBloomPass(
  new THREE.Vector2(innerWidth, innerHeight),
  1.4,    // strength：泛光强度
  0.5,    // radius：光晕扩散半径
  0.15    // threshold：亮度阈值，超过它才发光
);
composer.addPass(bloom);                                  // ② 加泛光

renderer.setAnimationLoop(() => {
  const t = performance.now() / 5000;
  camera.position.x = Math.sin(t) * 45;
  camera.position.z = Math.cos(t) * 45;
  camera.lookAt(0, 4, 0);
  composer.render();   // 注意：用 composer.render()，不是 renderer.render()
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
  composer.setSize(innerWidth, innerHeight);  // 后期处理也要跟着改尺寸
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip InstancedMesh 是「批量复印机」
要画 400 栋楼，傻办法是 new 400 个 Mesh（显卡要提交 400 次）。`InstancedMesh` 是**一次提交画 400 份**，每份用 `setMatrixAt(i, 矩阵)` 指定各自的位置/缩放，用 `setColorAt(i, 颜色)` 指定颜色。那个临时 `dummy` 对象就是「模板」，改好它的位置缩放，`updateMatrix()` 烘焙成矩阵再写进去。几百上千个重复物体，全靠它。
:::

::: tip 泛光（Bloom）是什么
后期处理就是「画面画完后再加工一遍」。`EffectComposer` 是一条加工流水线：`RenderPass` 先把场景正常画出来，`UnrealBloomPass` 再找出画面里**足够亮的像素**，把光晕糊到周围——霓虹灯、发光招牌的晕开效果就是这么来的。
:::

::: tip 大白话时间
楼为啥用 `MeshBasicMaterial` 不用 Standard？因为我们压根没打灯，Standard 没光就是一片黑；Basic 自己就亮、颜色最纯。再加上泛光只认够亮的像素——楼越亮，晕出来的光越带劲，正好一组搭档。
:::

::: warning 两个必改点
1. 加了 composer 后，动画里要写 `composer.render()`，**不能**再写 `renderer.render()`，否则泛光不生效。
2. 窗口变化时 `composer.setSize()` 也要调用，不然画面会被拉伸变形。
:::

::: tip 调出不同氛围
- `strength` 调到 `2.5` → 梦幻光污染；调到 `0.4` → 克制内敛
- `threshold` 调到 `0` → 所有东西都发光（很炸）；调到 `0.8` → 只有最亮的发光
- 把 `MeshBasicMaterial` 换成 `MeshStandardMaterial` 并加灯 → 楼有明暗立体感，但要调高 threshold 才发光
:::
