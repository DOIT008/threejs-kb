# 案例 05：会起伏的波浪海面

::: tip 大白话时间
这个案例像把一张渔网绷在水面，手提着网眼一上一下地抖，网就变成了波浪，光打上去还有明暗起伏。
核心思路：把平面切成密格子，每帧用几组方向不同的正弦波把每个交点抬高压低，再重算法线让光照跟着浪走。
做海面、湖面、布料、旗帜这类「会飘会皱」的效果，都从这个套路出发。
:::

::: tip 效果长啥样
整片海面像真的一样**此起彼伏**，波浪一层推着一层，光照随着浪的起伏明暗变化，远处渐渐融进雾里。核心是逐帧修改网格的顶点——这就是「顶点动画」。
:::

## 完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>波浪海面</title>
<style>body { margin: 0; overflow: hidden; }</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x0a1a2a);
scene.fog = new THREE.Fog(0x0a1a2a, 12, 45);   // 远处融进背景

const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 5, 14);
camera.lookAt(0, 0, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 海面：一个被切成 80×80 小格的平面（格子越多波浪越细腻，但越吃性能）
const geo = new THREE.PlaneGeometry(60, 60, 80, 80);
geo.rotateX(-Math.PI / 2);   // 平面默认竖着，转成水平
const sea = new THREE.Mesh(geo, new THREE.MeshStandardMaterial({
  color: 0x2266aa, roughness: 0.35, metalness: 0.3,
  side: THREE.DoubleSide, flatShading: true  // flatShading 让浪有棱角感
}));
scene.add(sea);

scene.add(new THREE.HemisphereLight(0x88ccff, 0x001122, 1.5));
const sun = new THREE.DirectionalLight(0xffeedd, 2);
sun.position.set(10, 15, 5);
scene.add(sun);

const pos = geo.attributes.position;   // 顶点位置缓冲区

renderer.setAnimationLoop(() => {
  const t = performance.now() / 1000;
  // 遍历每一个顶点，用三组正弦波叠加算出它的高度
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i), z = pos.getZ(i);
    const y = Math.sin(x * 0.5 + t * 2) * 0.4        // 沿 x 方向的浪
            + Math.sin(z * 0.8 + t * 1.3) * 0.3      // 沿 z 方向的浪
            + Math.sin((x + z) * 0.3 + t) * 0.5;     // 斜着的浪
    pos.setY(i, y);                                   // 更新这个顶点的高度
  }
  pos.needsUpdate = true;         // 通知显卡：顶点变了
  geo.computeVertexNormals();     // 重算法线 → 光照才能跟着浪变化
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 关键点拆解

::: tip 海面其实是「渔网」
`PlaneGeometry(60, 60, 80, 80)` 不是一张平滑的纸，而是被切成 80×80 格子的**渔网**，有 6561 个交点（顶点）。波浪动画就是**每帧把每个交点抬高或压低**，网就跟着起伏了。格子越密越细腻，但顶点太多会卡。
:::

::: tip 大白话时间
材质里那个 `flatShading: true` 是干嘛的？它让每个小格子各算各的光，块与块之间留出明暗分界，浪看着就有棱角、像水面碎光。想要丝绸般光滑就把它关掉——一个开关，两种画风。
:::

::: tip 三组正弦波叠加
只用一组正弦波，浪会像规则的正弦曲线很假。这里叠加了三组**频率、方向、速度都不同**的波，加在一起就成了看似随机的自然海浪。这个技巧叫「波的叠加」，做水面、布料、旗帜都用它。
:::

::: warning 为什么必须重算法线
光照靠「法线」判断朝哪个方向受光。顶点被你抬高后，法线还是旧的，光照就贴图一样不跟着变——浪看着「平」。所以要 `computeVertexNormals()` 重新算一遍。**但**每帧重算全部法线比较费性能，大场景会改用着色器在 GPU 上算（见进阶篇）。
:::

::: tip 改着玩
- `flatShading: true` 改成 `false` → 海面变光滑，像丝绸
- 去掉 `+ Math.sin(z * 0.8...)` 那一行 → 只剩单向浪，像传送带
- 把 `roughness` 改成 `0.1`、`metalness` 改成 `0.8` → 变成镜面海水
:::
