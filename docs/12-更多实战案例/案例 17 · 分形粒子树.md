# 案例 17 · 分形粒子树

一棵树从粗壮的树干开始，每根枝桠分成三根更细的，再分、再分，最后长成一棵枝繁叶茂的树——这就是分形。更妙的是几百根枝桠其实只用了一个圆柱体网格，靠 `InstancedMesh` 一次画完；再配上一群飘落的叶子粒子，画面立刻活了起来。

## 一、效果长啥样

画面中央长出一棵由圆柱拼成的树：树干粗、越往上越细、颜色从棕色渐变到嫩绿。树冠周围有黄色小叶片缓缓飘落，落地后又从树顶重新出现。拖拽鼠标可以环绕观察，树身还会随风轻轻摇摆。

```text
             ／ ／ ／          ← depth 3：细枝 + 绿叶色
           ／ ／ ／
         ╱ ╱ ╱              ← depth 2
        ╱ ╱ ╱
      ╱ ╱ ╱                 ← depth 1
      │ │ │
      │ │ │                 ← depth 0：树干（粗、棕色）
    ──┴─┴─┴──  地面

   递归：grow(起点, 方向, 长度, 半径, 深度)
         └─ 画自己这一段
         └─ depth>0 时，调用 grow() 三次（分叉）
         └─ depth===0 时停手 ← 没有这行就是无限递归

   InstancedMesh：几百根枝桠 = 1 个 CylinderGeometry + N 个变换矩阵
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>分形粒子树</title>
<style>
  body { margin: 0; overflow: hidden; }
  #tip {
    position: fixed; left: 16px; top: 16px; color: #fff;
    font: 14px/1.7 sans-serif; background: rgba(0,0,0,.55);
    padding: 10px 14px; border-radius: 8px; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="tip">分形树：递归 + InstancedMesh · 落叶粒子 · 拖拽转视角</div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x10141f);
scene.fog = new THREE.Fog(0x10141f, 12, 30);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(6, 5, 9);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x223344, 2.2));
const sun = new THREE.DirectionalLight(0xffeecc, 2);
sun.position.set(4, 9, 5);
scene.add(sun);

const ground = new THREE.Mesh(
  new THREE.CircleGeometry(7, 64),
  new THREE.MeshStandardMaterial({ color: 0x1e2a22, roughness: 1 })
);
ground.rotation.x = -Math.PI / 2;
scene.add(ground);

// ---------- 1. 递归生成所有枝桠 ----------
const branches = [];
const UP = new THREE.Vector3(0, 1, 0);
function grow(start, dir, len, radius, depth) {
  const end = start.clone().addScaledVector(dir, len);
  branches.push({ start, end, radius, depth });
  if (depth === 0) return;                       // 递归终止条件，必须有！
  for (let i = 0; i < 3; i++) {
    const nd = dir.clone();
    nd.applyAxisAngle(UP, (i - 1) * 0.8);         // 绕竖轴散开
    nd.applyAxisAngle(new THREE.Vector3(1, 0, 0), 0.35 + Math.random() * 0.3); // 再向外倾
    nd.normalize();
    grow(end, nd, len * 0.72, radius * 0.68, depth - 1);
  }
}
grow(new THREE.Vector3(0, 0, 0), UP.clone(), 2.2, 0.24, 5);

// ---------- 2. 用 InstancedMesh 一次画完所有枝桠 ----------
const tree = new THREE.InstancedMesh(
  new THREE.CylinderGeometry(1, 1, 1, 8),
  new THREE.MeshStandardMaterial({ roughness: 0.9 }),
  branches.length
);
const dummy = new THREE.Object3D();
const dir = new THREE.Vector3();
const mid = new THREE.Vector3();
const trunkColor = new THREE.Color(0x6b4a2f);
const leafColor = new THREE.Color(0x7ddc6b);
branches.forEach((b, i) => {
  dir.subVectors(b.end, b.start);
  const len = dir.length();
  dir.normalize();
  mid.addVectors(b.start, b.end).multiplyScalar(0.5);
  dummy.position.copy(mid);
  dummy.quaternion.setFromUnitVectors(UP, dir);   // 把圆柱的 Y 轴对齐到枝条方向
  dummy.scale.set(b.radius, len, b.radius);
  dummy.updateMatrix();
  tree.setMatrixAt(i, dummy.matrix);
  tree.setColorAt(i, trunkColor.clone().lerp(leafColor, (5 - b.depth) / 5));
});
tree.instanceMatrix.needsUpdate = true;
tree.instanceColor.needsUpdate = true;
const treeGroup = new THREE.Group();
treeGroup.add(tree);
scene.add(treeGroup);

// ---------- 3. 飘落的叶子粒子 ----------
const N = 900;
const p = new Float32Array(N * 3);
const speeds = new Float32Array(N);
for (let i = 0; i < N; i++) {
  p[i*3]   = (Math.random() - 0.5) * 9;
  p[i*3+1] = Math.random() * 9;
  p[i*3+2] = (Math.random() - 0.5) * 9;
  speeds[i] = 0.6 + Math.random() * 1.2;
}
const pgeo = new THREE.BufferGeometry();
pgeo.setAttribute('position', new THREE.BufferAttribute(p, 3));
const leaves = new THREE.Points(pgeo, new THREE.PointsMaterial({
  color: 0xffe06b, size: 0.09, transparent: true, opacity: 0.9,
  depthWrite: false
}));
scene.add(leaves);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 2.5, 0);

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  const t = now / 1000;
  treeGroup.rotation.z = Math.sin(t * 0.8) * 0.03;   // 整棵树轻轻摇

  for (let i = 0; i < N; i++) {
    const o = i * 3;
    p[o+1] -= speeds[i] * dt;
    p[o]   += Math.sin(t * 1.5 + i) * 0.004;         // 左右微微飘
    if (p[o+1] < 0) {                                // 落地 → 回到树顶
      p[o+1] = 8 + Math.random() * 2;
      p[o]   = (Math.random() - 0.5) * 9;
      p[o+2] = (Math.random() - 0.5) * 9;
    }
  }
  pgeo.attributes.position.needsUpdate = true;
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
分形就是「自己长得像自己」：一根树枝分出三根小树枝，每根小树枝又分出三根更小的，形状规律一模一样，只是尺寸缩小。代码里就是函数 `grow()` 调用自己，每次把长度乘 `0.72`、半径乘 `0.68`、深度减 1。递归一定要有**终止条件**——这里的 `if (depth === 0) return` 就是刹车，没它函数会一直调用自己，直到浏览器报「栈溢出」。
:::

::: tip InstancedMesh 是「批量复印机」
如果 364 根枝桠建 364 个 Mesh，GPU 要画 364 次（draw call），卡得要命。`InstancedMesh` 的思路是：只上传**一份**圆柱几何体 + 一份材质，再加 N 个 4×4 变换矩阵，GPU 一次就把 N 个实例全画出来。每个实例的位置/旋转/缩放各不相同，但共享同一份几何数据。本案例的枝桠数 = `1+3+9+27+81+243 = 364`，一个 draw call 搞定。
:::

::: tip 怎么把圆柱摆成枝条的形状
圆柱默认沿 Y 轴竖直站立、高度为 1。要把 A 点到 B 点之间的一段枝条摆好，做三件事：① 位置放在中点 `(A+B)/2`；② 用 `quaternion.setFromUnitVectors(Y轴, 方向)` 把圆柱的 Y 轴转到 `B-A` 的方向；③ 缩放成 `(半径, 长度, 半径)`。用一个临时 `Object3D`（代码里的 `dummy`）当「积木模具」，摆好造型后 `updateMatrix()` 再把矩阵交给 `setMatrixAt(i, ...)` 就行。
:::

::: tip instanceColor 给每根枝条上色
`setColorAt(i, color)` 能给第 i 个实例单独指定颜色。这里按深度从棕色 `lerp` 到绿色：越靠近树根越棕，越靠近树梢越绿。改完记得 `tree.instanceColor.needsUpdate = true`，否则颜色不会上传到 GPU。`lerp` 是线性插值——`lerp(a, b, 0)` 得到 a，`lerp(a, b, 1)` 得到 b，中间值在两者之间。
:::

::: tip 落叶粒子用「回收」而不是「新建」
900 片叶子从头到尾就是同一批粒子，落到地面后不是销毁重建，而是把 y 坐标重置到树顶、x/z 重新随机，原地复用。这种「对象池」思路避免了每帧创建对象带来的垃圾回收抖动，是粒子系统的标准做法。想让叶子转起来，可以给 `PointsMaterial` 换一张带旋转的精灵贴图。
:::

## 四、改着玩

- 递归调用里的 `3` 改成 `2` → 二叉树，枝条数从 364 骤降到 63，树更清爽；改成 `4` → 深度 5 时有 1365 根，注意性能。
- 初始 `depth` 从 `5` 改成 `4` → 少一层分叉，树矮一截；改成 `6` → 树冠更密。
- `len * 0.72` 改成 `0.85` → 每一层缩短得少，枝条又细又长，像竹子；改成 `0.6` → 矮胖灌木。
- 落叶粒子数 `N = 900` 改成 `3000` → 漫天飞舞；`size: 0.09` 改成 `0.2` → 叶子变大。
- 把 `leafColor` 改成 `0xff88cc` → 粉色樱花树，配合 `trunkColor = 0x4a3b3b` 更像。
