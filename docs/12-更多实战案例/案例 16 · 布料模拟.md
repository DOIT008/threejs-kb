# 案例 16 · 布料模拟

旗子飘动、窗帘摆动、衣服穿在身上，底层都是同一套东西：把一块布拆成网格点，让点与点之间保持固定距离，再加点重力风力和约束求解。这篇用 Verlet 积分手写一块布：顶边固定，重力让它下垂，阵风让它翻卷，还能用鼠标揪住任意一角拖拽。

## 一、效果长啥样

一块格纹方布挂在半空，顶边被钉住，其余部分在重力下自然下垂、被风一阵阵吹得鼓起来。把鼠标移到布上按下，就能揪住最近的一个网格点四处拖拽，松手后布料弹回并继续飘动。格子纹路让形变一目了然。

```text
   ■ ■ ■ ■ ■ ■ ■ ■    ← 顶边顶点被 pin（钉死不动）
   │ │ │ │ │ │ │ │
   ●─●─●─●─●─●─●─●    ← 每个 ● 是一个粒子
   │ │ │ │ │ │ │ │
   ●─●─●─●─●─●─●─●
   │ │ │ │ │ │ │ │
   ●─●─●─●─●─●─●─●    ← 重力往下拉，风往 +Z 方向吹

   相邻点之间的距离被约束成「原长」→ 布不会拉长成蜘蛛网
   鼠标拖拽 = 把抓到的那个点暂时变成「钉子」并跟着鼠标走
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>布料模拟 · Verlet</title>
<style>
  body { margin: 0; overflow: hidden; }
  #tip {
    position: fixed; left: 16px; top: 16px; color: #fff;
    font: 14px/1.7 sans-serif; background: rgba(0,0,0,.55);
    padding: 10px 14px; border-radius: 8px; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="tip">布上按住鼠标可以揪住一角拖动 · 空白处拖动转视角</div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x141824);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 0, 9);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x334455, 2.2));
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(3, 5, 6);
scene.add(light);

const W = 6, H = 4, NX = 24, NY = 16;
const geo = new THREE.PlaneGeometry(W, H, NX, NY);
const pos = geo.attributes.position;
const count = pos.count;
const idx = (iy, ix) => iy * (NX + 1) + ix;

// 记录每个粒子的「当前位置」和「上一帧位置」——Verlet 不存速度
const cur = new Float32Array(count * 3);
const prev = new Float32Array(count * 3);
const pinned = new Uint8Array(count);
const colors = new Float32Array(count * 3);
for (let i = 0; i < count; i++) {
  cur[i*3] = prev[i*3] = pos.getX(i);
  cur[i*3+1] = prev[i*3+1] = pos.getY(i);
  cur[i*3+2] = prev[i*3+2] = pos.getZ(i);
  const iy = Math.floor(i / (NX + 1)), ix = i % (NX + 1);
  const c = ((ix + iy) % 2) ? 0x4ecdc4 : 0xff6b6b;
  const col = new THREE.Color(c);
  colors[i*3] = col.r; colors[i*3+1] = col.g; colors[i*3+2] = col.b;
}
geo.setAttribute('color', new THREE.BufferAttribute(colors, 3));
for (let ix = 0; ix <= NX; ix++) pinned[idx(0, ix)] = 1; // 顶边钉住

// 结构约束：相邻点之间保持原长（横 + 竖）
const links = [];
for (let iy = 0; iy <= NY; iy++) for (let ix = 0; ix < NX; ix++)
  links.push([idx(iy, ix), idx(iy, ix + 1), W / NX]);
for (let iy = 0; iy < NY; iy++) for (let ix = 0; ix <= NX; ix++)
  links.push([idx(iy, ix), idx(iy + 1, ix), H / NY]);

const cloth = new THREE.Mesh(geo, new THREE.MeshStandardMaterial({
  vertexColors: true, side: THREE.DoubleSide, roughness: 0.85
}));
scene.add(cloth);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();
const dragPlane = new THREE.Plane(new THREE.Vector3(0, 0, 1), 0);
const hit = new THREE.Vector3();
let grabbed = -1;

function setPointer(e) {
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
}

renderer.domElement.addEventListener('pointerdown', e => {
  if (!raycaster.ray.intersectPlane(dragPlane, hit)) return;
  let best = -1, bestD = Infinity;
  for (let i = 0; i < count; i++) {
    if (pinned[i]) continue;
    const dx = cur[i*3] - hit.x, dy = cur[i*3+1] - hit.y;
    const d = dx*dx + dy*dy;
    if (d < bestD) { bestD = d; best = i; }
  }
  if (bestD > 0.6 * 0.6) return;           // 离布太远就当作点空白
  grabbed = best;
  controls.enabled = false;
});

renderer.domElement.addEventListener('pointermove', e => {
  if (grabbed < 0) return;
  setPointer(e);
  if (raycaster.ray.intersectPlane(dragPlane, hit)) {
    cur[grabbed*3] = hit.x;
    cur[grabbed*3+1] = hit.y;
    cur[grabbed*3+2] = 0;
    prev[grabbed*3] = hit.x;               // 同步上一帧，避免松手瞬间获得巨大速度
    prev[grabbed*3+1] = hit.y;
    prev[grabbed*3+2] = 0;
  }
});
function release() { grabbed = -1; controls.enabled = true; }
addEventListener('pointerup', release);
addEventListener('pointercancel', release);

const DT2 = (1 / 60) ** 2;                 // 固定时间步，布料模拟更稳定
let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  const t = now / 1000;

  for (let i = 0; i < count; i++) {
    if (pinned[i] || i === grabbed) continue;
    const o = i * 3;
    const x = cur[o], y = cur[o+1], z = cur[o+2];
    const wind = Math.sin(t * 3 + x * 1.5 + y) * 14 + 6;
    cur[o]   = x + (x - prev[o])   * 0.99;
    cur[o+1] = y + (y - prev[o+1]) * 0.99 - 9.8 * DT2;   // 重力
    cur[o+2] = z + (z - prev[o+2]) * 0.99 + wind * DT2;  // 风
    prev[o] = x; prev[o+1] = y; prev[o+2] = z;
  }

  // 多迭代几次约束，布才「挺」；迭代 1~2 次会像丝绸一样软
  for (let k = 0; k < 6; k++) {
    for (const [a, b, rest] of links) {
      const ao = a*3, bo = b*3;
      const dx = cur[bo]-cur[ao], dy = cur[bo+1]-cur[ao+1], dz = cur[bo+2]-cur[ao+2];
      const d = Math.hypot(dx, dy, dz) || 1e-6;
      const f = (d - rest) / d * 0.5;
      const ox = dx*f, oy = dy*f, oz = dz*f;
      if (!pinned[a] && a !== grabbed) { cur[ao]+=ox; cur[ao+1]+=oy; cur[ao+2]+=oz; }
      if (!pinned[b] && b !== grabbed) { cur[bo]-=ox; cur[bo+1]-=oy; cur[bo+2]-=oz; }
    }
  }

  for (let i = 0; i < count; i++) {
    pos.setXYZ(i, cur[i*3], cur[i*3+1], cur[i*3+2]);
  }
  pos.needsUpdate = true;
  geo.computeVertexNormals();
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
Verlet 积分的狠活是**不存速度，只存位置**：每个粒子记「现在在哪」和「上一帧在哪」，两者相减就是速度。更新时新位置 = 当前位置 + (当前 - 上一帧)×阻尼 + 加速度×dt²。为什么要这么绕？因为布料的核心是「距离约束」——相邻点必须保持固定间距，而约束是直接改坐标的。用传统欧拉法你得改完位置再去修正速度，一修正就容易抖；Verlet 只管位置，约束改完就完事，又稳又简单。
:::

::: tip 顶边钉住 = 别把它算进物理
`pinned` 数组标记哪些粒子不动。更新位置、求解约束时全部 `if (pinned[i]) continue` 跳过，它们就成了挂在墙上的钉子。钉住一整排就是窗帘，只钉两个角就是横幅，一个角都不钉就是自由落体的桌布——改两行代码就能换玩法。
:::

::: tip 重力是 -9.8，风是正弦波
`cur[o+1] -= 9.8 * DT2` 里的 `DT2 = (1/60)²` 是时间步的平方，来自物理公式 `s = ½at²`（常数 ½ 被吸收进加速度系数了）。风用了 `sin(t*3 + x*1.5 + y)`：随时间变化让风一阵一阵，随位置变化让布面上不同点受力不同，于是出现波浪。用固定 `1/60` 而不是真实帧间隔，是因为约束求解对时间步很敏感，固定步长比「忽大忽小」稳定得多。
:::

::: tip 约束求解为什么要迭代 6 次
一根弹簧被拉长后，我们把它两端各拉回一半。但一根点被拉动会连带影响邻居，一次扫描下来整块布还没达到平衡。反复扫 6 遍，误差逐轮收敛，布才不容易被拉长成渔网。迭代次数越多布越「硬」：想要丝绸感改成 2 次，想要帆布感改成 10 次。
:::

::: tip 鼠标拖动就是临时钉子
抓到某个粒子后，把它当成「钉子」跳过物理更新，`pointermove` 时直接把它的坐标设成鼠标射线在 z=0 平面上的落点。松手时同步 `prev = cur` 很关键：否则这一帧的位置差会被当成巨大速度，布料「啪」地弹飞出去。想要甩布效果，可以故意让 `prev` 比 `cur` 落后一点。
:::

## 四、改着玩

- `NX = 24, NY = 16` 改成 `40, 28` → 网格更细、褶皱更柔和，但顶点数翻倍注意性能。
- 约束迭代 `k < 6` 改成 `k < 2` → 布料变得像丝绸一样软塌塌；改成 `12` → 像硬帆布。
- 风的 `14 + 6` 改成 `40 + 10` → 狂风乱舞；改成 `0` → 只剩重力，垂直落下。
- 重力 `- 9.8 * DT2` 改成 `- 2 * DT2` → 月球重力，慢慢飘落。
- 把顶边的 `pinned[idx(0, ix)] = 1` 改成只钉 `idx(0, 0)` 和 `idx(0, NX)` 两个角 → 变成横幅，中间会大幅下垂。
