# 案例 19 · 多点触控手势

手机上看 3D，最自然的交互就是：一根手指拖动转模型，两根手指捏合缩放、旋转。浏览器把这些手指动作通过 `touchstart` / `touchmove` 事件告诉我们，只要算一算手指之间的距离和夹角，就能做出和原生 App 一样顺滑的手感。这篇做一个专属的「手势控制器」，同时兼容桌面鼠标。

## 一、效果长啥样

屏幕中央一个环面纽结模型，周围点缀几颗小球。手机上一根手指滑动 → 模型跟着转；两根手指捏合/张开 → 模型缩小/放大；两根手指转动 → 模型绕屏幕法线旋转。桌面上则用鼠标左键拖动旋转、滚轮缩放。左上角实时显示缩放倍数和旋转角度。

```text
   单指：touchstart 记下起点 → touchmove 算 dx,dy
                              dx → rotation.y，dy → rotation.x

   双指：touchstart 记下 (距离 d0, 夹角 a0)
                              touchmove 算 (距离 d1, 夹角 a1)
                              d1/d0 → 缩放倍数
                              a1-a0 → 绕 Z 旋转（±π 跨越要修正）
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
<title>多点触控手势</title>
<style>
  body { margin: 0; overflow: hidden; touch-action: none; }
  canvas { display: block; touch-action: none; }
  #hud {
    position: fixed; left: 12px; top: 12px; color: #fff;
    font: 13px/1.7 sans-serif; background: rgba(0,0,0,.55);
    padding: 8px 12px; border-radius: 8px; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="hud">单指旋转 · 双指缩放/转动 · 桌面：鼠标拖动 + 滚轮</div>
<script type="module">
import * as THREE from 'three';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x11151f);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 0, 6);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x334455, 2.2));
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(4, 6, 5);
scene.add(light);

// 要被手势操控的模型组
const model = new THREE.Group();
scene.add(model);
model.add(new THREE.Mesh(
  new THREE.TorusKnotGeometry(1.1, 0.36, 128, 20),
  new THREE.MeshStandardMaterial({ color: 0x4ecdc4, roughness: 0.3, metalness: 0.4 })
));
const colors = [0xff6b6b, 0xffd166, 0x8b7cf6];
for (let i = 0; i < 3; i++) {
  const a = i / 3 * Math.PI * 2;
  const m = new THREE.Mesh(
    new THREE.SphereGeometry(0.18, 20, 20),
    new THREE.MeshStandardMaterial({ color: colors[i], emissive: colors[i], emissiveIntensity: 0.35 })
  );
  m.position.set(Math.cos(a) * 2.2, Math.sin(a) * 2.2, 0);
  model.add(m);
}

// 工具：取所有手指坐标、两点距离、两点连线夹角
const pts = e => Array.from(e.touches, t => ({ x: t.clientX, y: t.clientY }));
const dist = (a, b) => Math.hypot(a.x - b.x, a.y - b.y);
const angle = (a, b) => Math.atan2(b.y - a.y, b.x - a.x);
const TAU = Math.PI * 2;
function angleDiff(now, before) {
  let d = now - before;
  while (d > Math.PI) d -= TAU;              // 处理 +π / -π 的跳变
  while (d < -Math.PI) d += TAU;
  return d;
}

let prev = [];
let lastDist = 0, lastAngle = 0;
const hud = document.getElementById('hud');
function updateHud() {
  hud.textContent = `缩放 ${model.scale.x.toFixed(2)}× · `
    + `Y ${Math.round(model.rotation.y * 180 / Math.PI)}° · `
    + `Z ${Math.round(model.rotation.z * 180 / Math.PI)}°`;
}

renderer.domElement.addEventListener('touchstart', e => {
  e.preventDefault();                        // 阻止浏览器滚动/双击缩放
  const now = pts(e);
  if (now.length === 2) { lastDist = dist(now[0], now[1]); lastAngle = angle(now[0], now[1]); }
  prev = now;
}, { passive: false });

renderer.domElement.addEventListener('touchmove', e => {
  e.preventDefault();
  const now = pts(e);
  if (now.length === 1 && prev.length === 1) {
    model.rotation.y += (now[0].x - prev[0].x) * 0.01;
    model.rotation.x += (now[0].y - prev[0].y) * 0.01;
  } else if (now.length === 2 && prev.length === 2) {
    const d = dist(now[0], now[1]);
    const a = angle(now[0], now[1]);
    if (lastDist > 0) {
      const s = THREE.MathUtils.clamp(d / lastDist, 0.5, 2); // 单帧最多放大/缩小 2 倍
      model.scale.multiplyScalar(s);
      model.scale.clampScalar(0.4, 4);
    }
    model.rotation.z += angleDiff(a, lastAngle);
    lastDist = d; lastAngle = a;
  }
  prev = now;
  updateHud();
}, { passive: false });

function endTouch(e) {
  e.preventDefault();
  prev = pts(e);                             // 剩几根手指就从几根继续
  if (prev.length < 2) lastDist = 0;
}
renderer.domElement.addEventListener('touchend', endTouch, { passive: false });
renderer.domElement.addEventListener('touchcancel', endTouch, { passive: false });

// 桌面兜底：鼠标拖动旋转 + 滚轮缩放
let dragging = false, mx = 0, my = 0;
renderer.domElement.addEventListener('pointerdown', e => {
  if (e.pointerType === 'touch') return;     // 触摸交给上面的 touch 事件
  dragging = true; mx = e.clientX; my = e.clientY;
});
renderer.domElement.addEventListener('pointermove', e => {
  if (!dragging) return;
  model.rotation.y += (e.clientX - mx) * 0.01;
  model.rotation.x += (e.clientY - my) * 0.01;
  mx = e.clientX; my = e.clientY;
  updateHud();
});
addEventListener('pointerup', () => { dragging = false; });
renderer.domElement.addEventListener('wheel', e => {
  e.preventDefault();
  model.scale.multiplyScalar(e.deltaY > 0 ? 0.92 : 1.08);
  model.scale.clampScalar(0.4, 4);
  updateHud();
}, { passive: false });

renderer.setAnimationLoop(() => {
  renderer.render(scene, camera);
});
addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
触摸事件和鼠标事件最大的不同是「可以同时有好几根手指」。`e.touches` 就是当前所有手指的列表，每根都有 `clientX/clientY`。两根手指之间的距离变大 = 用户在「张开」，我们就把模型放大；距离变小 = 「捏合」，就缩小。两根手指连线的角度变了 = 用户在「拧」，就让模型跟着转。所以手势识别的本质就是两件事：**算距离、算角度**。
:::

::: tip touch-action: none 是第一个坑
如果不写 CSS 的 `touch-action: none`，手指在 canvas 上滑动时，浏览器会先把它当成「页面滚动」或「双指缩放网页」，直接接管事件，你的 `touchmove` 可能只收到一两次就不动了。另外监听时要传 `{ passive: false }` 并在回调里 `e.preventDefault()`，明确告诉浏览器「这次触摸我自己处理，别滚动」。`<meta name="viewport" ... user-scalable=no>` 也是同一目的——禁掉网页自带缩放。
:::

::: tip 捏合缩放为什么用「比例」而不是「差值」
`d1 / d0` 是相对变化：手指距离从 100px 变到 150px，比例 1.5，模型就放大 1.5 倍，这与手指原来离多远无关。如果用 `d1 - d0 = 50px` 当增量，同样的 50px 在近距离时是巨变、远距离时几乎没反应，手感会飘。再用 `clamp(d/lastDist, 0.5, 2)` 限制单帧倍率，防止某帧事件抖动导致模型瞬间放大到天上去。
:::

::: tip 角度跨越 ±π 的处理
`atan2()` 返回的角度范围是 `-π ~ +π`。当两根手指转过正上方时，角度会从 `+3.14` 瞬间跳到 `-3.14`，直接相减会得到接近 `-6.28` 的假差值，模型猛地转一大圈。`angleDiff()` 用循环把差值拉回 `-π ~ +π` 区间：大于 π 就减 2π，小于 -π 就加 2π。这个「角度归一化」是所有旋转手势的必备补丁。
:::

::: tip touchcancel 和多指接力
手指可能被系统手势、来电打断，浏览器会发 `touchcancel`，要像 `touchend` 一样处理，否则状态会卡住。从双指变成单指时（抬起一根），要用剩下的那根手指重新作为旋转起点，`prev = pts(e)` 这行就是在做「接力」，避免下一帧突然用旧坐标算出一个巨大的 dx。
:::

## 四、改着玩

- `model.rotation.y += dx * 0.01` 的 `0.01` 改成 `0.02` → 转得更快；改成 `0.005` → 更细腻。
- `clampScalar(0.4, 4)` 改成 `(0.2, 8)` → 允许缩得更小、放得更大。
- 双指时再加「平移」：算两指中点 `((a.x+b.x)/2, (a.y+b.y)/2)`，把它的位移映射到 `model.position.x/y`，就能边缩放边拖着模型走。
- 给 `model.rotation.z` 的增量乘 `0.5` → 双指拧转的灵敏度减半，更从容。
- 把单指旋转的 `rotation.x` 累加限制在 `±Math.PI/2` → 防止模型翻过头看背面蒙圈。
