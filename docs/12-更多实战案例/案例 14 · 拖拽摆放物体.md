# 案例 14 · 拖拽摆放物体

做编辑器、搭建场景、摆放家具，最常用的交互就是「点住一个东西拖着走，松手自动对齐格子」。这篇用射线拾取 + 平面投影实现这套手感：鼠标按住立方体拖动，它贴着地面走，松开时「咔哒」一下吸附到网格上。

## 一、效果长啥样

灰白网格地面上散落着几个彩色立方体。鼠标移到方块上它会高亮，按住拖动时方块微微抬起、跟着鼠标在地面上滑行；松开鼠标，方块自动对齐到最近的网格交点，落回地面。空白处拖动则是旋转视角（OrbitControls）。

```text
   屏幕上的鼠标 (clientX, clientY)
            │ 换算
            ▼
   标准化设备坐标 NDC（-1 ~ +1）
            │ raycaster.setFromCamera()
            ▼
   一条射进场景的射线 ────碰────► 立方体（拾取成功 = 抓住它）
            │
            │ ray.intersectPlane(y=0 的无限平面)
            ▼
   地面上的落点 → 减去抓取偏移 → 成为方块新位置
            │ 松手
            ▼
   Math.round(x / 网格) × 网格 → 吸附对齐
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>拖拽摆放物体</title>
<style>
  body { margin: 0; overflow: hidden; cursor: grab; }
  #tip {
    position: fixed; left: 16px; top: 16px; color: #fff;
    font: 14px/1.7 sans-serif; background: rgba(0,0,0,.55);
    padding: 10px 14px; border-radius: 8px; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="tip">拖动方块摆放 · 拖动空白处转视角</div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0xe8edf5);

const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(7, 8, 10);
camera.lookAt(0, 0, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFShadowMap;
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x8899aa, 2.2));
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(5, 10, 6);
sun.castShadow = true;
scene.add(sun);

// 地面 + 网格参考线
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0xf4f6fa })
);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);
const grid = new THREE.GridHelper(40, 40, 0x8899aa, 0xc4ccda);
grid.position.y = 0.01;
scene.add(grid);

// 几个可拖动的方块
const colors = [0xff6b6b, 0x4ecdc4, 0xffd166, 0x8b7cf6];
const boxes = colors.map((c, i) => {
  const m = new THREE.Mesh(
    new THREE.BoxGeometry(1, 1, 1),
    new THREE.MeshStandardMaterial({ color: c })
  );
  m.position.set((i - 1.5) * 3, 0.5, (i % 2 ? 2 : -2));
  m.castShadow = true;
  m.userData.baseColor = c;
  scene.add(m);
  return m;
});

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();
const plane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0); // y = 0 的地面
const hit = new THREE.Vector3();
const offset = new THREE.Vector3();
let dragging = null;
let hovered = null;

function setPointer(e) {
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
}

renderer.domElement.addEventListener('pointerdown', e => {
  setPointer(e);
  const found = raycaster.intersectObjects(boxes)[0];
  if (!found) return;
  dragging = found.object;
  controls.enabled = false;                 // 拖方块时先关掉转视角
  document.body.style.cursor = 'grabbing';
  // 记录「抓地点」与「方块中心」的差值，拖起来才不会瞬间跳到鼠标下
  if (raycaster.ray.intersectPlane(plane, hit)) offset.copy(hit).sub(dragging.position);
});

renderer.domElement.addEventListener('pointermove', e => {
  setPointer(e);
  if (dragging) {
    if (raycaster.ray.intersectPlane(plane, hit)) {
      dragging.position.x = hit.x - offset.x;
      dragging.position.z = hit.z - offset.z;
      dragging.position.y = 1;              // 拖起来时抬高一截
    }
    return;
  }
  const found = raycaster.intersectObjects(boxes)[0];
  const now = found ? found.object : null;
  if (now !== hovered) {
    if (hovered) hovered.material.color.setHex(hovered.userData.baseColor);
    if (now) now.material.color.setHex(0xffffff);
    hovered = now;
  }
});

function drop() {
  if (!dragging) return;
  const g = 1;                              // 网格大小
  dragging.position.x = Math.round(dragging.position.x / g) * g;
  dragging.position.z = Math.round(dragging.position.z / g) * g;
  dragging.position.y = 0.5;                // 落回地面
  dragging = null;
  controls.enabled = true;
  document.body.style.cursor = 'grab';
}
addEventListener('pointerup', drop);
addEventListener('pointercancel', drop);

renderer.setAnimationLoop(() => {
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
`Raycaster`（射线检测器）就像从相机镜头射出的一支激光笔：你把鼠标位置告诉它，它沿着那条线打进场景，凡是被线穿过的物体都会被「命中」。`intersectObjects()` 返回命中列表，按距离从近到远排，所以 `[0]` 就是最上面那个——这正好实现「点谁抓谁」。鼠标坐标要先从像素换算成 **NDC**（标准化设备坐标，范围 -1 到 +1，左上角是 `(-1, 1)`），`Raycaster` 只认这套坐标。
:::

::: tip 为什么要用数学平面来投影
拿到射线之后，`ray.intersectPlane(plane, hit)` 会算出「这条射线穿过 y=0 平面的哪个点」。这里的 `THREE.Plane` 不是能看见的地面模型，而是一个**数学上的无限平面**——它没有边界、没有破洞、计算极快。如果改用射线和地面 Mesh 求交，一旦鼠标拖出地板边缘就拾取失败了。用数学平面，鼠标拖到天边也能算出落点。
:::

::: tip offset 是「手感」的关键
如果求出地面落点后直接 `box.position.copy(hit)`，方块会「嗖」地一下把中心跳到鼠标下——因为你抓的是方块的角，不是中心。正确做法是按下时记下 `offset = 抓地点 - 方块中心`，拖动时 `位置 = 落点 - offset`。这样方块相对于鼠标的抓握关系保持不变，拖起来才像真的在手里。这个小细节是「能用」和「好用」的分界线。
:::

::: tip 吸附就是四舍五入到网格
松开时 `Math.round(x / 网格大小) * 网格大小` 一行搞定：先除以格宽看落在第几格，四舍五入取整，再乘回去。比如格宽 1、x=2.37 → round(2.37)=2 → 吸到 2。想做半格吸附就把格宽设成 `0.5`。拖动期间记得 `controls.enabled = false`，否则你拖方块的同时相机也在转，场面会非常晕。
:::

## 四、改着玩

- 把 `const g = 1` 改成 `0.5` → 半格吸附，摆得更精细；改成 `2` → 只能放在偶数格上。
- 拖动时 `dragging.position.y = 1` 改成 `1.5` → 抬得更高，阴影离方块更远，悬浮感更强。
- 给方块加 `m.rotation.y` 在 `drop()` 里也 `Math.round(.../(Math.PI/4))*(Math.PI/4)` → 松手时旋转也吸附到 45°。
- 把 `GridHelper(40, 40, ...)` 的第二个参数改成 `20` → 格子变大，吸附间距自动跟着 `g` 调成 `2` 才对得上。
- 在 `pointermove` 的高亮逻辑里改成 `now.material.emissive.setHex(0x333333)` → 用自发光高亮，比直接染白更自然。
