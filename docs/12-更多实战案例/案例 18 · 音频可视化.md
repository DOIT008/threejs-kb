# 案例 18 · 音频可视化

音乐播放器里那种「跟着节拍跳动的可视化条」是怎么做的？答案不神秘：浏览器能把声音拆成各个频率的能量表，我们拿这张表去控制柱子的高矮就行。这篇用 Web Audio API 生成一个不断变调的音符，再用 `AnalyserNode` 的频谱数据驱动一圈 3D 光柱。

## 一、效果长啥样

深色场景里，64 根彩色光柱围成一圈。点击「开启声音」后，一段合成音开始播放，柱子随频率高低此起彼伏地跳动——低音区柱子高、高音区柱子矮，音符每 0.22 秒换一次，柱浪跟着节奏流动。拖拽鼠标可以环绕观察。

```text
   点击授权 → AudioContext.resume()
        │
   振荡器 Oscillator（发出锯齿波）
        │  不断换频率：220 → 261 → 293 → …
   低通滤波器 BiquadFilter（改变音色，制造频谱变化）
        │
   分析器 AnalyserNode ──getByteFrequencyData──► [128 个 0~255 的数]
        │                                            │
        └──────► 扬声器                      第 i 个数 → 第 i 根柱子的高度
                                              height = 0.2 + v/255 × 5
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>音频可视化</title>
<style>
  body { margin: 0; overflow: hidden; }
  #overlay {
    position: fixed; inset: 0; display: flex; align-items: center;
    justify-content: center; color: #fff; cursor: pointer;
    font: 20px/1.7 sans-serif; background: rgba(8,10,18,.85);
    flex-direction: column; gap: 8px;
  }
  #overlay small { font-size: 13px; opacity: .7; }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="overlay">点击开启声音<small>浏览器要求用户交互后才能播放音频 · 建议先调低音量</small></div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x080a12);
scene.fog = new THREE.Fog(0x080a12, 16, 34);

const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 9, 15);
camera.lookAt(0, 1, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x222233, 2));
const light = new THREE.DirectionalLight(0xffffff, 1.6);
light.position.set(5, 10, 4);
scene.add(light);

const floor = new THREE.Mesh(
  new THREE.CircleGeometry(9, 64),
  new THREE.MeshStandardMaterial({ color: 0x111522, roughness: 1 })
);
floor.rotation.x = -Math.PI / 2;
scene.add(floor);

// 64 根柱子围成一圈，用 InstancedMesh 一次画完
const NUM = 64, R = 5.2;
const bars = new THREE.InstancedMesh(
  new THREE.BoxGeometry(0.32, 1, 0.32),
  new THREE.MeshStandardMaterial({ roughness: 0.35, metalness: 0.2 }),
  NUM
);
const dummy = new THREE.Object3D();
const color = new THREE.Color();
const angles = [];
for (let i = 0; i < NUM; i++) {
  const a = i / NUM * Math.PI * 2;
  angles.push(a);
  dummy.position.set(Math.cos(a) * R, 0.5, Math.sin(a) * R);
  dummy.scale.set(1, 1, 1);
  dummy.updateMatrix();
  bars.setMatrixAt(i, dummy.matrix);
  bars.setColorAt(i, color.setHSL(i / NUM, 0.85, 0.55));
}
bars.instanceMatrix.needsUpdate = true;
bars.instanceColor.needsUpdate = true;
scene.add(bars);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 1.5, 0);

// ---------- Web Audio：点击后才创建，符合浏览器自动播放策略 ----------
let ctx, analyser, freqData, osc, filter;
const notes = [220, 261.63, 293.66, 329.63, 392, 440, 523.25, 587.33];
let note = 0;

document.getElementById('overlay').addEventListener('click', async () => {
  if (ctx) { await ctx.resume(); return; }
  ctx = new (window.AudioContext || window.webkitAudioContext)();
  await ctx.resume();

  analyser = ctx.createAnalyser();
  analyser.fftSize = 256;                       // → 128 个频段
  analyser.smoothingTimeConstant = 0.78;        // 数值平滑，柱子不抽搐
  freqData = new Uint8Array(analyser.frequencyBinCount);

  osc = ctx.createOscillator();
  osc.type = 'sawtooth';
  osc.frequency.value = notes[0];
  filter = ctx.createBiquadFilter();
  filter.type = 'lowpass';
  filter.frequency.value = 1200;

  const gain = ctx.createGain();
  gain.gain.value = 0.05;                       // 音量调小，别吓到自己
  osc.connect(filter);
  filter.connect(analyser);
  analyser.connect(gain);
  gain.connect(ctx.destination);
  osc.start();

  setInterval(() => {
    note = (note + 1) % notes.length;
    osc.frequency.setTargetAtTime(notes[note], ctx.currentTime, 0.03);
    filter.frequency.setTargetAtTime(600 + Math.random() * 2600, ctx.currentTime, 0.05);
  }, 220);
  document.getElementById('overlay').style.display = 'none';
});

renderer.setAnimationLoop(() => {
  if (analyser) {
    analyser.getByteFrequencyData(freqData);
    for (let i = 0; i < NUM; i++) {
      // 幂函数映射：低频段占更多柱子，视觉上更均衡
      const bin = Math.min(freqData.length - 1,
        Math.floor(Math.pow(i / NUM, 1.6) * 110) + 1);
      const h = 0.2 + freqData[bin] / 255 * 5;
      const a = angles[i];
      dummy.position.set(Math.cos(a) * R, h / 2, Math.sin(a) * R);
      dummy.scale.set(1, h, 1);
      dummy.updateMatrix();
      bars.setMatrixAt(i, dummy.matrix);
      bars.setColorAt(i, color.setHSL(i / NUM, 0.85, 0.35 + h / 18));
    }
    bars.instanceMatrix.needsUpdate = true;
    bars.instanceColor.needsUpdate = true;
  }
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
`AnalyserNode` 就像给声音做「心电图」：它把当前一小段时间里的声音按频率切开，数一数每个频段有多少能量，返回一个 0~255 的数组。下标小的元素代表低音（鼓点贝斯），下标大的代表高音（镲片）。我们把数组里第 i 个数当成第 i 根柱子的身高——能量 0 就矮矮趴着，能量 255 就窜到最高。于是「听不见的数字」变成了「看得见的跳动」。
:::

::: tip 为什么必须点击才能出声
浏览器的自动播放策略规定：网页不能未经用户操作就播放声音。所以 `new AudioContext()` 之后它往往处于 `suspended`（挂起）状态，必须在点击事件里调用 `ctx.resume()` 才能启动。代码里把整个音频初始化都放在点击回调中，正是这个原因。想用麦克风的话，把振荡器换成 `navigator.mediaDevices.getUserMedia({audio:true})` 再 `ctx.createMediaStreamSource(stream)` 接到 analyser 即可，同样要点击授权。
:::

::: tip 连线图：振荡器 → 滤波 → 分析 → 音量 → 输出
Web Audio 像搭乐高：`osc.connect(filter)` 把音源接进滤波器，`filter.connect(analyser)` 再接分析器，`analyser.connect(gain)` 接音量旋钮，最后 `gain.connect(ctx.destination)` 送到扬声器。分析器是**旁路**的——声音经过它不受影响，它只是偷偷复制一份数据给我们看。每 0.22 秒换一次音高、顺手抖一下滤波器截止频率，频谱才会不断变化，柱子才不会一动不动。
:::

::: tip fftSize 决定「切片精度」
`fftSize = 256` 会得到 `frequencyBinCount = 128` 个频段，每个频段宽约 `采样率/256 ≈ 172Hz`。想看得更细就调到 512 或 1024（数组更长，但柱子也更多、计算更重）。注意低频段往往能量大、高频段几乎为 0，直接用 `data[i]` 会导致只有左边几根柱子动。代码里用 `Math.pow(i/NUM, 1.6)` 做非线性映射，把低频段「拉宽」分给更多柱子，画面就均衡了。
:::

::: tip 柱子其实只有一份网格
和分形树一个套路：64 根柱子是同一个 `BoxGeometry` 的 64 个实例。每帧根据频谱更新每个实例的矩阵（改 y 缩放和位置）和颜色（`setColorAt`），最后两个 `needsUpdate = true` 把数据推给 GPU。如果建 64 个独立 Mesh，代码更长、性能更差，InstancedMesh 是这种「大量同类物体」场景的标准答案。
:::

## 四、改着玩

- `analyser.fftSize` 改成 `512` → 频段翻倍到 256，把 `NUM` 也改成 `128` 才能用满数据。
- `gain.gain.value = 0.05` 改成 `0.2` → 声音变大（可视化效果不变，小心耳朵）。
- `notes` 数组换成自己喜欢的音阶，比如 `[261.63, 293.66, 349.23, 392, 440, 523.25]` → C 大调五声音阶，更好听。
- `osc.type = 'sawtooth'` 改成 `'square'` → 方波，频谱更极端；改成 `'sine'` → 正弦波，只有一根柱子亮。
- `setInterval(..., 220)` 改成 `120` → 节奏加快一倍；改成 `500` → 慢节奏，柱子变化更舒缓。
- 想用麦克风：把 `osc` 换成 `getUserMedia` 的流，记得 `analyser.connect(ctx.destination)` 要删掉，否则会啸叫。
