# 案例 20 · 昼夜切换

很多场景需要「时间流逝」：白天阳光明媚，黄昏染成橘红，夜里星星出来、灯光亮起。这背后没有魔法，就是把一个 0~1 的时间变量同时喂给太阳位置、天空颜色、灯光强度和星星透明度。这篇做一个可调时间、可自动循环的完整昼夜系统。

## 一、效果长啥样

一片草地上立着几栋简单建筑，天空中太阳沿弧线东升西落。拖动时间滑杆，能看到天空从湛蓝渐变到橘红的黄昏再到深蓝的夜空；太阳落到地平线下后，月亮升起、星星一颗颗浮现、建筑的窗户透出光。点「自动」按钮则时间自行流逝，循环往复。

```text
   time 0 ───── 0.25 ───── 0.5 ───── 0.75 ───── 1
  午夜          日出         正午         日落        午夜
    │            │            │            │          │
  高度 y = sin((time - 0.25) × 2π)
              0              +1            0         -1
    │            │            │            │          │
  夜晚 ───────→ 白天 ──────────────────→ 夜晚
  星星 opacity 1 → 0 ──────────────────→ 1
  太阳光 0 → 2.5 → 0；月光 0.6 → 0 → 0.6
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>昼夜切换</title>
<style>
  body { margin: 0; overflow: hidden; }
  #ui {
    position: fixed; left: 16px; bottom: 16px; color: #fff;
    font: 14px/1.8 sans-serif; background: rgba(0,0,0,.5);
    padding: 10px 14px; border-radius: 8px;
  }
  #ui input { vertical-align: middle; width: 220px; }
  #ui button { margin-left: 8px; cursor: pointer; }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="ui">时间 <input id="time" type="range" min="0" max="1" step="0.001" value="0.28">
  <span id="label">06:43</span> <button id="auto">自动：开</button></div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
scene.fog = new THREE.Fog(0x87ceeb, 25, 70);

const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 200);
camera.position.set(10, 7, 14);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFShadowMap;
document.body.appendChild(renderer.domElement);

// 三套颜色：白天、黄昏、夜晚
const SKY_DAY = new THREE.Color(0x87ceeb);
const SKY_DUSK = new THREE.Color(0xff9251);
const SKY_NIGHT = new THREE.Color(0x050a18);
const GROUND_DAY = new THREE.Color(0x6ba85c);
const GROUND_NIGHT = new THREE.Color(0x182028);
const skyColor = new THREE.Color();
const clamp = THREE.MathUtils.clamp;
const smooth = THREE.MathUtils.smoothstep;

// 光源：太阳（暖白）、月亮（冷蓝）、环境补光
const sunLight = new THREE.DirectionalLight(0xffffff, 2.5);
sunLight.castShadow = true;
scene.add(sunLight);
const moonLight = new THREE.DirectionalLight(0x88aaff, 0);
scene.add(moonLight);
const hemi = new THREE.HemisphereLight(0xffffff, 0x556644, 2);
scene.add(hemi);

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(80, 80),
  new THREE.MeshStandardMaterial({ color: 0x6ba85c, roughness: 1 })
);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);

const buildingMat = new THREE.MeshStandardMaterial({ color: 0x9aa3ad, roughness: 0.8 });
for (let i = 0; i < 6; i++) {
  const h = 2 + Math.random() * 4;
  const b = new THREE.Mesh(new THREE.BoxGeometry(2, h, 2), buildingMat);
  b.position.set((i - 2.5) * 4, h / 2, -6 - (i % 2) * 3);
  b.castShadow = true;
  scene.add(b);
}

// 太阳 / 月亮的可视小球
const sunBall = new THREE.Mesh(
  new THREE.SphereGeometry(1.6, 24, 24),
  new THREE.MeshBasicMaterial({ color: 0xffe08a })
);
const moonBall = new THREE.Mesh(
  new THREE.SphereGeometry(1.1, 24, 24),
  new THREE.MeshBasicMaterial({ color: 0xdce8ff })
);
scene.add(sunBall, moonBall);

// 星空：一次性生成 1000 个点，靠透明度控制显隐
const N = 1000;
const sp = new Float32Array(N * 3);
for (let i = 0; i < N; i++) {
  const a = Math.random() * Math.PI * 2;
  const b = Math.random() * 0.9 + 0.08;      // 只在地平线以上
  const r = 90;
  sp[i*3]   = Math.cos(a) * Math.cos(b) * r;
  sp[i*3+1] = Math.sin(b) * r;
  sp[i*3+2] = Math.sin(a) * Math.cos(b) * r;
}
const sgeo = new THREE.BufferGeometry();
sgeo.setAttribute('position', new THREE.BufferAttribute(sp, 3));
const starMat = new THREE.PointsMaterial({
  color: 0xffffff, size: 0.5, transparent: true, opacity: 0, depthWrite: false
});
const stars = new THREE.Points(sgeo, starMat);
scene.add(stars);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 2, -3);

const slider = document.getElementById('time');
const label = document.getElementById('label');
const btn = document.getElementById('auto');
let auto = true;
let time = 0.28;
btn.addEventListener('click', () => {
  auto = !auto;
  btn.textContent = `自动：${auto ? '开' : '关'}`;
});

function applyTime(t) {
  const angle = (t - 0.25) * Math.PI * 2;
  const h = Math.sin(angle);                     // 太阳高度 -1 ~ +1
  const day = smooth(h, -0.12, 0.2);             // 白天程度 0~1
  const night = 1 - day;

  // 天空：夜 → 昼插值，靠近地平线时再混一点黄昏橘
  skyColor.copy(SKY_NIGHT).lerp(SKY_DAY, day);
  skyColor.lerp(SKY_DUSK, clamp(1 - Math.abs(h) * 4, 0, 1) * 0.7);
  scene.background = skyColor;
  scene.fog.color.copy(skyColor);
  ground.material.color.copy(GROUND_NIGHT).lerp(GROUND_DAY, day);

  // 灯光：太阳升高时变白变亮，月亮反之
  sunLight.position.set(Math.cos(angle) * 30, h * 30, 8);
  sunLight.color.set(0xffb070).lerp(new THREE.Color(0xffffff), smooth(h, 0, 0.5));
  sunLight.intensity = day * 2.5;
  moonLight.position.set(-Math.cos(angle) * 30, -h * 30, -8);
  moonLight.intensity = night * 0.7;
  hemi.intensity = 0.15 + day * 1.9;

  sunBall.position.copy(sunLight.position).multiplyScalar(1.6);
  moonBall.position.copy(moonLight.position).multiplyScalar(1.6);
  starMat.opacity = night;

  const minutes = Math.floor(t * 24 * 60);
  label.textContent = `${String(Math.floor(minutes / 60)).padStart(2,'0')}:${String(minutes % 60).padStart(2,'0')}`;
}

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);
  last = now;
  if (auto) {
    time = (time + dt * 0.02) % 1;              // 约 50 秒走完一天
    slider.value = time;
  } else {
    time = Number(slider.value);
  }
  applyTime(time);
  stars.rotation.y += dt * 0.005;
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
整个昼夜系统其实只有**一个变量**：`time`（0 到 1 代表一天）。所有效果都由它推导：太阳高度 `sin((time-0.25)×2π)`，白天程度 `day`，夜晚程度 `night = 1 - day`。然后拿 `day` 当「调色盘的滑块」去混天空色、当「调光器」去控制灯光强度、当「开关」去控制星星透明度。理解了「一个变量驱动一切」，你就能自己加雾、加萤火虫、加路灯——都是同一套套路。
:::

::: tip 用 sin 算太阳高度，用 smoothstep 算白天程度
太阳一天转一圈，高度自然是正弦曲线：日出时 0、正午最高 +1、日落回 0、午夜最低 -1。`smoothstep(h, -0.12, 0.2)` 把高度平滑地映射成 0~1：低于 -0.12 算全黑，高于 0.2 算全亮，中间做平滑过渡。它比 `if` 硬切换自然得多——日出日落是「渐渐」亮的，不是「啪」一下开灯。
:::

::: tip Color.lerp 是调色盘
`a.lerp(b, t)` 表示「从颜色 a 往颜色 b 走 t 的比例」：t=0 得到 a，t=1 得到 b，0.5 是中间色。代码里先 `夜色.lerp(昼色, day)`，再在靠近地平线时 `lerp(黄昏橘, dusk)`——两层插值叠出「夜 → 橘红黄昏 → 蓝天」的连续变化。地面颜色、太阳光颜色（地平线偏橘、正午偏白）用的是同一个方法。
:::

::: tip 星星为什么用透明度而不是 visible
用 `starMat.opacity = night` 让星星**渐隐渐现**，比 `stars.visible = (night > 0.5)` 的突然出现自然太多。前提是材质设 `transparent: true`；再加 `depthWrite: false`，防止星星写深度后把后面的天空挡住。1000 颗星是一次性生成的 `Points`，整辈子只更新一个 opacity 数字，几乎零开销。
:::

::: tip 平行光的位置只决定「方向」
`DirectionalLight` 照向它的 `target`（默认原点），所以改 `position` 就是改光照方向，不用手动 `lookAt`。太阳和月亮放在相对的两侧（`moonLight` 的坐标取反），一个落下另一个正好升起。阴影贴图会跟着光源走，所以太阳落到地平线下时把强度设为 0，既省性能也避免奇怪的下方阴影。
:::

## 四、改着玩

- `time = time + dt * 0.02` 的 `0.02` 改成 `0.005` → 一天拉长到 200 秒，适合慢慢欣赏；改成 `0.1` → 10 秒快进。
- `SKY_DUSK = 0xff9251` 改成 `0xff2255` → 赛博朋克紫色黄昏。
- 建筑的 `buildingMat` 加 `emissive: 0xffdd88, emissiveIntensity: 0`（初始 0），在 `applyTime` 里写 `buildingMat.emissiveIntensity = night * 0.8` → 夜晚窗户亮灯。
- 星空 `size: 0.5` 改成 `1.2`、`N = 1000` 改成 `3000` → 满天繁星。
- 给雾的浓度随夜晚变化：`scene.fog.near = 25 - night * 15` → 夜里更朦胧。
