# 案例 21 · 物理弹跳

不用 cannon.js、不用 Rapier，自己写一个够用的物理引擎其实没那么难：每帧给球加重力、更新位置，然后检查有没有撞地、撞墙、撞到别的球，撞了就把速度按「弹回来」的规则改一改。这篇做十几个彩球落地弹跳、互相碰撞，能量逐渐衰减最后安静地躺平——点一下球还能把它重新弹起来。

## 一、效果长啥样

十几个大小不一的彩球从空中落下，砸到地面「啪嗒啪嗒」反弹，撞到一起会互相弹开。每次反弹高度都比上次低一点（能量衰减），最后全都滚停在地面上。用鼠标点击任意球，会给它一个向上的冲量，让它跳起来继续撞别人。

```text
   每帧循环（拆成 3 个子步，防止穿模）：
   ┌────────────────────────────────────┐
   │ 1. 速度 += 重力 × dt               │
   │ 2. 位置 += 速度 × dt               │
   │ 3. 撞地面？→ y 推回 r，vy = -vy × 弹性系数 │
   │ 4. 撞墙？  → 对应轴速度取反 × 弹性系数     │
   │ 5. 两两检测：球心距 < r1+r2 ？              │
   │     ├─ 按质量反比把两球分开（消除重叠）     │
   │     └─ 沿碰撞法线交换冲量（互相弹开）       │
   └────────────────────────────────────┘
   弹性系数 0.78 < 1 → 每次反弹都损失能量 → 最终静止
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>物理弹跳（自写引擎）</title>
<style>
  body { margin: 0; overflow: hidden; }
  #tip {
    position: fixed; left: 16px; top: 16px; color: #fff;
    font: 14px/1.7 sans-serif; background: rgba(0,0,0,.55);
    padding: 10px 14px; border-radius: 8px; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="tip">点击任意小球把它弹起来 · 球会互相碰撞并逐渐停下</div>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const G = 18;            // 重力加速度
const REST = 0.78;       // 恢复系数：1 = 完全弹，0 = 不弹
const FRICTION = 0.985;  // 触地水平摩擦
const BOUND = 8;         // 墙面范围（±BOUND）
const SUB = 3;           // 每帧物理子步数

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x0f1320);

const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 100);
camera.position.set(12, 11, 15);
camera.lookAt(0, 2, 0);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFShadowMap;
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x334455, 2));
const sun = new THREE.DirectionalLight(0xffffff, 2.2);
sun.position.set(6, 14, 8);
sun.castShadow = true;
sun.shadow.camera.left = -12; sun.shadow.camera.right = 12;
sun.shadow.camera.top = 12; sun.shadow.camera.bottom = -12;
scene.add(sun);

const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(30, 30),
  new THREE.MeshStandardMaterial({ color: 0x1d2740, roughness: 0.9 })
);
floor.rotation.x = -Math.PI / 2;
floor.receiveShadow = true;
scene.add(floor);
scene.add(new THREE.GridHelper(30, 30, 0x445577, 0x2a3350));

const palette = [0xff6b6b, 0x4ecdc4, 0xffd166, 0x8b7cf6, 0xef96c5, 0x6bcB77];
const balls = [];
for (let i = 0; i < 14; i++) {
  const r = 0.45 + Math.random() * 0.5;
  const c = palette[i % palette.length];
  const mesh = new THREE.Mesh(
    new THREE.SphereGeometry(r, 24, 24),
    new THREE.MeshStandardMaterial({ color: c, roughness: 0.35, metalness: 0.15 })
  );
  mesh.castShadow = true;
  mesh.receiveShadow = true;
  scene.add(mesh);
  balls.push({
    mesh, r,
    mass: r * r * r,                              // 质量 ∝ 体积
    pos: new THREE.Vector3(
      (Math.random() - 0.5) * 10, 4 + Math.random() * 7, (Math.random() - 0.5) * 10
    ),
    vel: new THREE.Vector3(
      (Math.random() - 0.5) * 4, 0, (Math.random() - 0.5) * 4
    )
  });
}

function step(dt) {
  for (const b of balls) {
    b.vel.y -= G * dt;
    b.pos.addScaledVector(b.vel, dt);

    // 地面
    if (b.pos.y - b.r < 0) {
      b.pos.y = b.r;
      b.vel.y = Math.abs(b.vel.y) < 0.6 ? 0 : -b.vel.y * REST;
      b.vel.x *= FRICTION; b.vel.z *= FRICTION;
    }
    // 四面墙
    for (const axis of ['x', 'z']) {
      if (b.pos[axis] + b.r > BOUND) { b.pos[axis] = BOUND - b.r; b.vel[axis] = -b.vel[axis] * REST; }
      if (b.pos[axis] - b.r < -BOUND) { b.pos[axis] = -BOUND + b.r; b.vel[axis] = -b.vel[axis] * REST; }
    }
  }

  // 球与球：O(n²) 两两检测，14 个球完全够用
  const n = new THREE.Vector3(), rel = new THREE.Vector3();
  for (let i = 0; i < balls.length; i++) {
    for (let j = i + 1; j < balls.length; j++) {
      const a = balls[i], b = balls[j];
      n.subVectors(b.pos, a.pos);
      const d = n.length(), minD = a.r + b.r;
      if (d === 0 || d >= minD) continue;
      n.divideScalar(d);                          // 单位法线：从 a 指向 b
      const overlap = minD - d;
      const total = a.mass + b.mass;
      a.pos.addScaledVector(n, -overlap * b.mass / total);  // 重的球被推得少
      b.pos.addScaledVector(n, overlap * a.mass / total);

      rel.subVectors(b.vel, a.vel);
      const vn = rel.dot(n);
      if (vn >= 0) continue;                      // 正在分离就别再弹
      const impulse = -(1 + REST) * vn / (1 / a.mass + 1 / b.mass);
      a.vel.addScaledVector(n, -impulse / a.mass);
      b.vel.addScaledVector(n, impulse / b.mass);
    }
  }
}

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();
renderer.domElement.addEventListener('pointerdown', e => {
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const hit = raycaster.intersectObjects(balls.map(b => b.mesh))[0];
  if (!hit) return;
  const ball = balls.find(b => b.mesh === hit.object);
  ball.vel.y = 11;                               // 点击 → 向上冲量
  ball.vel.x += (Math.random() - 0.5) * 3;
});

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.033);
  last = now;
  for (let s = 0; s < SUB; s++) step(dt / SUB);
  for (const b of balls) b.mesh.position.copy(b.pos);
  controls.update();
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
自己写物理引擎，核心就是三行：「速度 += 重力×dt」「位置 += 速度×dt」「撞了就修正」。弹跳的奥秘在 `REST`（恢复系数）：撞地时把竖直速度取反再乘 0.78，意思是「弹回来的速度只有撞下去时的 78%」。一次损失 22%，几次之后就弹不动了——这就是现实里球越弹越低的原因。水平方向再乘 0.985 的摩擦，球最终会停下来。
:::

::: tip 撞地为什么要「先推位置，再改速度」
如果只写 `vel.y = -vel.y * REST` 而不修正位置，球心可能已经陷到地面以下，下一帧又判定一次碰撞、又反弹一次，球会在地面上下抖动甚至越陷越深。所以必须先把 `pos.y` 推回到 `r`（球刚好贴地的位置），再改速度。另外当 `|vel.y| < 0.6` 时直接设为 0，让球「睡」在地面上，避免微小弹跳永远不停。
:::

::: tip 球球碰撞分两步：先分开，再弹开
两个球重叠时，先算从 A 指向 B 的单位法线 `n = (B.pos - A.pos) / 距离`。第一步把重叠量 `overlap = r1+r2-距离` 按**质量反比**分配给两球——大球质量大、被推得少，小球被弹得远。第二步算沿法线的相对速度 `vn`：只有 `vn < 0`（正在靠近）才需要弹；用冲量公式 `j = -(1+REST)·vn / (1/m1+1/m2)` 算出该交换多少动量，再按 `1/m` 分给双方。切向速度不动，所以不会凭空产生旋转。
:::

::: tip 为什么质量用 r 的三次方
球的质量正比于体积，体积公式是 `4/3·π·r³`，常数项不影响相对大小，所以直接用 `r³` 当质量。这样半径 1 的球质量是半径 0.5 的球的 8 倍——大球撞小球时，小球嗖地飞走、大球几乎不减速，符合直觉。用 `r²` 会让大球显得太轻。
:::

::: tip 子步长是防穿模的保险
一帧里球可能移动几个单位，如果两个球迎面飞来，可能在两帧之间「擦身而过」，碰撞检测完全漏掉。把每帧拆成 3 个子步（`SUB = 3`），每步只走 1/3 的距离，检测精度大幅提高。配合 `dt` 封顶 0.033 秒（切后台回来时的巨大 dt 被截断），物理系统就不会炸。
:::

## 四、改着玩

- `REST = 0.78` 改成 `0.95` → 超级弹力球，弹很久才停；改成 `0.3` → 像橡皮泥，落地就趴着。
- `G = 18` 改成 `4` → 月球重力，球慢悠悠地飘落；改成 `40` → 重力加速度，砸得很猛。
- 球数 `14` 改成 `60` → 球满场乱撞（O(n²) 检测会变重，60 个约 1800 次/帧还能接受）。
- `FRICTION = 0.985` 改成 `0.9` → 落地后很快停止滚动；改成 `1` → 球会一直滑。
- 点击冲量 `ball.vel.y = 11` 改成 `20` → 一飞冲天；再加 `ball.vel.z -= 5` → 往前飞。
