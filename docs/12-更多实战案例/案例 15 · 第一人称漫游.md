# 案例 15 · 第一人称漫游

想做虚拟看房、展厅漫游、CHAN 走迷宫这类场景，就得让相机变成「人眼」：鼠标转头、WASD 走路，还会被墙挡住。这篇用官方的 `PointerLockControls` 实现第一人称视角，再手写一个够用的圆柱体 vs 立方体碰撞检测。

## 一、效果长啥样

页面中间一个十字准星，点击画面后鼠标被锁定（光标消失），移动鼠标就像转头看四周；按 W/A/S/D 前后左右走，撞到彩色柱子或场地边界会被挡住、还能沿着柱子侧面滑动。按 Esc 释放鼠标，点击画面重新进入。

```text
        点击画面 → PointerLockControls.lock()
                        │
             鼠标移动 → 相机 quaternion 旋转（转头）
                        │
       WASD → moveForward / moveRight（脚下的位移）
                        │
         ┌──────────────┴──────────────┐
         ▼                             ▼
   先走「前后」再走「左右」        每走一步检查：
   （分两步才能贴墙滑动）      相机圆 vs 柱子方盒 是否重叠？
                                     │
                               重叠 → 退回上一步
```

## 二、完整代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>第一人称漫游</title>
<style>
  body { margin: 0; overflow: hidden; }
  #hud {
    position: fixed; inset: 0; display: flex; flex-direction: column;
    align-items: center; justify-content: center; gap: 12px;
    color: #fff; font: 16px/1.7 sans-serif;
    background: rgba(10,12,20,.75); text-align: center; cursor: pointer;
  }
  #hud small { opacity: .75; font-size: 13px; }
  #cross {
    position: fixed; left: 50%; top: 50%; width: 6px; height: 6px;
    margin: -3px; border-radius: 50%; background: #fff;
    box-shadow: 0 0 0 1px #0008; display: none; pointer-events: none;
  }
</style>
<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
    "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
  }
}
</script>
</head>
<body>
<div id="hud">点击进入漫游<br><small>WASD 移动 · 鼠标看向 · Esc 退出 · R 回起点</small></div>
<div id="cross"></div>
<script type="module">
import * as THREE from 'three';
import { PointerLockControls } from 'three/addons/controls/PointerLockControls.js';

const EYE = 1.7;        // 视点高度（人眼）
const RADIUS = 0.4;     // 玩家碰撞半径
const SPEED = 6;        // 移动速度（米/秒）
const LIMIT = 18;       // 场地边界

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x9fd3ff);
scene.fog = new THREE.Fog(0x9fd3ff, 20, 45);

const camera = new THREE.PerspectiveCamera(70, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, EYE, 8);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFShadowMap;
document.body.appendChild(renderer.domElement);

scene.add(new THREE.HemisphereLight(0xffffff, 0x667788, 2.4));
const sun = new THREE.DirectionalLight(0xffffff, 2);
sun.position.set(8, 14, 6);
sun.castShadow = true;
scene.add(sun);

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0xc9d6c5 })
);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);

// 障碍物：数组里存中心 x/z 和半宽半深，碰撞检测就靠这份数据
const walls = [];
const palette = [0xe76f51, 0x4ea8de, 0x80ed99, 0xf4a261];
[[-4,-2,1,3], [3,1,3,1], [0,-7,4,1], [8,-4,1,4]].forEach(([x,z,hx,hz], i) => {
  const m = new THREE.Mesh(
    new THREE.BoxGeometry(hx * 2, 3, hz * 2),
    new THREE.MeshStandardMaterial({ color: palette[i % 4] })
  );
  m.position.set(x, 1.5, z);
  m.castShadow = true;
  scene.add(m);
  walls.push({ x, z, hx, hz });
});

const controls = new PointerLockControls(camera, document.body);
const hud = document.getElementById('hud');
const cross = document.getElementById('cross');
hud.addEventListener('click', () => controls.lock());
controls.addEventListener('lock', () => {
  hud.style.display = 'none';
  cross.style.display = 'block';
});
controls.addEventListener('unlock', () => {
  hud.style.display = 'flex';
  cross.style.display = 'none';
});

const keys = {};
addEventListener('keydown', e => {
  keys[e.code] = true;
  if (e.code === 'KeyR') camera.position.set(0, EYE, 8);
});
addEventListener('keyup', e => { keys[e.code] = false; });

// 相机当作一个半径 RADIUS 的圆柱，和墙的轴对齐方盒做重叠测试
function hits(x, z) {
  if (Math.abs(x) > LIMIT - RADIUS || Math.abs(z) > LIMIT - RADIUS) return true;
  return walls.some(w =>
    Math.abs(x - w.x) < w.hx + RADIUS && Math.abs(z - w.z) < w.hz + RADIUS
  );
}

let last = performance.now();
renderer.setAnimationLoop(() => {
  const now = performance.now();
  const dt = Math.min((now - last) / 1000, 0.05);   // 封顶，防止卡顿时一步穿过墙
  last = now;

  if (controls.isLocked) {
    const step = SPEED * dt;
    // 前后、左右分两步走：撞墙时只回退撞上的那一维，于是能贴着墙滑
    const beforeZ = camera.position.clone();
    if (keys.KeyW) controls.moveForward(step);
    if (keys.KeyS) controls.moveForward(-step);
    camera.position.y = EYE;
    if (hits(camera.position.x, camera.position.z)) camera.position.copy(beforeZ);

    const beforeX = camera.position.clone();
    if (keys.KeyD) controls.moveRight(step);
    if (keys.KeyA) controls.moveRight(-step);
    camera.position.y = EYE;
    if (hits(camera.position.x, camera.position.z)) camera.position.copy(beforeX);
  }
  renderer.render(scene, camera);
});

addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});
</script>
</body>
</html>
```

## 三、关键点拆解

::: tip 大白话时间
`PointerLockControls` 做两件事：一是把鼠标指针「锁」在画面中央并隐藏起来，二是把鼠标的移动量翻译成相机的旋转。于是你往左晃鼠标，头就往左转，跟玩 FPS 游戏一模一样。它是**事件驱动的**——必须用户点一下页面调用 `controls.lock()` 才能进入（浏览器不允许网页偷偷锁鼠标），按 Esc 会自动解锁，所以代码里要监听 `lock` / `unlock` 事件来切换提示层。注意 r187 里要操作相机本体用 `controls.object`，老教程里的 `getObject()` 已经没了。
:::

::: tip 碰撞检测 = 把人当圆、把墙当方盒
我们不去算复杂的网格相交，而是给每个障碍物记一组 `{x, z, hx, hz}`（中心 + 半宽半深），把玩家看成一个半径 `RADIUS` 的圆。判断重叠只要两个轴都满足 `|玩家x - 墙x| < 墙半宽 + 玩家半径` 且 z 轴同理。为什么加半径？因为相机只是一个点，点贴到墙面上会「穿模」，加个半径等于给玩家胖了一圈，看起来才真实。场地边界也用同一个函数处理：超出 `LIMIT` 就当作撞墙。
:::

::: tip 为什么要分「前后」和「左右」两步走
如果四个方向混在一起算完再判断碰撞，一撞墙就整体退回，你会被墙「粘住」动弹不得。把前后位移和左右位移分开处理：先试着走前后，撞了就只退回前后这一步；再试着走左右，撞了只退回左右这一步。结果就是——正对着墙按 W 走不动，但按着 W+D 会沿着墙面**滑过去**。这是游戏里最经典的「轴分离碰撞」，几行代码就有不错的手感。
:::

::: tip 地面碰撞其实被「作弊」了
这里没有做跳跃和重力，所以视点高度永远是 `EYE = 1.7`，地面碰撞等价于「把 y 钉死」。每走完一步都重新 `camera.position.y = EYE`，是为了防止 `moveForward/moveRight` 因为相机的俯仰角把人带得飞起来或钻进地里。等你想加跳跃时，再引入一个 `yVelocity` 和重力公式，落地时把 y 钳回 `EYE` 即可。
:::

## 四、改着玩

- `SPEED = 6` 改成 `10` → 跑步模式；再配合 `keys.ShiftLeft` 判断做成「按住 Shift 加速」。
- `RADIUS = 0.4` 改成 `0.8` → 人变胖，通道变窄，更容易被卡住，可用来测试碰撞。
- 改 `walls` 数组里任意一组的 `hx/hz` → 柱子粗细立刻变化，碰撞盒自动同步（因为用的是同一份数据）。
- 把 `scene.fog` 的 `20, 45` 改成 `8, 20` → 大雾弥漫，只能看清近处，恐怖游戏氛围拉满。
- 在 `keydown` 里加 `if (e.code === 'Space' && controls.isLocked)` → 往上加一个跳跃速度，再在动画循环里叠加重力。
