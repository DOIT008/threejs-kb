# Vue3 数字工厂完整实战

前面六篇都是单页 HTML，适合学原理。真做项目，你得用 Vue3 把东西**拆成组件**：3D 场景一块、看板一块、详情面板一块、报警列表一块，再用 Pinia 把它们共享的数据管起来。这篇我们把整套骨架一次给全——**12 个文件的完整内容**（含容易漏掉的 `index.html` 和 `vite.config.js`），复制过去就能跑。

::: tip 实测过
这套代码我实际建了 Vite 项目跑过 `npm run build`，41 个模块全部编译通过。过程中还专门验证了「漏掉 `vite.config.js` 会怎样」——确实会构建失败，所以那两个文件在下面都给了完整内容，别跳过。
:::

::: info 信息

这一篇的代码基于 **Vite + Vue3 + Pinia + Three.js r187**。用 `<script setup>` 单文件组件写法。请先 `npm init vite@latest` 选 Vue 模板，再 `npm i three pinia`，然后把下面文件覆盖进去。

:::

## 一、项目结构树

先看清全貌，再逐个文件填：

```text
digital-factory/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.js                    # ① 入口：装 Pinia
    ├── App.vue                    # ② 总布局 + 启动数据层
    ├── stores/
    │   └── devices.js             # ③ Pinia：设备状态/选中/报警（全局唯一数据源）
    ├── composables/
    │   ├── useThree.js            # ④ Three.js 生命周期封装
    │   └── useDeviceData.js       # ⑤ WebSocket 数据层（含模拟兜底）
    └── components/
        ├── FactoryScene.vue       # ⑥ 3D 车间：建模 + 拾取 + 聚焦
        ├── DataDashboard.vue      # ⑦ 数据看板：OEE/稼动率/良率
        ├── DevicePanel.vue        # ⑧ 设备详情面板
        └── AlarmList.vue          # ⑨ 报警列表
```

数据流是这样的，记住这张图，代码就不会乱：

```text
WebSocket / 模拟数据
        │  applyData(msg)
        ▼
   Pinia store  ←──── 全局唯一数据源
   ├─ devices[]          各组件都读它
   ├─ selectedId         点谁、选中谁
   └─ alarms[]           报警日志
        │
        ├──> FactoryScene.vue   （3D 变色、选中圈、相机聚焦）
        ├──> DataDashboard.vue  （KPI、柱状图）
        ├──> DevicePanel.vue    （详情）
        └──> AlarmList.vue      （报警列表）
```

::: tip 大白话时间

**所有组件只认 Pinia 这一份数据，互不直接调用。** 点看板的柱子 → 改 `selectedId` → 3D 场景和详情面板自己跟着变；点 3D 设备 → 也改 `selectedId` → 柱子高亮。这叫"**单向数据流 + 共享状态**"，是 Vue 项目不写成一团乱麻的关键。

:::

## 二、文件 ①：`src/stores/devices.js`

全局唯一的数据源。注意：**store 里只放普通数据，绝不塞 Three.js 对象**（3D 对象由场景组件自己用 `shallowRef` 拿着）。

```js
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const STATUS_META = {
  running: { label: '运行', color: '#42b883' },
  standby: { label: '待机', color: '#ffc107' },
  alarm:   { label: '报警', color: '#ff4d4f' },
  offline: { label: '离线', color: '#8b949e' }
}

export const useDevicesStore = defineStore('devices', () => {
  // 设备基础信息 + 实时状态（纯数据，不含 3D 对象）
  const devices = ref([
    { id: 'CNC-01', name: '数控机床 1#', type: 'cnc',     position: [-8, 0, -6], status: 'running', temp: 68, output: 82 },
    { id: 'CNC-02', name: '数控机床 2#', type: 'cnc',     position: [-4, 0, -6], status: 'running', temp: 71, output: 78 },
    { id: 'ROB-01', name: '上下料机器人', type: 'robot',   position: [ 0, 0, -6], status: 'standby', temp: 42, output: 60 },
    { id: 'CNC-03', name: '数控机床 3#', type: 'cnc',     position: [ 4, 0, -6], status: 'alarm',   temp: 93, output: 12 },
    { id: 'ST-01',  name: '质检工位',     type: 'station', position: [ 8, 0, -6], status: 'offline', temp: 25, output: 0  },
    { id: 'ROB-02', name: '包装机器人',   type: 'robot',   position: [ 0, 0,  6], status: 'running', temp: 55, output: 74 }
  ])

  const selectedId = ref(null)   // 当前选中的设备 id
  const alarms = ref([])         // 报警日志

  const selectedDevice = computed(() =>
    devices.value.find(d => d.id === selectedId.value) || null
  )
  const activeAlarms = computed(() =>
    devices.value.filter(d => d.status === 'alarm')
  )

  // 数据入口：WebSocket 收到消息后统一调这里
  function applyData({ id, status, temp, output }) {
    const d = devices.value.find(x => x.id === id)
    if (!d) return
    const prev = d.status
    if (status && STATUS_META[status]) d.status = status
    if (temp != null) d.temp = temp
    if (output != null) d.output = output

    // 从非报警变成报警 → 记一条日志
    if (status === 'alarm' && prev !== 'alarm') {
      alarms.value.unshift({
        id: d.id, name: d.name,
        time: new Date().toLocaleTimeString('zh-CN')
      })
    }
  }

  function select(id) { selectedId.value = id }
  function resetAlarm(id) {
    const d = devices.value.find(x => x.id === id)
    if (d) d.status = 'standby'
    alarms.value = alarms.value.filter(a => a.id !== id)
  }

  return {
    devices, selectedId, alarms, selectedDevice, activeAlarms,
    applyData, select, resetAlarm
  }
})
```

## 三、文件 ④：`src/composables/useThree.js`

把"场景/相机/渲染器/循环/清理"这些脏活打包。谁要 3D，一行调用就行。**只有一条渲染循环**，所有组件通过 `onFrame()` 登记自己的每帧动作。

```js
import { ref, shallowRef, onMounted, onUnmounted } from 'vue'
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

export function useThree(containerRef, options = {}) {
  const {
    background = 0x0d1117,
    cameraPos = [11, 9, 14],
    target = [0, 0.5, 0]
  } = options

  // 注意用 shallowRef：Three 对象内部结构复杂，不要被 Vue 深度响应式代理
  const scene    = shallowRef(null)
  const camera   = shallowRef(null)
  const renderer = shallowRef(null)
  const controls = shallowRef(null)
  const ready    = ref(false)

  const frameCallbacks = []
  const onFrame = fn => frameCallbacks.push(fn)
  let observer = null

  onMounted(() => {
    const el = containerRef.value
    const w = el.clientWidth || 1, h = el.clientHeight || 1

    scene.value = new THREE.Scene()
    scene.value.background = new THREE.Color(background)

    camera.value = new THREE.PerspectiveCamera(50, w / h, 0.1, 100)
    camera.value.position.set(...cameraPos)

    renderer.value = new THREE.WebGLRenderer({ antialias: true })
    renderer.value.setSize(w, h)
    renderer.value.setPixelRatio(Math.min(devicePixelRatio, 2))
    renderer.value.shadowMap.enabled = true
    renderer.value.shadowMap.type = THREE.PCFShadowMap
    el.appendChild(renderer.value.domElement)

    controls.value = new OrbitControls(camera.value, renderer.value.domElement)
    controls.value.enableDamping = true
    controls.value.target.set(...target)

    renderer.value.setAnimationLoop(() => {
      frameCallbacks.forEach(fn => fn())                  // 先更新各物体
      renderer.value.render(scene.value, camera.value)    // 再统一渲染
    })

    observer = new ResizeObserver(onResize)
    observer.observe(el)
    ready.value = true
  })

  function onResize() {
    const el = containerRef.value
    if (!el || !renderer.value) return
    const w = el.clientWidth || 1, h = el.clientHeight || 1
    camera.value.aspect = w / h
    camera.value.updateProjectionMatrix()
    renderer.value.setSize(w, h)
  }

  onUnmounted(() => {
    renderer.value?.setAnimationLoop(null)
    observer?.disconnect()
    controls.value?.dispose()
    scene.value?.traverse(o => {
      o.geometry?.dispose()
      if (Array.isArray(o.material)) o.material.forEach(m => m.dispose())
      else o.material?.dispose()
    })
    renderer.value?.dispose()
    renderer.value?.domElement.remove()
  })

  return { scene, camera, renderer, controls, ready, onFrame }
}
```

::: warning 为什么用 `shallowRef` + `watch(ready)`

Three.js 对象（`Scene`/`Mesh`/`Material`）内部有海量属性和循环引用，如果被 Vue 深度响应式代理，会**严重拖慢性能甚至报错**——`shallowRef` 只代理最外层引用，不碰内部。另外 `useThree` 在 `onMounted` 里才建好场景，而 `<script setup>` 顶层执行时还没挂载，所以外部必须用 `watch(ready, ...)` 等场景就绪后再往里加东西。

:::

## 四、文件 ⑤：`src/composables/useDeviceData.js`

数据层。有 `url` 就走真 WebSocket，没有就用定时器模拟——**换真实项目只改这一处**。

```js
import { onMounted, onUnmounted } from 'vue'
import { useDevicesStore } from '../stores/devices'

export function useDeviceData({ url = null, interval = 1200 } = {}) {
  const store = useDevicesStore()
  let ws = null
  let timer = null

  // 模拟数据：随机挑一台设备改状态
  function mockFeed() {
    const d = store.devices[Math.floor(Math.random() * store.devices.length)]
    const keys = ['running', 'running', 'running', 'standby', 'alarm', 'offline']
    const status = keys[Math.floor(Math.random() * keys.length)]
    store.applyData({
      id: d.id,
      status,
      temp: status === 'offline' ? 25 : 55 + Math.random() * 40,
      output: status === 'running' ? 60 + Math.floor(Math.random() * 40) : 0
    })
  }

  onMounted(() => {
    if (url) {
      ws = new WebSocket(url)
      ws.onmessage = (e) => {
        try { store.applyData(JSON.parse(e.data)) }
        catch (err) { console.warn('设备数据格式错误', err) }
      }
      ws.onclose = () => console.warn('WebSocket 断开，等待重连')
    } else {
      timer = setInterval(mockFeed, interval) // 没有 url 就用模拟数据
    }
  })

  onUnmounted(() => {
    if (ws) ws.close()
    if (timer) clearInterval(timer)
  })
}
```

::: info 信息

真实项目里建议在 `onclose` 里加**自动重连**（`setTimeout` 后重新 `new WebSocket`），并处理"心跳超时 → 全部设备标离线"。还记得第 03 篇说的兜底吗？断网时不能让界面一直显示故障前的绿色。

:::

## 五、文件 ⑥：`src/components/FactoryScene.vue`

3D 车间：建模、拾取、按状态变色、选中圈、相机聚焦。**关键点：3D 对象存在普通 `Map` 里，颜色每帧从 store 读，绝不把 Mesh 塞进 Pinia。**

```vue
<template>
  <div ref="container" class="scene"></div>
</template>

<script setup>
import { ref, watch } from 'vue'
import * as THREE from 'three'
import { useThree } from '../composables/useThree'
import { useDevicesStore, STATUS_META } from '../stores/devices'

const container = ref(null)
const store = useDevicesStore()
const { scene, camera, renderer, controls, ready, onFrame } = useThree(container)

// 普通 Map：id -> Mesh（不放进 Pinia！）
const meshes = new Map()
let ring = null
let raycaster = null
let pointer = null
let downX = 0, downY = 0

const focus = { active: false, camTo: new THREE.Vector3(), targetTo: new THREE.Vector3() }

watch(ready, v => { if (v) buildScene() })

function buildScene() {
  // ---- 光照 + 地面 + 网格 ----
  scene.value.add(new THREE.HemisphereLight(0xaaccff, 0x222233, 1.5))
  const sun = new THREE.DirectionalLight(0xffffff, 2)
  sun.position.set(6, 10, 5)
  sun.castShadow = true
  scene.value.add(sun)

  const floor = new THREE.Mesh(
    new THREE.PlaneGeometry(30, 20),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.95 })
  )
  floor.rotation.x = -Math.PI / 2
  floor.receiveShadow = true
  scene.value.add(floor)
  scene.value.add(new THREE.GridHelper(30, 30, 0x3b4a63, 0x27334a))

  // ---- 按 store 里的数据造设备 ----
  const bodyMat = new THREE.MeshStandardMaterial({ color: 0x64748b, metalness: 0.5, roughness: 0.5 })
  store.devices.forEach(d => {
    const g = new THREE.Group()
    const body = new THREE.Mesh(new THREE.BoxGeometry(1.5, 1.2, 1.3), bodyMat)
    body.position.y = 0.6
    body.castShadow = true
    g.add(body)

    // 每盏灯独立材质，才能单独改颜色
    const lampMat = new THREE.MeshStandardMaterial({
      color: 0x42b883, emissive: 0x42b883, emissiveIntensity: 0.7
    })
    const lamp = new THREE.Mesh(new THREE.SphereGeometry(0.17, 20, 20), lampMat)
    lamp.position.y = 1.5
    g.add(lamp)

    g.position.set(...d.position)
    g.userData.id = d.id
    scene.value.add(g)
    meshes.set(d.id, { group: g, lampMat })
  })

  // ---- 选中圈 ----
  ring = new THREE.Mesh(
    new THREE.TorusGeometry(1.15, 0.05, 8, 48),
    new THREE.MeshBasicMaterial({ color: 0x42b883 })
  )
  ring.rotation.x = -Math.PI / 2
  ring.visible = false
  scene.value.add(ring)

  // ---- 点击拾取 ----
  raycaster = new THREE.Raycaster()
  pointer = new THREE.Vector2()
  const canvas = renderer.value.domElement
  canvas.addEventListener('pointerdown', e => { downX = e.clientX; downY = e.clientY })
  canvas.addEventListener('pointerup', e => {
    if (Math.hypot(e.clientX - downX, e.clientY - downY) > 5) return
    const rect = canvas.getBoundingClientRect()
    pointer.x = ((e.clientX - rect.left) / rect.width) * 2 - 1
    pointer.y = -((e.clientY - rect.top) / rect.height) * 2 + 1
    raycaster.setFromCamera(pointer, camera.value)
    const all = [...meshes.values()].map(m => m.group)
    const hits = raycaster.intersectObjects(all, true)
    if (hits.length) {
      let o = hits[0].object
      while (o && !o.userData.id) o = o.parent
      if (o) store.select(o.userData.id) // 选中 → 改 Pinia
    }
  })

  // ---- 每帧：颜色跟随状态 + 相机聚焦 ----
  onFrame(() => {
    const t = performance.now() / 1000
    store.devices.forEach(d => {
      const entry = meshes.get(d.id)
      if (!entry) return
      const target = new THREE.Color(STATUS_META[d.status].color)
      entry.lampMat.color.lerp(target, 0.08)
      entry.lampMat.emissive.lerp(target, 0.08)
      if (d.status === 'alarm') entry.lampMat.emissiveIntensity = 0.5 + Math.abs(Math.sin(t * 8)) * 1.5
      else if (d.status === 'running') entry.lampMat.emissiveIntensity = 0.5 + Math.sin(t * 3) * 0.3
      else entry.lampMat.emissiveIntensity = 0.3
    })

    if (focus.active) {
      camera.value.position.lerp(focus.camTo, 0.06)
      controls.value.target.lerp(focus.targetTo, 0.08)
      if (camera.value.position.distanceTo(focus.camTo) < 0.05) {
        camera.value.position.copy(focus.camTo)
        focus.active = false
        controls.value.enabled = true
      }
    }
  })
}

// 选中变化（无论来自 3D 点击还是看板点击）→ 移动圈 + 相机飞过去
watch(() => store.selectedId, id => {
  if (!id || !ring) { if (ring) ring.visible = false; return }
  const entry = meshes.get(id)
  if (!entry) return
  const p = new THREE.Vector3()
  entry.group.getWorldPosition(p)
  ring.position.set(p.x, 0.06, p.z)
  ring.visible = true
  focus.camTo.set(p.x + 3, 3.2, p.z + 5)
  focus.targetTo.copy(p)
  focus.active = true
  controls.value.enabled = false
})
</script>

<style scoped>
.scene { width: 100%; height: 100%; }
.scene :deep(canvas) { display: block; }
</style>
```

::: warning 两个小细节

1. 拾取时算鼠标坐标要用**画布的包围盒**（`getBoundingClientRect`），不能直接用 `innerWidth`——因为我们的画布在左侧容器里，不是全屏。
2. `onFrame` 回调里每帧都 `new THREE.Color(...)` 会产生垃圾。**优化版**预先给每台设备存一个 `targetColor` 对象，用 `setHex()` 改它再 `lerp`。这里为可读性简写了，性能优化清单里有提。

:::

## 六、文件 ⑦：`src/components/DataDashboard.vue`

看板：OEE 环形、稼动率/良率条、各设备产出柱状图。点柱子调用 `store.select(id)`，和 3D 联动。

```vue
<template>
  <aside class="dash">
    <h2>车间实时看板</h2>
    <div class="card">

    <div class="card">

<script setup>
import { computed } from 'vue'
import { useDevicesStore } from '../stores/devices'

const store = useDevicesStore()
const maxOutput = computed(() => Math.max(...store.devices.map(d => d.output), 1))
const barHeight = output => (output / maxOutput.value * 100) + '%'

// 由设备状态算出的看板指标（真实项目应由后端直接给这些聚合值）
const availability = computed(() => {
  const running = store.devices.filter(d => d.status === 'running').length
  return Math.round(running / store.devices.length * 100)
})
const quality = computed(() => {
  const good = store.devices.reduce((s, d) => s + d.output, 0)
  const total = store.devices.length * 100
  return Math.round(good / total * 100)
})
const oee = computed(() => Math.round(availability.value * 0.9 * quality.value / 100))
</script>
```

## 七、文件 ⑧：`src/components/DevicePanel.vue`

详情面板：读 store 里的 `selectedDevice`，点哪台显示哪台。

```vue
<template>
  <div v-if="store.selectedDevice" class="panel">
    <h3>{{ store.selectedDevice.name }}</h3>
    <div class="row"><span>编号</span><b>{{ store.selectedDevice.id }}</b></div>
    <div class="row"><span>状态</span>
      <b :style="{ color: statusColor }">{{ statusLabel }}</b>
    </div>
    <div class="row"><span>温度</span><b>{{ store.selectedDevice.temp.toFixed(1) }} ℃</b></div>
    <div class="row"><span>产出</span><b>{{ store.selectedDevice.output }} 件</b></div>
    <button @click="store.select(null)">关闭</button>
  </div>
</template>

<script setup>
```

## 十、性能优化清单

项目跑起来之后，按这个清单逐条检查：

| 优化项 | 做法 | 为什么 |
|---|---|---|
| 3D 对象不进 Pinia | Mesh 存普通 `Map`，Pinia 只放数据 | 避免深度响应式代理拖垮性能 |
| 用 `shallowRef` 包 Three 对象 | `shallowRef(new THREE.Scene())` | 同上 |
| 单一渲染循环 | 所有更新走 `onFrame()` | 多个循环抢 GPU 是大忌 |
| 复用临时对象 | 循环外建 `targetColor`，循环里 `setHex()` | 避免每帧 `new` 产生垃圾 |
| InstancedMesh | 成百上千的相同物体一次画 | 把 draw call 从几百降到 1 |
| 数据节流 | 100ms 最多处理一次数据 | 高频数据不压垮渲染 |
| 像素比封顶 | `min(devicePixelRatio, 2)` | 高分屏别渲染 3 倍像素 |
| 阴影贴图适中 | `2048` 够用，别上 `4096` | 阴影 Very 吃显存 |
| 静态物体冻结 | `obj.matrixAutoUpdate = false` | 不变的物体别每帧算矩阵 |
| 容器自适应 | `ResizeObserver` 而非只监听 window | 侧栏变化也能跟上 |
| 彻底清理 | `onUnmounted` 里 dispose + 关 WebSocket | 路由切换不泄漏内存/连接 |
| 看板聚合交给后端 | OEE 等由后端算好推来 | 前端别在大数据上做重计算 |

::: warning 最容易漏的两条

**① 清理**：路由切走组件销毁时，如果没 `setAnimationLoop(null)`、没关 WebSocket、没 `dispose()`，内存和连接会越积越多，页面越用越卡。useThree 和 useDeviceData 已经帮你在 `onUnmounted` 里做了，别自己另起循环绕过它。

**② 临时对象**：`onFrame` 每秒跑 60 次，里面每次 `new THREE.Color()` 一分钟就是 3600 个对象等着 GC。把它提到循环外，用 `setHex()` 改值——这是 3D 项目最常见也最隐蔽的性能杀手。

:::

## 十一、小结

这篇我们搭起了一个正经的 Vue3 数字工厂项目：

- **Pinia store** 是唯一数据源，3D 和看板都读它、通过 `selectedId` 联动；
- **useThree** 封装生命周期，保证单循环 + 彻底清理；
- **useDeviceData** 收敛数据入口，模拟与真实 WebSocket 一行切换；
- **四个组件**各司其职，3D 对象绝不进响应式状态。

demo 能跑了，但离真实项目上线还有一段路——真实设备怎么接？坐标怎么和厂区对齐？模型太大怎么办？最后一篇《从演示到落地》我们把这些"工程问题"一次讲透。
