# 报警与动画效果

前面设备会变色、能点击了。但报警这种事，光变个色还不够震撼——**得让人隔着老远就注意到"出事了"**。这篇我们加动画特效：报警冒泡、跑马灯、告警粒子、危险红区、屏幕闪烁。放心，都是基础三件套能搞定的东西，不需要额外引擎。

## 一、报警分级：不是所有报警都一样急

真实工厂里报警成百上千，如果每报警都红闪+粒子+大喇叭，人反而会麻木（这叫"告警疲劳"）。所以要先分级，**不同级别给不同强度的视觉**：

| 级别 | 名称 | 颜色 | 闪烁速度 | 特效 | 大白话场景 |
|---|---|---|---|---|---|
| 1 | 提示 info | 🔵 蓝 | 不闪 | 仅状态变蓝 | "耗材快用完了，抽空看看" |
| 2 | 警告 warning | 🟡 黄 | 慢闪（1~2Hz） | 黄灯慢脉冲 | "温度偏高，注意观察" |
| 3 | 严重 critical | 🔴 红 | 快闪（3~5Hz） | 红灯脉冲 + 粒子 | "设备故障，需要尽快处理" |
| 4 | 紧急 emergency | 🟣 红紫急闪 | 极快（6~10Hz） | 全部特效 + 屏幕闪 + 跑马灯 | "有危险！立即停机疏散" |

::: tip 大白话时间

报警分级就像**医院的分诊台**：量体温的护士、普通门诊、急诊、抢救室——越紧急，动静越大，资源越优先。数字孪生也一样：**级别越高，视觉越"吵"**，让人第一眼就锁定最该处理的问题。

:::

## 二、自发光脉冲：报警冒泡

最基础的报警动画是**脉冲**——亮度像呼吸一样忽明忽暗。公式就一行，用 `Math.sin` 或 `Math.abs(Math.sin)`：

```js
// 呼吸灯：0.5 ± 0.3 之间缓慢起伏
const glow = 0.5 + Math.sin(t * 3) * 0.3;
material.emissiveIntensity = glow;

// 急促闪烁：0.4 ~ 1.9 之间快速跳（abs 让低谷也是亮的）
const alarm = 0.4 + Math.abs(Math.sin(t * 8)) * 1.5;
material.emissiveIntensity = alarm;
```

::: info 信息

`Math.sin(t * speed)` 天然在 -1~+1 之间来回摆，乘个系数再加个基数就得到"呼吸"。`Math.abs(Math.sin(...))` 把负值翻正，会变成 **0→1→0** 的尖峰，闪烁感更强。把 `speed`（频率）调大就是"急闪"，调小就是"慢闪"——对应上面的分级表。

:::

"冒泡"效果就是让一个球**一边脉冲一边上下浮动 + 缩放**：

```js
bubble.position.y = 2 + Math.sin(t * 2) * 0.15;      // 上下浮
const s = 1 + Math.sin(t * 4) * 0.15;                 // 忽大忽小
bubble.scale.setScalar(s);
bubble.material.emissiveIntensity = 0.5 + Math.abs(Math.sin(t * 5));
```

## 三、跑马灯：让报警范围一目了然

"跑马灯"是一圈**依次亮灭**的小灯，像警车顶灯那样绕圈跑，特别适合标出**危险区域的边界**。做法是摆一圈小球，每盏灯的亮度按"时间 - 序号"算，形成追逐效果：

```js
const lights = [];
for (let i = 0; i < 16; i++) {
  const a = (i / 16) * Math.PI * 2;
  const m = new THREE.MeshBasicMaterial({ color: 0x0a3d2a });
  const bulb = new THREE.Mesh(new THREE.SphereGeometry(0.08, 12, 12), m);
  bulb.position.set(Math.cos(a) * 3, 0.2, Math.sin(a) * 3);
  scene.add(bulb);
  lights.push(m);
}

// 动画里：
lights.forEach((m, i) => {
  const v = Math.max(0, Math.sin(t * 4 - i * 0.5)); // 每盏相位差 0.5
  m.color.setRGB(0.1 + v * 0.9, 0.05 + v * 0.25, 0.05); // 亮的那几盏变红
});
```

::: tip 大白话时间

关键在 `t * 4 - i * 0.5` 里那个 **`- i * 0.5`**：每盏灯都有自己的"时间差"，于是亮的那一小段会沿着圈**依次传递**，像跑道上的接力棒。如果所有灯用同一个 `t`，它们就会同时亮同时灭，那就不是跑马灯而是闪光灯了。

:::

## 四、粒子告警：向上冒的火花

严重报警可以加一团**向上飘散的粒子**，像设备着火冒火星。用 `Points` + `BufferGeometry`，每帧更新每个粒子的 Y 坐标，飘出范围就拉回底部重生：

```js
const N = 120;
const pos = new Float32Array(N * 3);
for (let i = 0; i < N; i++) {
  pos[i*3]     = (Math.random() - 0.5) * 1.5; // x 在设备附近随机
  pos[i*3 + 1] = Math.random() * 3;           // y 高度随机
  pos[i*3 + 2] = (Math.random() - 0.5) * 1.5; // z 随机
}
const geo = new THREE.BufferGeometry();
geo.setAttribute('position', new THREE.BufferAttribute(pos, 3));
const pts = new THREE.Points(geo, new THREE.PointsMaterial({
  color: 0xff6a3d, size: 0.12, transparent: true, opacity: 0.9, depthWrite: false
}));
scene.add(pts);

// 动画里：每个粒子往上飘，飘过 3 米就回到底部
const attr = geo.attributes.position;
for (let i = 0; i < N; i++) {
  let y = attr.getY(i) + 0.02;
  if (y > 3) y = 0;
  attr.setY(i, y);
}
attr.needsUpdate = true; // 告诉 GPU 数据变了
```

::: warning 注意

改完粒子位置**必须设 `needsUpdate = true`**，否则 GPU 不知道数据变了，粒子会一动不动。这是新手最常踩的坑之一。另外粒子材质用 `depthWrite: false`，避免半透明粒子互相遮挡出奇怪的方块。

:::

## 五、危险区域红色地面

在危险设备脚下铺一块**半透明红色地面**，并让透明度脉冲，界定"闲人免进"的范围：

```js
const danger = new THREE.Mesh(
  new THREE.CircleGeometry(3, 48),
  new THREE.MeshBasicMaterial({
    color: 0xff2d2d, transparent: true, opacity: 0.25,
    depthWrite: false, side: THREE.DoubleSide
  })
);
danger.rotation.x = -Math.PI / 2;
danger.position.y = 0.02; // 稍微抬高，避免和地面 z-fighting 闪烁
scene.add(danger);

// 动画里脉冲透明度
danger.material.opacity = 0.15 + Math.abs(Math.sin(t * 3)) * 0.25;
```

::: warning 注意

`position.y = 0.02` 这点小偏移很重要。如果和地面完全重合（都在 y=0），两个面会互相争抢绘制，产生**摩尔纹一样的闪烁**，专业叫 **z-fighting**。抬高 1~2 厘米就能躲开。

:::

## 六、屏幕空间闪烁：整屏红框警告

最紧急的报警，可以在整个画面叠一层**红色边框闪烁**——这是 HTML/CSS 的活儿，跟 3D 无关，但效果极强：

```html
<div id="flash"></div>
<style>
  #flash {
    position: fixed; inset: 0; pointer-events: none;
    box-shadow: inset 0 0 120px 30px rgba(255, 40, 40, .0);
    transition: box-shadow .08s linear;
  }
</style>
```

```js
// 动画里：紧急报警时让红框一闪一闪
const flash = document.getElementById('flash');
flash.style.boxShadow = (t % 0.6 < 0.3)
  ? 'inset 0 0 120px 30px rgba(255,40,40,.55)'
  : 'inset 0 0 120px 30px rgba(255,40,40,0)';
```

::: tip 大白话时间

这一层就是给屏幕**镶了个红色发光框**，`inset` 阴影让它从边缘往里泛红。`pointer-events: none` 保证它不挡鼠标点击。紧急报警时开，平时关——比在 3D 里做各种特效都来得直接。

:::

## 七、完整示例：报警动画全家桶

把上面所有特效合到一个例子里：6 台设备，其中一台处于"严重报警"，你会看到——红色地面脉冲、跑马灯绕圈、粒子向上冒、报警球冒泡闪烁、屏幕红框急闪。点"复位"按钮（或等几秒自动恢复）动画停止，切回正常。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>报警与动画效果</title>
  <style>
    body { margin: 0; overflow: hidden; background: #0d1117; font-family: sans-serif; }
    #flash { position: fixed; inset: 0; pointer-events: none;
             box-shadow: inset 0 0 120px 30px rgba(255,40,40,0); }
    #hud { position: fixed; left: 16px; top: 16px; color: #ffb4b4;
           background: rgba(40,0,0,.55); padding: 10px 16px; border-radius: 8px;
           font-size: 14px; line-height: 1.8; }
    #hud button { margin-top: 6px; background: #ff4d4f; color: #fff;
                  border: 0; border-radius: 4px; padding: 4px 12px; cursor: pointer; }
  </style>
  <script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
    }
  }
  </script>
</head>
<body>
  <div id="flash"></div>
  <div id="hud">
    <div>⚠ 3# 设备：严重报警（温度超限）</div>
    <div id="stateText">特效运行中…</div>
    <button id="reset">模拟复位</button>
  </div>

  <script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  // ===== 基础场景 =====
  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x0d1117);
  const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
  camera.position.set(10, 8, 13);
  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFShadowMap;
  document.body.appendChild(renderer.domElement);
  const controls = new OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;
  controls.target.set(0, 0.5, 0);
  scene.add(new THREE.HemisphereLight(0xaaccff, 0x222233, 1.5));
  const sun = new THREE.DirectionalLight(0xffffff, 2);
  sun.position.set(6, 10, 5); sun.castShadow = true; scene.add(sun);
  const floor = new THREE.Mesh(new THREE.PlaneGeometry(30, 20),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.95 }));
  floor.rotation.x = -Math.PI / 2; floor.receiveShadow = true; scene.add(floor);
  scene.add(new THREE.GridHelper(30, 30, 0x3b4a63, 0x27334a));

  // ===== 6 台设备 =====
  const bodyMat = new THREE.MeshStandardMaterial({ color: 0x64748b, metalness: 0.5, roughness: 0.5 });
  for (let i = 0; i < 6; i++) {
    const g = new THREE.Mesh(new THREE.BoxGeometry(1.5, 1.2, 1.3), bodyMat);
    g.position.set((i - 2.5) * 2.6, 0.6, 0);
    g.castShadow = true; scene.add(g);
  }
  const alarmX = 0; // 中间那台（索引2附近）作为报警设备

  // ===== 特效 1：报警冒泡球 =====
  const bubbleMat = new THREE.MeshStandardMaterial({
    color: 0xff4d4f, emissive: 0xff4d4f, emissiveIntensity: 1, transparent: true, opacity: 0.9
  });
  const bubble = new THREE.Mesh(new THREE.SphereGeometry(0.35, 24, 24), bubbleMat);
  bubble.position.set(alarmX, 2.4, 0);
  scene.add(bubble);

  // ===== 特效 2：危险红区地面 =====
  const danger = new THREE.Mesh(
    new THREE.CircleGeometry(2.8, 48),
    new THREE.MeshBasicMaterial({ color: 0xff2d2d, transparent: true, opacity: 0.25,
      depthWrite: false, side: THREE.DoubleSide })
  );
  danger.rotation.x = -Math.PI / 2;
  danger.position.set(alarmX, 0.02, 0);
  scene.add(danger);

  // ===== 特效 3：跑马灯（一圈依次亮灭的小球） =====
  const bulbs = [];
  for (let i = 0; i < 16; i++) {
    const a = (i / 16) * Math.PI * 2;
    const m = new THREE.MeshBasicMaterial({ color: 0x551111 });
    const b = new THREE.Mesh(new THREE.SphereGeometry(0.1, 12, 12), m);
    b.position.set(alarmX + Math.cos(a) * 2.8, 0.15, Math.sin(a) * 2.8);
    scene.add(b); bulbs.push(m);
  }

  // ===== 特效 4：告警粒子（向上冒的火星） =====
  const N = 150;
  const pos = new Float32Array(N * 3);
  const speeds = new Float32Array(N);
  for (let i = 0; i < N; i++) {
    pos[i*3]     = alarmX + (Math.random() - 0.5) * 1.8;
    pos[i*3 + 1] = Math.random() * 3;
    pos[i*3 + 2] = (Math.random() - 0.5) * 1.8;
    speeds[i] = 0.015 + Math.random() * 0.03;
  }
  const pGeo = new THREE.BufferGeometry();
  pGeo.setAttribute('position', new THREE.BufferAttribute(pos, 3));
  const particles = new THREE.Points(pGeo, new THREE.PointsMaterial({
    color: 0xff6a3d, size: 0.13, transparent: true, opacity: 0.9, depthWrite: false
  }));
  scene.add(particles);

  // ===== 复位逻辑 =====
  let alarming = true;
  const flash = document.getElementById('flash');
  const stateText = document.getElementById('stateText');
  document.getElementById('reset').onclick = () => {
    alarming = false;
    stateText.textContent = '已复位，特效关闭';
    bubble.visible = danger.visible = particles.visible = false;
    bulbs.forEach(m => m.color.setHex(0x223344));
    flash.style.boxShadow = 'inset 0 0 120px 30px rgba(255,40,40,0)';
  };

  // ===== 动画循环 =====
  const timer = new THREE.Timer();
  renderer.setAnimationLoop(() => {
    timer.update();
    const t = timer.getElapsed();

    if (alarming) {
      // 冒泡：浮动 + 缩放 + 脉冲
      bubble.position.y = 2.4 + Math.sin(t * 2) * 0.18;
      bubble.scale.setScalar(1 + Math.sin(t * 4) * 0.15);
      bubbleMat.emissiveIntensity = 0.6 + Math.abs(Math.sin(t * 7)) * 1.6;

      // 危险地面脉冲
      danger.material.opacity = 0.15 + Math.abs(Math.sin(t * 3)) * 0.25;

      // 跑马灯追逐
      bulbs.forEach((m, i) => {
        const v = Math.max(0, Math.sin(t * 5 - i * 0.5));
        m.color.setRGB(0.25 + v * 0.75, 0.05 + v * 0.2, 0.05);
      });

      // 粒子上升
      const attr = pGeo.attributes.position;
      for (let i = 0; i < N; i++) {
        let y = attr.getY(i) + speeds[i];
        if (y > 3.2) y = 0;
        attr.setY(i, y);
      }
      attr.needsUpdate = true;

      // 屏幕急闪
      flash.style.boxShadow = (t % 0.6 < 0.3)
        ? 'inset 0 0 120px 30px rgba(255,40,40,.5)'
        : 'inset 0 0 120px 30px rgba(255,40,40,0)';
    }

    controls.update();
    renderer.render(scene, camera);
  });

  addEventListener('resize', () => {
    camera.aspect = innerWidth / innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(innerWidth, innerHeight);
  });
  </script>
</body>
</html>
```

::: warning 别让特效滥用

特效是"调味料"不是"主菜"。真实项目里请遵守：

- **同一时刻只给最高级别的报警开全特效**，低级别的只变色/慢闪，否则满屏乱闪没人看得懂；
- 粒子数量控制在几百以内，太多会掉帧；
- 提供"静音/减弱特效"开关——有些用户对闪烁光敏感（光敏性癫痫），这是无障碍的基本要求。

:::

## 八、小结

| 特效 | 核心手段 |
|---|---|
| 冒泡/脉冲 | `emissiveIntensity = 基数 + abs(sin(t*速度))*幅度` |
| 跑马灯 | 一圈灯，每盏相位差 `- i * 步长` |
| 粒子告警 | `Points` + 每帧改 Y + `needsUpdate` |
| 危险红区 | 半透明圆面 + 脉冲透明度 + 抬高防 z-fighting |
| 屏幕闪烁 | HTML 红色 inset 阴影 + JS 切换 |
