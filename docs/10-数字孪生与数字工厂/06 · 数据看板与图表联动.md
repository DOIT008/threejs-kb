# 数据看板与图表联动

场景够炫了，但真正拍板的人更爱看数字——"今天产线效率多少？良品率几个点？哪台设备拖后腿？"这篇我们做一块**数据看板**，放在 3D 场景旁边，用纯 HTML/CSS 画出 ECharts 那种效果，还能**点图表联动 3D**。

::: info 信息

为什么不用 ECharts？当然可以用，功能强。但看板的很多需求其实很轻——几个环形进度、几根柱子、几个数字——用 **CSS 就能画得很好看**，还零依赖、体积为 0。这篇先用纯 CSS 打底，你要上 ECharts 随时可以替换，思路一模一样。

:::

## 一、看板放哪：和 3D 场景并排

最经典的布局是**左边 3D、右边看板**，或者**中间 3D、两侧看板**。用 Flexbox 两行 CSS 就搞定：

```css
.app { display: flex; height: 100vh; }
#scene { flex: 1; }        /* 3D 场景自适应占满剩余宽度 */
#dash  { width: 340px; overflow-y: auto; } /* 看板固定宽度 */
```

::: warning 注意

3D 场景现在**不再是全屏**了，所以相机宽高比、渲染器尺寸都要用**容器**的宽高（`container.clientWidth / clientHeight`），而不是 `innerWidth / innerHeight`。用 `ResizeObserver` 监听容器变化最稳，别只监听 `window.resize`——侧栏展开/收起时容器变了，窗口可没变。

:::

## 二、关键指标：OEE / 稼动率 / 良率是啥

制造业看板绕不开这三个词，我用人话解释：

| 指标 | 全称 | 大白话 | 怎么算 |
|---|---|---|---|
| **OEE** | 设备综合效率 | "这台设备到底有多大本事发挥出来了" | 可用率 × 性能 × 良品率 |
| 稼动率 | Availability | "时间里有多久真正在干活" | 实际运行时间 ÷ 计划时间 |
| 良率 | Quality / Yield | "做出来的东西有多少是好的" | 良品数 ÷ 总产出 |

::: tip 大白话时间

拿做包子打比方：

- **稼动率**：一天 8 小时，你真正在蒸包子 6 小时，稼动率 = 6/8 = 75%（剩下 2 小时在和面、打扫、摸鱼）；
- **良率**：蒸了 100 个，92 个没蒸塌，良率 92%；
- **OEE**：把"时间利用、速度快慢、质量好坏"三者乘起来，**一个数概括你到底干得怎么样**。行业里 OEE 能到 85% 就算很牛了。

:::

## 三、纯 CSS 图表：环形进度、柱状图、迷你折线

### 环形进度（画 OEE）

用 `conic-gradient`（锥形渐变）画圆环，中间盖一个圆就是空心环：

```css
.ring {
  width: 100px; height: 100px; border-radius: 50%;
  background: conic-gradient(var(--brand) calc(var(--pct) * 1%), #233045 0);
  display: grid; place-items: center;
}
.ring-inner {
  width: 76px; height: 76px; border-radius: 50%;
  background: var(--panel);
  display: grid; place-items: center;
  font-size: 20px; font-weight: 700;
}
```

```html
<div class="ring" style="--pct: 82"><div class="ring-inner">82%</div></div>
```

`--pct` 改成多少，环就填多少——JS 里改这个 CSS 变量就行，不用碰渐变本身。

### 柱状图（各设备产出）

```css
.bars { display: flex; align-items: flex-end; gap: 8px; height: 120px; }
.bar  { flex: 1; background: linear-gradient(var(--brand), #2a7a5a);
        border-radius: 4px 4px 0 0; cursor: pointer; transition: opacity .2s; }
.bar:hover { opacity: .75; }
.bar.active { outline: 2px solid #fff; }
```

每根柱子是个 `div`，`height` 按数值百分比设。加个 `data-id`，点击时就知道对应哪台设备。

### 迷你折线（趋势）

用 `clip-path` 把一段折线"裁"出来，或者更简单——直接用几个高低不同的小竖条表示趋势。追求极简的话，一行 emoji/符号 + 数字也行。看板的重点是**信息清晰**，不是炫技。

## 四、CSS 变量适配 Vue 绿主题

把所有颜色抽成 CSS 变量，好处是**换主题只改一处**。本知识库统一用 Vue 绿 `#42b883`：

```css
:root {
  --brand:  #42b883;   /* 主题绿 */
  --bg:     #0d1117;   /* 背景 */
  --panel:  #161e2a;   /* 卡片底色 */
  --text:   #e6edf3;   /* 主文字 */
  --muted:  #8b949e;   /* 次要文字 */
  --border: #2a3444;   /* 边框 */
  --danger: #ff4d4f;   /* 报警红 */
}
```

::: tip 大白话时间

CSS 变量（自定义属性）就是**给颜色起外号**。全站写 `var(--brand)`，不写死 `#42b883`。哪天老板说"换成科技蓝"，你只要把 `:root` 里那一行改成 `--brand: #3b82f6`，几十个地方瞬间全变——这就是"一处改，处处改"。

:::

在 Vue3 里，你甚至可以给不同租户/页面在外层元素上覆盖变量：

```vue
<template>
  <div class="app" :style="{ '--brand': themeColor }">
    <Scene3D />
    <Dashboard />
  </div>
</template>

<script setup>
import { ref } from 'vue'
const themeColor = ref('#42b883') // 切换主题只改这个值
</script>
```

## 五、点击图表联动 3D

联动的核心只有一句话：**图表点击事件 → 调用 3D 场景的"选中设备"函数**。和上一篇的点击拾取正好反过来——那边是 3D → UI，这边是 UI → 3D。

```js
// 给每根柱子绑点击
document.querySelectorAll('.bar').forEach(bar => {
  bar.onclick = () => {
    const id = bar.dataset.id;
    selectDeviceIn3D(id); // 高亮对应设备 + 相机聚焦
    document.querySelectorAll('.bar').forEach(b => b.classList.remove('active'));
    bar.classList.add('active');
  };
});
```

::: info 信息

在 Vue3 项目里，这个联动更优雅：柱子和 3D 设备都读 **Pinia 里同一份 `selectedDeviceId` 状态**。点柱子 → 改 store → 3D 组件 `watch` 这个 id → 高亮设备；点 3D 设备 → 也改 store → 柱子自动高亮。**两边不互相调用，只认同一份数据**，这就是第 07 篇要讲的状态管理。

:::

## 六、完整示例：HTML + CSS + JS 看板

下面是一个完整可运行的"3D + 看板"页面：左边是场景和 6 台设备，右边是 KPI 卡片（OEE 环形、稼动率、良率）+ 各设备产出柱状图。点击柱子，3D 里的对应设备会出现选中圈、相机飞过去；数字每隔一会儿还会自己跳动，模拟实时数据。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>数据看板与 3D 联动</title>
  <style>
    :root {
      --brand: #42b883; --bg: #0d1117; --panel: #161e2a;
      --text: #e6edf3; --muted: #8b949e; --border: #2a3444; --danger: #ff4d4f;
    }
    * { box-sizing: border-box; }
    body { margin: 0; background: var(--bg); color: var(--text); font-family: sans-serif; }
    .app { display: flex; height: 100vh; }
    #scene { flex: 1; position: relative; }

    /* ===== 看板 ===== */
    #dash { width: 340px; background: var(--panel); border-left: 1px solid var(--border);
            padding: 18px; overflow-y: auto; }
    #dash h2 { font-size: 17px; margin: 0 0 4px; color: var(--brand); }
    #dash .sub { color: var(--muted); font-size: 12px; margin-bottom: 18px; }
    .card { background: #1d2736; border: 1px solid var(--border);
            border-radius: 10px; padding: 14px; margin-bottom: 14px; }
    .card h3 { margin: 0 0 10px; font-size: 13px; color: var(--muted); font-weight: 500; }

    /* 环形 OEE */
    .oee-row { display: flex; align-items: center; gap: 18px; }
    .ring { width: 100px; height: 100px; border-radius: 50%; flex: none;
            background: conic-gradient(var(--brand) calc(var(--pct) * 1%), #233045 0);
            display: grid; place-items: center; }
    .ring-inner { width: 76px; height: 76px; border-radius: 50%; background: #1d2736;
                  display: grid; place-items: center; font-size: 20px; font-weight: 700; }
    .oee-info { font-size: 12px; color: var(--muted); line-height: 1.9; }

    /* 指标条 */
    .metric { margin-bottom: 12px; }
    .metric .label { display: flex; justify-content: space-between; font-size: 13px; margin-bottom: 5px; }
    .track { height: 8px; background: #233045; border-radius: 4px; overflow: hidden; }
    .fill  { height: 100%; background: linear-gradient(90deg, var(--brand), #6ee7b7);
             border-radius: 4px; transition: width .4s; }

    /* 柱状图 */
    .bars { display: flex; align-items: flex-end; gap: 7px; height: 120px; }
    .bar { flex: 1; min-height: 4px; background: linear-gradient(var(--brand), #2a7a5a);
           border-radius: 4px 4px 0 0; cursor: pointer; transition: opacity .2s, outline .2s; }
    .bar:hover { opacity: .75; }
    .bar.active { outline: 2px solid #fff; outline-offset: 1px; }
    .bar-labels { display: flex; gap: 7px; margin-top: 6px; }
    .bar-labels span { flex: 1; text-align: center; font-size: 10px; color: var(--muted); }
  </style>
  <script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
    }
  }
  </script>
</head>
<body>
  <div class="app">
    <div id="scene"></div>
    <aside id="dash">
      <h2>车间实时看板</h2>
      <div class="sub">数据每 2 秒刷新 · 点击柱子联动 3D</div>

      <div class="card">
        <h3>设备综合效率 OEE</h3>
        <div class="oee-row">
          <div class="ring" id="oeeRing" style="--pct: 0">
            <div class="ring-inner" id="oeeText">--</div>
          </div>
          <div class="oee-info">
            可用率 × 性能 × 良品率<br />
            行业优秀线：<b style="color:var(--brand)">85%</b>
          </div>
        </div>
      </div>

      <div class="card">
        <h3>关键指标</h3>
        <div class="metric">
          <div class="label"><span>稼动率</span><b id="avText">--</b></div>
          <div class="track"><div class="fill" id="avFill" style="width:0"></div></div>
        </div>
        <div class="metric">
          <div class="label"><span>良率</span><b id="qyText">--</b></div>
          <div class="track"><div class="fill" id="qyFill" style="width:0"></div></div>
        </div>
      </div>

      <div class="card">
        <h3>各设备产出（点击联动 3D）</h3>
        <div class="bars" id="bars"></div>
        <div class="bar-labels" id="barLabels"></div>
      </div>
    </aside>
  </div>

  <script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  // ===== 设备数据 =====
  const devices = Array.from({ length: 6 }, (_, i) => ({
    id: 'DEV-' + (i + 1),
    name: '设备 ' + (i + 1),
    output: 40 + Math.floor(Math.random() * 60)
  }));

  // ===== 3D 场景（注意：用容器的宽高，不是 innerWidth） =====
  const container = document.getElementById('scene');
  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x0d1117);
  const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 100);
  camera.position.set(11, 9, 14);
  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFShadowMap;
  container.appendChild(renderer.domElement);
  const controls = new OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;
  controls.target.set(0, 0.5, 0);
  scene.add(new THREE.HemisphereLight(0xaaccff, 0x222233, 1.5));
  const sun = new THREE.DirectionalLight(0xffffff, 2);
  sun.position.set(6, 10, 5); sun.castShadow = true; scene.add(sun);
  const floor = new THREE.Mesh(new THREE.PlaneGeometry(30, 20),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.95 }));
  floor.rotation.x = -Math.PI / 2; floor.receiveShadow = true; scene.add(floor);
  scene.add(new THREE.GridHelper(30, 30, 0x3b4a63, 0x27334a));

  const bodyMat = new THREE.MeshStandardMaterial({ color: 0x64748b, metalness: 0.5, roughness: 0.5 });
  const meshes = [];
  devices.forEach((d, i) => {
    const m = new THREE.Mesh(new THREE.BoxGeometry(1.5, 1.2, 1.3), bodyMat);
    m.position.set((i - 2.5) * 2.6, 0.6, 0);
    m.castShadow = true;
    m.userData.id = d.id;
    scene.add(m); meshes.push(m);
  });

  // 选中圈
  const ring = new THREE.Mesh(
    new THREE.TorusGeometry(1.15, 0.05, 8, 48),
    new THREE.MeshBasicMaterial({ color: 0x42b883 })
  );
  ring.rotation.x = -Math.PI / 2; ring.visible = false; scene.add(ring);

  // ===== 点击图表 → 联动 3D =====
  const focus = { active: false, camTo: new THREE.Vector3(), targetTo: new THREE.Vector3() };
  function selectDeviceIn3D(id) {
    const i = devices.findIndex(d => d.id === id);
    const m = meshes[i];
    ring.position.set(m.position.x, 0.06, m.position.z);
    ring.visible = true;
    focus.camTo.set(m.position.x + 3, 3.2, m.position.z + 5);
    focus.targetTo.copy(m.position);
    focus.active = true;
    controls.enabled = false;
  }

  // ===== 渲染柱状图（纯 DOM） =====
  const barsEl = document.getElementById('bars');
  const labelsEl = document.getElementById('barLabels');
  function renderBars() {
    barsEl.innerHTML = ''; labelsEl.innerHTML = '';
    const max = Math.max(...devices.map(d => d.output), 1);
    devices.forEach(d => {
      const bar = document.createElement('div');
      bar.className = 'bar';
      bar.style.height = (d.output / max * 100) + '%';
      bar.dataset.id = d.id;
      bar.title = `${d.name}：${d.output} 件`;
      bar.onclick = () => {
        document.querySelectorAll('.bar').forEach(b => b.classList.remove('active'));
        bar.classList.add('active');
        selectDeviceIn3D(d.id);
      };
      barsEl.appendChild(bar);
      const label = document.createElement('span');
      label.textContent = d.id.slice(-1);
      labelsEl.appendChild(label);
    });
  }
  renderBars();

  // ===== 更新 KPI =====
  function updateKPI() {
    const availability = 70 + Math.random() * 20; // 稼动率
    const quality = 88 + Math.random() * 10;       // 良率
    const performance = 85 + Math.random() * 10;   // 性能
    const oee = Math.round(availability / 100 * performance / 100 * quality / 100 * 100);

    const ring = document.getElementById('oeeRing');
    ring.style.setProperty('--pct', oee);          // 改 CSS 变量 → 环形跟着变
    document.getElementById('oeeText').textContent = oee + '%';
    document.getElementById('avText').textContent = availability.toFixed(1) + '%';
    document.getElementById('qyText').textContent = quality.toFixed(1) + '%';
    document.getElementById('avFill').style.width = availability + '%';
    document.getElementById('qyFill').style.width = quality + '%';

    devices.forEach(d => { d.output = 40 + Math.floor(Math.random() * 60); });
    renderBars();
  }
  updateKPI();
  setInterval(updateKPI, 2000);

  // ===== 容器自适应 =====
  function resize() {
    const w = container.clientWidth, h = container.clientHeight;
    camera.aspect = w / h;
    camera.updateProjectionMatrix();
    renderer.setSize(w, h);
  }
  new ResizeObserver(resize).observe(container);
  resize();

  // ===== 动画循环 =====
  const timer = new THREE.Timer();
  renderer.setAnimationLoop(() => {
    timer.update();
    if (focus.active) {
      camera.position.lerp(focus.camTo, 0.06);
      controls.target.lerp(focus.targetTo, 0.08);
      if (camera.position.distanceTo(focus.camTo) < 0.05) {
        camera.position.copy(focus.camTo);
        focus.active = false;
        controls.enabled = true;
      }
    }
    controls.update();
    renderer.render(scene, camera);
  });
  </script>
</body>
</html>
```

::: tip 大白话时间

这个例子的联动链路特别清晰：

**点柱子 → `bar.onclick` → `selectDeviceIn3D(id)` → 移动选中圈 + 设置相机目标 → 动画循环 lerp 飞过去。**

而 KPI 数字更新走的是另一条线：`updateKPI()` 每 2 秒算一次，改 CSS 变量 `--pct` 和 `width`。两条线互不干扰——**看板管数字，3D 管场景，一个 id 把它们串起来**。到了 Vue3 里，这个 id 就是 Pinia 里的 `selectedDeviceId`。

:::

## 七、小结

| 需求 | 手段 |
|---|---|
| 环形 OEE | `conic-gradient` + CSS 变量 `--pct` |
| 指标条 | `width` 百分比 + `transition` |
| 柱状图 | 一排 `div`，高度按数值 |
| 换主题 | 改 `:root` 里的 CSS 变量 |
| UI 联动 3D | 点击事件调用 `selectDeviceIn3D(id)` |
| 容器自适应 | `ResizeObserver` + 容器宽高 |

单个页面的玩法都讲完了。下一篇我们把所有东西装进一个**正经的 Vue3 项目**——组件化、Pinia 状态、WebSocket 数据层，一次给全 6 个核心文件。
