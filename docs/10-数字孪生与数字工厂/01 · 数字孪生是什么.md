# 数字孪生是什么？

一句话：**数字孪生就是给现实里的一个东西（一台设备、一栋楼、一座城市）在电脑里造一个"活"的双胞胎。** 这个双胞胎不光长得像，还会跟着现实里的对象实时变化——现实里机器温度升高，电脑里的模型也跟着变红；现实里停机，电脑里的模型也跟着熄火。

## 一、先说人话版本

你小时候玩过"大家来找茬"吗？两张图摆一起，找不同。数字孪生有点反过来——它追求的是**两张图一模一样，而且其中一张会实时跟着另一张变**。

打个比方：

- **现实世界**是演员，正在现场直播；
- **数字孪生**是演员的"数字分身"，坐在直播间里；
- 演员流汗，分身流汗；演员摔倒，分身摔倒；分身还能提前"预演"演员下一步摔倒会不会出事。

::: tip 大白话时间

普通 3D 模型是一张**照片**，数字孪生是一路**直播**。

照片再好看也是静态的；直播虽然画质可能差点，但它是"活的"——这恰恰是数字孪生最值钱的地方。

:::

## 二、和 3D 可视化、游戏有啥区别

很多人第一反应：这不就是做个 3D 页面吗？还真不太一样。我给你列个对照表：

| 对比项 | 3D 可视化 | 游戏 | 数字孪生 |
|---|---|---|---|
| 数据来源 | 人工整理的静态数据 | 策划写死的剧本 | 真实设备的实时数据 |
| 是否实时 | 一般不实时 | 按游戏逻辑变化 | **秒级甚至毫秒级同步现实** |
| 是否影响现实 | 不影响 | 不影响 | **可以反向控制现实设备** |
| 核心目标 | "好看、看懂" | "好玩" | "看得准、控得住、能预测" |
| 典型例子 | 3D 柱状图、产品展示 | 赛车、射击游戏 | 工厂监控、楼宇运维 |

看出门道了吧？**游戏是"假的但好玩"，数字孪生是"真的且有用"。** 游戏里那台机器是程序员编出来的，数字孪生里那台机器对应着车间里一台真实存在的、会发烫会坏的设备。

::: warning 注意

不是所有"看起来像数字孪生"的项目都是真数字孪生。很多所谓的大屏，其实只是把数据库里的数据做了个 3D 包装——没有实时联动、不能反向控制，顶多算"3D 可视化大屏"。**判断标准很简单：现实对象变了，屏幕会不会自己跟着变？** 会，才算入门。

:::

## 三、三个核心特征

数字孪生有三条腿，缺一条就站不稳。

### 特征一：实时数据联动

现实对象身上的传感器（温度、压力、转速、电流……）持续把数据发到电脑里，3D 模型根据这些数据改变颜色、位置、动画。**这是数字孪生和普通 3D 的分水岭。**

### 特征二：双向映射

不光是"现实 → 数字"，还要能"数字 → 现实"。你在 3D 界面上点一下"启动这台设备"，指令通过网络传回车间，真实设备真的转起来。这就叫**双向**。

::: tip 大白话时间

单向映射像看电视——你只能看，电视里的人看不到你。

双向映射像视频通话——你看得见对方，对方也看得见你，还能听你指挥。数字孪生要的是"视频通话"，不是"看电视"。

:::

### 特征三：仿真推演

因为电脑里有现实对象的完整模型，你就可以拿它做"如果……会怎样"的实验，而不必真的去折腾现实设备。比如："如果这条产线提速 20%，会不会堵料？"先在数字孪生里跑一遍，没问题再到现实里改。

## 四、都在哪些行业用

| 行业 | 孪生对象 | 典型用途 |
|---|---|---|
| 工厂 | 产线、设备、整车间 | 监控稼动率、预测设备故障、产线平衡分析 |
| 楼宇 | 空调、电梯、照明 | 能耗优化、设备故障预警、空间管理 |
| 电网 | 变电站、输电线路 | 负荷监控、故障定位、巡检辅助 |
| 城市 | 道路、管网、建筑 | 交通调度、内涝模拟、城市规划 |

你会发现规律：**越是"设备贵、停机损失大、危险系数高"的场景，数字孪生越值钱。** 因为这意味着"提前发现问题"能省下真金白银。

## 五、技术栈全景图

做一个数字孪生系统，前端到后端大概是这么一套东西：

| 层次 | 技术 | 作用 |
|---|---|---|
| 3D 渲染层 | **Three.js**（r187） | 把设备、场景画出来，做交互和动画 |
| 前端框架 | **Vue3** | 管理界面组件、状态、路由 |
| 状态管理 | Pinia | 统一存放设备状态，多个组件共享 |
| 实时通信 | **WebSocket / MQTT** | 把实时数据从后端推到前端 |
| 工业协议 | OPC UA / Modbus | 后端用来和真实设备对话（第 08 篇细讲） |
| 数据存储 | 时序数据库（InfluxDB 等） | 存设备上报的历史数据，供回放和分析 |

::: info 信息

**WebSocket** 像一个常开的电话线：连上之后，后端有数据就主动推给你，不用你一遍遍打电话去问。**MQTT** 是物联网领域更轻量的一套" publish/subscribe（发布/订阅）"机制，特别适合设备多、网络不稳的场景。这两篇教程里我们先用 `setInterval` 模拟数据流，把 3D 部分跑通，真实项目再换成它们。

:::

## 六、最小架构长啥样

先别被上面一堆名词吓到。最小的数字孪生系统，其实就四块：

```text
┌─────────────┐   ① 设备上报    ┌──────────────┐
│  现实设备    │ ──────────────> │  数据网关     │
│ (传感器/PLC) │ <────────────── │ (后端服务)    │
└─────────────┘   ④ 反向控制    └──────┬───────┘
                                        │ ② WebSocket / MQTT 推送
                                        v
                              ┌────────────────────┐
                              │   前端 (Vue3)       │
                              │  ┌──────────────┐  │
                              │  │ 状态仓库 Pinia │  │
                              │  └──────┬───────┘  │
                              │         │ ③ 数据驱动│
                              │  ┌──────v───────┐  │
                              │  │ Three.js 场景 │  │
                              │  │ (3D 双胞胎)    │  │
                              │  └──────────────┘  │
                              └────────────────────┘
```

数据的流动是个闭环：**现实设备 → 网关 → 前端状态 → 3D 模型**，反向还能从 3D 界面发指令回去控制设备。本篇我们先把 ② ③ 这两步用模拟数据跑通。

## 七、最小可运行示例：一个数字孪生系统长啥样

下面这个例子，就是前面架构图的"迷你版"：一台设备 + 头顶一盏状态灯 + 一个模拟数据流。把整段代码存成 `index.html`，用浏览器打开就能看（需要联网加载 Three.js）。试着盯着看十几秒，状态灯会自己变颜色——那就是"数据流驱动 3D"的魔法。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>数字孪生最小示例</title>
  <style>
    body { margin: 0; overflow: hidden; background: #0d1117; font-family: sans-serif; }
    #hud {
      position: fixed; top: 16px; left: 16px; color: #e6edf3;
      background: rgba(0, 0, 0, .55); padding: 12px 18px;
      border-radius: 8px; line-height: 1.9; font-size: 14px;
    }
    #dot { display: inline-block; width: 11px; height: 11px;
           border-radius: 50%; margin-right: 7px; background: #888; }
  </style>
  <script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
    }
  }
  </script>
</head>
<body>
  <div id="hud">
    <div><span id="dot"></span>1# 注塑机：<b id="state">初始化中…</b></div>
    <div>温度 <span id="temp">--</span> ℃　｜　节拍 <span id="beat">--</span> s</div>
  </div>

  <script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  // ===== 1. 基础三件套 =====
  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x0d1117);
  scene.fog = new THREE.Fog(0x0d1117, 10, 30);

  const camera = new THREE.PerspectiveCamera(55, innerWidth / innerHeight, 0.1, 100);
  camera.position.set(6, 4.5, 7);

  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFShadowMap;
  document.body.appendChild(renderer.domElement);

  const controls = new OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;
  controls.target.set(0, 1, 0);

  // ===== 2. 光照 + 地面 =====
  scene.add(new THREE.HemisphereLight(0x88bbff, 0x222233, 1.1));
  const sun = new THREE.DirectionalLight(0xffffff, 2.2);
  sun.position.set(5, 9, 4);
  sun.castShadow = true;
  sun.shadow.mapSize.set(1024, 1024);
  scene.add(sun);

  const floor = new THREE.Mesh(
    new THREE.PlaneGeometry(40, 40),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.95 })
  );
  floor.rotation.x = -Math.PI / 2;
  floor.receiveShadow = true;
  scene.add(floor);
  scene.add(new THREE.GridHelper(40, 40, 0x334155, 0x223044));

  // ===== 3. 造一台设备（几个方块拼出来） =====
  const machine = new THREE.Group();
  const metal = new THREE.MeshStandardMaterial({ color: 0x64748b, metalness: 0.6, roughness: 0.4 });
  const base = new THREE.Mesh(new THREE.BoxGeometry(2.4, 0.3, 1.6), metal);
  base.position.y = 0.15;
  const body = new THREE.Mesh(new THREE.BoxGeometry(1.8, 1.4, 1.2), metal);
  body.position.y = 1.0;
  base.castShadow = body.castShadow = true;
  machine.add(base, body);
  scene.add(machine);

  // 头顶的状态灯：一个自发光的球
  const lampMat = new THREE.MeshStandardMaterial({
    color: 0x42b883, emissive: 0x42b883, emissiveIntensity: 0.6
  });
  const lamp = new THREE.Mesh(new THREE.SphereGeometry(0.18, 24, 24), lampMat);
  lamp.position.set(0, 2.0, 0);
  machine.add(lamp);

  // ===== 4. 状态 → 颜色 映射表 =====
  const STATUS = {
    running:  { name: '运行中', color: 0x42b883 }, // 绿
    standby:  { name: '待机',   color: 0xffc107 }, // 黄
    alarm:    { name: '报警',   color: 0xff4d4f }, // 红
    offline:  { name: '离线',   color: 0x555555 }  // 灰
  };
  let currentStatus = 'standby';
  const targetColor = new THREE.Color(STATUS.standby.color);
  const dot = document.getElementById('dot');
  const elState = document.getElementById('state');
  const elTemp = document.getElementById('temp');
  const elBeat = document.getElementById('beat');

  // ===== 5. 模拟数据流：真实项目换成 WebSocket 就行 =====
  function feedData() {
    const keys = Object.keys(STATUS);
    currentStatus = keys[Math.floor(Math.random() * keys.length)];
    const info = STATUS[currentStatus];

    targetColor.setHex(info.color);
    dot.style.background = '#' + info.color.toString(16).padStart(6, '0');
    elState.textContent = info.name;
    elTemp.textContent = (currentStatus === 'offline' ? '--' : (60 + Math.random() * 30).toFixed(1));
    elBeat.textContent = (currentStatus === 'running' ? (8 + Math.random() * 4).toFixed(1) : '--');
  }
  feedData();
  setInterval(feedData, 2000); // 每 2 秒来一条新数据

  // ===== 6. 动画循环（r187 写法：Timer + setAnimationLoop） =====
  const timer = new THREE.Timer();
  renderer.setAnimationLoop(() => {
    timer.update();
    const t = timer.getElapsed();

    // 颜色平滑过渡：不是"啪"地变，而是慢慢靠过去
    lampMat.color.lerp(targetColor, 0.06);
    lampMat.emissive.lerp(targetColor, 0.06);

    // 运行时呼吸灯；报警时急促闪烁；离线时熄灭
    if (currentStatus === 'running') lampMat.emissiveIntensity = 0.5 + Math.sin(t * 3) * 0.35;
    else if (currentStatus === 'alarm') lampMat.emissiveIntensity = 0.4 + Math.abs(Math.sin(t * 8)) * 1.2;
    else if (currentStatus === 'standby') lampMat.emissiveIntensity = 0.3;
    else lampMat.emissiveIntensity = 0.0;

    controls.update();
    renderer.render(scene, camera);
  });

  addEventListener('resize', () => {
    camera.aspect = innerWidth / innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(innerWidth, innerHeight);
  });
  </script>
</body>
</html>
```

::: tip 大白话时间

这段代码里最关键的其实只有三行：

1. `feedData()` 每 2 秒造一条假数据——**它就是"现实世界"**；
2. `targetColor.setHex(...)` 根据状态改目标颜色；
3. 动画循环里 `lampMat.color.lerp(targetColor, 0.06)` 让灯**慢慢**变成目标颜色。

真实项目里，你只要把第 1 步的 `setInterval` 换成 WebSocket 的 `onmessage`，把收到的数据喂进来，后面两步完全不用动。**整个数字孪生的骨架就搭好了。**

:::

## 八、小结

| 记住这几点 | 一句话 |
|---|---|
| 是什么 | 现实对象的"活的"数字分身 |
| 区别于 3D | 实时联动 + 双向控制 + 仿真推演 |
| 核心闭环 | 现实 → 数据 → 3D，还能反向控制 |
| 技术栈 | Three.js + Vue3 + WebSocket/MQTT + 时序库 |
