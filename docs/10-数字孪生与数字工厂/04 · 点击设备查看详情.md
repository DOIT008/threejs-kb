# 点击设备查看详情

设备会变色了，但用户光看颜色还不够——"这台机器到底叫啥？温度多少？啥时候报的警？"这时候就要做点击交互：**点一下设备，弹出详情面板，相机还平滑地飞过去**。这篇把拾取、高亮、UI 联动、相机动画一次讲清。

## 一、拾取：Raycaster 是怎么"点中"物体的

Three.js 里判断"鼠标点中了谁"，用的是 **`Raycaster`（射线检测器）**。原理特别像**打激光枪**：

1. 鼠标在屏幕上点一下，得到一个屏幕坐标；
2. 把这个坐标换算成一条从相机射出去的射线；
3. 看这条射线穿过了哪些物体——第一个穿到的就是"点中的"。

```js
const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

addEventListener('pointerdown', (e) => {
  // 屏幕坐标 → 归一化设备坐标（-1 到 +1）
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;

  raycaster.setFromCamera(pointer, camera);        // 发射射线
  const hits = raycaster.intersectObjects(deviceGroup.children, true); // true = 也检测子物体
  if (hits.length) {
    const device = findDeviceRoot(hits[0].object); // 找到它属于哪台设备
    selectDevice(device);
  }
});
```

::: tip 大白话时间

`intersectObjects(..., true)` 最后那个 `true` 很关键。设备通常是 `Group`（外壳、灯、零件一堆子物体），不写 `true` 的话射线只检测 Group 本身——而 Group 没有几何体，永远点不中。**写 `true` 等于说"连它肚子里的零件也一起查"。**

:::

### 找到"点中的是哪台设备"

射线击中的往往是某个小零件（比如一盏灯），但我们要的是整台设备。所以给每台设备的根 `Group` 打上 `userData.id`，命中后顺着父级往上找：

```js
function findDeviceRoot(object) {
  let o = object;
  while (o) {
    if (o.userData && o.userData.id) return o; // 找到带 id 的那一层
    o = o.parent;
  }
  return null;
}
```

## 二、高亮：让选中的设备脱颖而出

点中之后得让用户看清"我选的是这台"。三种常见做法：

| 方法 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| 发光强调 | 把选中设备的 `emissive` 调亮 | 最简单、零依赖 | 边界不够清晰 |
| 描边圈 | 脚底放一个发光圆环 | 直观、像"选中框" | 要有额外几何体 |
| OutlinePass | 后期处理描边轮廓 | 最专业、贴合模型边缘 | 要引 EffectComposer，稍复杂 |

前两种轻量，组合起来效果就很好。**下面主示例用"发光 + 描边圈"**，因为它不引入后期处理，代码更好懂、更稳。想要专业描边的看后面的 OutlinePass 小节。

```js
// 选中时：把设备所有 Mesh 的自发光调亮
device.traverse(o => {
  if (o.isMesh && o.material.emissive) {
    o.material.emissive.setHex(0x2a6df5);
    o.material.emissiveIntensity = 0.8;
  }
});
```

::: warning 注意

如果多台设备**共用同一个材质实例**，改一台的 `emissive` 会连累所有设备！解决办法：要么每台设备 `material.clone()` 自己的材质，要么只改一个独立的"选中圈"而不动设备本体。主示例里我们用一个独立的描边圈，就是为了躲开这个坑。

:::

## 三、信息面板：HTML overlay 跟着 3D 坐标走

详情面板最好用普通 HTML 做（好排版、能放按钮），然后让它**贴在设备旁边**。诀窍是把设备的 3D 世界坐标**投影**成屏幕坐标：

```js
// 设备头顶的世界坐标 → 屏幕像素坐标
const worldPos = new THREE.Vector3();
device.getWorldPosition(worldPos);
worldPos.y += 2; // 抬高一点，让面板浮在设备上方

const v = worldPos.clone().project(camera); // 关键：project() 投影
const x = (v.x * 0.5 + 0.5) * innerWidth;
const y = (-v.y * 0.5 + 0.5) * innerHeight;

panel.style.left = x + 'px';
panel.style.top  = y + 'px';
panel.style.transform = 'translate(-50%, -100%)'; // 面板底部对准这个点
```

::: tip 大白话时间

`project()` 就像给 3D 世界拍了张**照片**，然后告诉你"那个设备在这张照片的第几行第几列"。拿到像素坐标后，HTML 面板就可以用 `left/top` 贴过去。**每帧都算一次**，相机怎么转，面板就怎么跟着走，像用绳子拴在设备上一样。

:::

::: warning 一定要处理"物体在相机背后"

当设备转到相机背后时，`project()` 算出的坐标会翻到屏幕另一边，面板会"穿帮"跑错位置。判断方法：投影后如果 `v.z > 1`，说明在视野外/背后，把面板藏起来：

```js
if (v.z > 1) panel.style.display = 'none';
else panel.style.display = 'block';
```

:::

## 四、相机聚焦：lerp 飞过去

点中设备后，让相机平滑地飞到设备附近，用户能看得更清楚。做法还是老朋友 **lerp**——每帧朝目标位置靠一点：

```js
const focus = { active: false, camTo: new THREE.Vector3(), targetTo: new THREE.Vector3() };

function focusOn(device) {
  const p = new THREE.Vector3();
  device.getWorldPosition(p);
  focus.camTo.set(p.x + 3, p.y + 3, p.z + 5); // 相机停在设备斜上方
  focus.targetTo.copy(p);                      // 视线中心对准设备
  focus.active = true;
  controls.enabled = false;                    // 飞行期间禁用手动控制，避免"抢方向盘"
}

// 动画循环里：
if (focus.active) {
  camera.position.lerp(focus.camTo, 0.06);
  controls.target.lerp(focus.targetTo, 0.08);
  if (camera.position.distanceTo(focus.camTo) < 0.05) {
    camera.position.copy(focus.camTo);
    focus.active = false;
    controls.enabled = true;
  }
}
controls.update();
```

::: info 信息

飞行期间 `controls.enabled = false` 是必须的。`OrbitControls` 内部也在改相机位置，你 lerp 它也 lerp，俩人抢方向盘画面会抖。到了之后记得恢复 `true`，把控制权还给用户。

:::

## 五、完整示例：点击设备查看详情

下面是完整可运行版本。6 台设备，点任意一台：出现蓝色选中圈、弹出贴在设备上方的详情面板、相机平滑聚焦；点空白处取消选中。为了区分"点击"和"拖拽旋转"，只有按下和抬起位置几乎没动时才算点击。

  </div>
  <div id="tip">点击设备查看详情 · 拖拽旋转视角 · 点空白处取消</div>

  scene.background = new THREE.Color(0x0d1117);
  const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
  camera.position.set(11, 9, 14);

        panel.style.left = (v.x * 0.5 + 0.5) * innerWidth + 'px';
        panel.style.top  = (-v.y * 0.5 + 0.5) * innerHeight + 'px';
        panel.style.transform = 'translate(-50%, -100%)';

    renderer.render(scene, camera);

    camera.updateProjectionMatrix();

</body>
</html>

## 六、想要专业描边？用 OutlinePass

如果你觉得"发光圈"太朴素，可以上后期处理的 `OutlinePass`，它会沿着模型轮廓描一圈，最专业。接入套路是**把 `renderer.render` 换成 `composer.render`**：

```js
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { OutlinePass } from 'three/addons/postprocessing/OutlinePass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

const outline = new OutlinePass(new THREE.Vector2(innerWidth, innerHeight), scene, camera);
outline.edgeStrength = 4;      // 描边强度
outline.edgeGlow = 0.6;        // 辉光
outline.visibleEdgeColor.set('#2a9df5');
composer.addPass(outline);
composer.addPass(new OutputPass()); // r187 里放在最后做色调映射/输出

// 选中时把命中的物体交给它
outline.selectedObjects = [selectedDevice];

// 动画循环里换成 composer.render()（别再 renderer.render）
renderer.setAnimationLoop(() => {
  controls.update();
  composer.render();
});
```

::: warning 注意

用了 `EffectComposer` 后，`resize` 时要额外 `composer.setSize(innerWidth, innerHeight)`，否则画面会糊或错位。`OutputPass` 要放在最后——它负责把颜色正确输出，漏了会偏色。另外 OutlinePass 对性能有一定开销，设备特别多时慎用，优先用发光/描边圈这种轻量方案。

:::

## 七、小结

| 需求 | 方案 |
|---|---|
| 点中设备 | `Raycaster` + `userData.id` 找根 |
| 区分点击/拖拽 | 按下抬起位移 < 5px |
| 高亮 | 发光 / 描边圈 / `OutlinePass` |
| 面板跟设备 | 每帧 `project()` 投影坐标 |
| 相机聚焦 | lerp 到目标 + 禁用控制器 |
