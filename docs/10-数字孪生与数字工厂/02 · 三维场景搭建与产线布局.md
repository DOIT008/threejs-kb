# 三维场景搭建与产线布局

上一篇我们知道了数字孪生是啥，这篇开始动手。第一步就是把车间"画"出来：地面、网格、墙体、产线、工位、传送带、一台台设备机台。重点不是堆代码，而是**先定好规矩**——坐标系怎么算、布局数据怎么存。规矩定好了，后面接数据、做交互都顺。

## 一、先定规矩：坐标系与单位

Three.js 的世界坐标是：**X 向右、Y 向上、Z 朝屏幕外**（右手坐标系）。做数字孪生时我们统一约定：

| 约定 | 取值 | 大白话解释 |
|---|---|---|
| 单位 | **1 单位 = 1 米** | 别用厘米，否则光照、相机、物理全是乱的 |
| 地面 | Y = 0 平面 | 所有设备都"站"在这个面上 |
| X 轴 | 车间的长（横向） | 比如 30 米，范围 -15 ~ +15 |
| Z 轴 | 车间的宽（纵深） | 比如 20 米，范围 -10 ~ +10 |
| Y 轴 | 高度 | 墙高 4 米就是 Y 从 0 到 4 |

::: tip 大白话时间

把车间想成一个**大棋盘**：地面是棋盘，X 和 Z 是棋盘的格子坐标，Y 是棋子能摞多高。1 格 = 1 米。设备放在哪一格，就用 `[x, y, z]` 写清楚，比如 `[-8, 0, -5]` 表示"左边 8 米、靠里 5 米、贴地"。

**单位统一是头等大事。** 你用米，模型也用米，相机的"近平面/远平面"、灯光范围才对得上。混用单位就像拿英尺量体温——数值再精确也没意义。

:::

## 二、车间里都有啥

一个最小车间，拆开看就这 7 样：

| 元素 | 几何体 | 作用 |
|---|---|---|
| 地面 | `PlaneGeometry` | 承接阴影，整个车间的底 |
| 网格 | `GridHelper` | 1 米一格，方便对齐和目测距离 |
| 墙体 | 4 个 `BoxGeometry`（薄板） | 围出车间边界 |
| 产线 | 细长 `BoxGeometry` | 传送带/流水线本体 |
| 工位 | `BoxGeometry` 拼的桌子 | 人工操作台 |
| 设备机台 | `Group`（几个盒子组合） | 数控机床、机器人等主角 |
| 批量货物 | `InstancedMesh` | 货架上成百上千个箱子，一次画完 |

不要一上来就建得跟真实工厂一样复杂。**先用方块把布局摆对，再考虑换 GLB 精细模型。** 布局对了，后面换模型只是替换几何体而已。

## 三、布局数据结构：用 JSON 描述整个车间

关键点来了：设备位置**不要写死在代码里**，而是抽成一个 JSON。这样改布局不用改代码，甚至可以让后端直接返回这份 JSON。

一份完整的 `layout.json` 长这样：

```json
{
  "name": "一号装配车间",
  "size": { "width": 30, "depth": 20, "height": 4 },
  "grid": { "step": 1 },
  "lines": [
    {
      "id": "L1",
      "name": "装配一线",
      "from": [-12, -5],
      "to": [12, -5],
      "speed": 0.8
    },
    {
      "id": "L2",
      "name": "装配二线",
      "from": [-12, 5],
      "to": [12, 5],
      "speed": 0.6
    }
  ],
  "devices": [
    { "id": "CNC-01", "name": "1号数控机床", "type": "cnc",    "position": [-8, 0, -8], "rotation": 0 },
    { "id": "CNC-02", "name": "2号数控机床", "type": "cnc",    "position": [-4, 0, -8], "rotation": 0 },
    { "id": "ROB-01", "name": "上下料机器人", "type": "robot", "position": [ 0, 0, -8], "rotation": 0 },
    { "id": "CNC-03", "name": "3号数控机床", "type": "cnc",    "position": [ 4, 0, -8], "rotation": 0 },
    { "id": "ST-01",  "name": "质检工位",     "type": "station","position": [ 8, 0, -8], "rotation": 0 },
    { "id": "CNC-04", "name": "4号数控机床", "type": "cnc",    "position": [-8, 0,  8], "rotation": 0 },
    { "id": "ROB-02", "name": "包装机器人",   "type": "robot", "position": [ 0, 0,  8], "rotation": 0 },
    { "id": "ST-02",  "name": "打包工位",     "type": "station","position": [ 8, 0,  8], "rotation": 0 }
  ],
  "storage": {
    "origin": [12, 0, 0],
    "cols": 4,
    "rows": 5,
    "gap": 0.9
  }
}
```

几个字段说明一下：

| 字段 | 含义 |
|---|---|
| `size` | 车间长宽高，用来建地面和墙 |
| `lines[].from / to` | 产线起点终点的 `[x, z]`，两点确定一条直线 |
| `devices[].type` | 设备类型，决定用哪种几何体组合来画 |
| `devices[].position` | `[x, y, z]`，设备落地点 |
| `storage` | 货架区域参数，用来批量生成货物箱子 |

::: info 信息

**`from`/`to` 只写 `[x, z]` 两个值**，因为产线永远贴地（Y 固定）。写两个值比写三个值省事，也不容易出错。等以后要做立体仓库，再给产线加个 Y 也不迟。

:::

## 四、批量建模：InstancedMesh 一次画完几百个箱子

货架上如果有 200 个箱子，傻乎乎地 `new Mesh` 200 次，电脑会卡。正确姿势是 **`InstancedMesh`**——同一个几何体、同一个材质，只画一次，但摆 200 个位置。

核心就三步：

```js
// 1. 声明数量，创建 InstancedMesh
const boxes = new THREE.InstancedMesh(
  new THREE.BoxGeometry(0.7, 0.5, 0.7),
  new THREE.MeshStandardMaterial({ color: 0xffffff }),
  200 // 实例数量
);

// 2. 用 dummy 摆好每一个的位置/旋转/缩放
const dummy = new THREE.Object3D();
for (let i = 0; i < 200; i++) {
  dummy.position.set(/* 算出来的位置 */);
  dummy.updateMatrix();
  boxes.setMatrixAt(i, dummy.matrix);        // 写入第 i 个的变换矩阵
}

// 3. 加进场景（只需要一次 draw call）
scene.add(boxes);
```

::: warning 注意

`InstancedMesh` 里的所有实例**共享同一个材质**。想给每个箱子不同颜色？用 `setColorAt(i, color)` 单独设置——材质颜色会被每个实例的颜色乘上，所以材质设成白色最稳。改完记得 `instanceMatrix.needsUpdate = true` 和 `instanceColor.needsUpdate = true`（一次性设置后通常不用，但运行中改要设）。

:::

## 五、完整示例：加载布局并渲染整个车间

下面这个例子把上面的 JSON 和渲染逻辑全串起来了。为了让你**双击 HTML 就能跑**（不依赖本地服务器），我把 JSON 直接内嵌在 `<script type="application/json">` 里；真实项目里把这坨 JSON 换成 `fetch('/api/layout')` 拿到的结果就行。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>数字工厂 - 车间布局</title>
  <style>
    body { margin: 0; overflow: hidden; background: #0d1117; }
    #tip { position: fixed; left: 16px; top: 16px; color: #c9d1d9;
           background: rgba(0,0,0,.5); padding: 10px 14px; border-radius: 8px; font-size: 13px; }
  </style>
  <script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.187.0/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.187.0/examples/jsm/"
    }
  }
  </script>
</head>
<body>
  <div id="tip">左键拖拽旋转 · 滚轮缩放 · 右键平移</div>

  <!-- 布局数据：真实项目用 fetch 从后端取 -->
  <script id="layout-data" type="application/json">
  {
    "name": "一号装配车间",
    "size": { "width": 30, "depth": 20, "height": 4 },
    "grid": { "step": 1 },
    "lines": [
      { "id": "L1", "from": [-12, -5], "to": [12, -5], "speed": 0.8 },
      { "id": "L2", "from": [-12,  5], "to": [12,  5], "speed": 0.6 }
    ],
    "devices": [
      { "id": "CNC-01", "type": "cnc",     "position": [-8, 0, -8] },
      { "id": "CNC-02", "type": "cnc",     "position": [-4, 0, -8] },
      { "id": "ROB-01", "type": "robot",   "position": [ 0, 0, -8] },
      { "id": "CNC-03", "type": "cnc",     "position": [ 4, 0, -8] },
      { "id": "ST-01",  "type": "station", "position": [ 8, 0, -8] },
      { "id": "CNC-04", "type": "cnc",     "position": [-8, 0,  8] },
      { "id": "ROB-02", "type": "robot",   "position": [ 0, 0,  8] },
      { "id": "ST-02",  "type": "station", "position": [ 8, 0,  8] }
    ],
    "storage": { "origin": [12, 0, 0], "cols": 3, "rows": 6, "gap": 0.9 }
  }
  </script>

  <script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  const layout = JSON.parse(document.getElementById('layout-data').textContent);

  // ===== 基础三件套 =====
  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x0d1117);
  const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 200);
  camera.position.set(22, 18, 22);

  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFShadowMap;
  document.body.appendChild(renderer.domElement);

  const controls = new OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;
  controls.target.set(0, 0, 0);
  controls.maxPolarAngle = Math.PI / 2 - 0.02;

  scene.add(new THREE.HemisphereLight(0xaaccee, 0x222233, 1.4));
  const sun = new THREE.DirectionalLight(0xffffff, 2.4);
  sun.position.set(12, 20, 8);
  sun.castShadow = true;
  sun.shadow.mapSize.set(2048, 2048);
  const d = 20;
  sun.shadow.camera.left = -d; sun.shadow.camera.right = d;
  sun.shadow.camera.top = d;   sun.shadow.camera.bottom = -d;
  scene.add(sun);

  const { width, depth, height } = layout.size;

  // ===== 1. 地面 + 网格 =====
  const floor = new THREE.Mesh(
    new THREE.PlaneGeometry(width, depth),
    new THREE.MeshStandardMaterial({ color: 0x1b2230, roughness: 0.95 })
  );
  floor.rotation.x = -Math.PI / 2;
  floor.receiveShadow = true;
  scene.add(floor);
  scene.add(new THREE.GridHelper(Math.max(width, depth), Math.max(width, depth), 0x3b4a63, 0x27334a));

  // ===== 2. 四面墙（用薄盒子，半透明不挡视线） =====
  const wallMat = new THREE.MeshStandardMaterial({
    color: 0x2c3a52, transparent: true, opacity: 0.35, side: THREE.DoubleSide
  });
  function addWall(w, h, x, z, ry) {
    const m = new THREE.Mesh(new THREE.BoxGeometry(w, h, 0.15), wallMat);
    m.position.set(x, h / 2, z);
    m.rotation.y = ry;
    scene.add(m);
  }
  addWall(width, height, 0, -depth / 2, 0);
  addWall(width, height, 0,  depth / 2, 0);
  addWall(depth, height, -width / 2, 0, Math.PI / 2);
  addWall(depth, height,  width / 2, 0, Math.PI / 2);

  // ===== 3. 产线（传送带）+ 上面滚动的箱子 =====
  const beltMat = new THREE.MeshStandardMaterial({ color: 0x374151, roughness: 0.7 });
  const boxMat  = new THREE.MeshStandardMaterial({ color: 0xd49a3a, roughness: 0.6 });
  const movingBoxes = [];
  layout.lines.forEach(line => {
    const [x1, z1] = line.from, [x2, z2] = line.to;
    const len = Math.abs(x2 - x1);
    const belt = new THREE.Mesh(new THREE.BoxGeometry(len, 0.25, 1.2), beltMat);
    belt.position.set((x1 + x2) / 2, 0.5, z1);
    belt.castShadow = belt.receiveShadow = true;
    scene.add(belt);

    // 每条线上摆 6 个箱子，动画里让它们沿线滚动
    for (let i = 0; i < 6; i++) {
      const box = new THREE.Mesh(new THREE.BoxGeometry(0.5, 0.5, 0.5), boxMat);
      box.position.set(x1 + (len / 6) * i, 0.88, z1);
      box.castShadow = true;
      scene.add(box);
      movingBoxes.push({ mesh: box, from: x1, to: x2, speed: line.speed });
    }
  });

  // ===== 4. 设备机台：按 type 用不同的方块组合 =====
  const cncMat    = new THREE.MeshStandardMaterial({ color: 0x5b8def, metalness: 0.5, roughness: 0.4 });
  const robotMat  = new THREE.MeshStandardMaterial({ color: 0xe05a5a, metalness: 0.4, roughness: 0.5 });
  const stationMat= new THREE.MeshStandardMaterial({ color: 0x9b7ede, roughness: 0.6 });
  const deviceGroup = new THREE.Group();
  scene.add(deviceGroup);

  layout.devices.forEach(dev => {
    const g = new THREE.Group();
    if (dev.type === 'cnc') {
      const base = new THREE.Mesh(new THREE.BoxGeometry(1.6, 1.2, 1.4), cncMat);
      base.position.y = 0.6; g.add(base);
      const head = new THREE.Mesh(new THREE.BoxGeometry(0.5, 0.5, 0.5), cncMat);
      head.position.set(0, 1.45, 0); g.add(head);
    } else if (dev.type === 'robot') {
      const pillar = new THREE.Mesh(new THREE.CylinderGeometry(0.25, 0.35, 1.2, 16), robotMat);
      pillar.position.y = 0.6; g.add(pillar);
      const arm = new THREE.Mesh(new THREE.BoxGeometry(1.4, 0.2, 0.2), robotMat);
      arm.position.set(0.5, 1.3, 0); g.add(arm);
    } else { // station 工位
      const table = new THREE.Mesh(new THREE.BoxGeometry(1.8, 0.15, 1), stationMat);
      table.position.y = 0.9; g.add(table);
      for (const sx of [-0.8, 0.8]) for (const sz of [-0.4, 0.4]) {
        const leg = new THREE.Mesh(new THREE.BoxGeometry(0.1, 0.9, 0.1), stationMat);
        leg.position.set(sx, 0.45, sz); g.add(leg);
      }
    }
    g.traverse(o => { if (o.isMesh) o.castShadow = true; });
    g.position.set(...dev.position);
    g.rotation.y = dev.rotation || 0;
    g.userData = { id: dev.id, type: dev.type }; // 打上标签，第 04 篇拾取时要用
    deviceGroup.add(g);
  });

  // ===== 5. 货架货物：InstancedMesh 批量生成 =====
  const s = layout.storage;
  const count = s.cols * s.rows;
  const goods = new THREE.InstancedMesh(
    new THREE.BoxGeometry(0.7, 0.6, 0.7),
    new THREE.MeshStandardMaterial({ color: 0xffffff, roughness: 0.7 }),
    count
  );
  goods.castShadow = true;
  const dummy = new THREE.Object3D();
  const color = new THREE.Color();
  let idx = 0;
  for (let r = 0; r < s.rows; r++) {
    for (let c = 0; c < s.cols; c++) {
      dummy.position.set(s.origin[0], 0.3 + r * s.gap, s.origin[1] + (c - s.cols / 2) * s.gap);
      dummy.updateMatrix();
      goods.setMatrixAt(idx, dummy.matrix);
      goods.setColorAt(idx, color.setHSL(0.08 + r * 0.02, 0.6, 0.45 + c * 0.03));
      idx++;
    }
  }
  scene.add(goods);

  // ===== 6. 动画循环 =====
  const timer = new THREE.Timer();
  renderer.setAnimationLoop(() => {
    timer.update();
    const dt = timer.getDelta();
    // 传送带上的箱子滚动，到头了回到起点
    movingBoxes.forEach(b => {
      b.mesh.position.x += b.speed * dt;
      if (b.mesh.position.x > b.to) b.mesh.position.x = b.from;
    });
    controls.update();
    renderer.render(scene, camera);
  });

  addEventListener('resize', () => {
    camera.aspect = innerWidth / innerHeight;
    camera.updateProjectionMatrix();
    renderer.setSize(innerWidth, innerHeight);
  });
  </script>
</body>
</html>
```

::: tip 大白话时间

这段代码看着长，其实套路很固定：**读 JSON → 按类型造方块 → 摆到指定坐标 → 加进场景**。真正体现"数字孪生"的只有两个地方：

1. 每个设备 `g.userData = { id: dev.id }` 打上了身份标签——没这个标签，后面点它你都不知道是谁；
2. `layout` 是从 JSON 来的——把 JSON 换成后端接口返回的数据，你的车间就能"自动长成"真实工厂的样子。

至于 `InstancedMesh`，记住它是**"一次画很多相同东西"的省性能神器**就够了。

:::

::: warning 关于 fetch 加载本地 JSON

如果你把 JSON 单独放成 `layout.json` 再用 `fetch('./layout.json')` 读，**双击 HTML 直接打开会失败**——浏览器的安全策略（CORS）不允许 `file://` 协议读本地文件。解决办法有两个：用本地服务器跑（比如 `npx serve`，或 VS Code 的 Live Server 插件），或者像上面例子那样把 JSON 内嵌进 HTML。真实项目部署在服务器上，`fetch` 就没这个问题。

:::

## 六、小结

| 这一步你学会了 | 对应代码 |
|---|---|
| 统一坐标系 | 1 单位 = 1 米，地面 Y=0 |
| 用 JSON 描述布局 | `layout.json` 结构 |
| 按类型批量造设备 | `devices[].type` → 不同方块组合 |
| 一次画几百个箱子 | `InstancedMesh` |
| 给设备打身份标签 | `g.userData.id` |

车间摆好了，但这些设备还是"死"的——没有状态、不会变色。下一篇我们就接上实时数据，让它们**活起来**。
